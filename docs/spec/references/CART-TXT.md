# CART-TXT: Atari800 DOC/cart.txt

The description of the CART file format (the 16-byte header) and of each cartridge type that
the Atari800 emulator supports, with the type number, the machine, the size and the bank
switching. The CART type numbers are the ones that other emulators also use.

The section index is `CART-TXT.sections.txt`. It has one key for each cartridge type,
`type-<N>`, for example `CART-TXT type-12`.
