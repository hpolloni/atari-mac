# NMS: NMOS 6510 Unintended Opcodes "No More Secrets"

A description of the undocumented (unintended) opcodes of the NMOS 6502 family, with the
unintended addressing modes, the decimal mode, the dummy reads and writes, and the bugs. The
scope section says that the 6502C "SALLY" of the Atari 8-bit computers "also seems to work the
same". The URL is a Wayback Machine snapshot of the file on csdb.dk.

The section index is `NMS.sections.txt`. The headings of the document are not numbered, so
each heading has a short key, for example `NMS ANE` or `NMS decimal-mode`.
