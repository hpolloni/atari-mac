# Keys: the numbered sections use their number (1, 1.3, 1.3.1, 2.4.1.1). The appendices

# How it was made: from the table of contents on PDF page 2 (text layer), with all its

# headings are from PDF pages 16-21. Appendices B, C and D are reprinted data sheets
