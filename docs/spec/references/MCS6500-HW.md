# MCS6500-HW: MCS6500 Microcomputer Family Hardware Manual

The hardware manual of the MOS Technology MCS6500 family: the MCS650X processors, the bus
timing, the interrupts, the MCS6520 PIA and the MCS6530. Appendix A gives the address bus and
the data bus for each cycle of each instruction. The file is a scan from the archive.org item
`6500-10A_MCS6500_Hardware_Manual_1976_Jan`.

The section index is `MCS6500-HW.sections.txt`. A citation uses the section number, for example
`MCS6500-HW 1.3.2 Processor Interrupts` or `MCS6500-HW App-A`.
