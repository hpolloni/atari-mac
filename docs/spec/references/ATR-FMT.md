# ATR-FMT: ATR File Format Description

A one-page description of the ATR disk image format: the 16-byte header, the sector size, the
size in paragraphs, and the sectors that follow. The page was on jindroush.atari.org. The URL
is a Wayback Machine snapshot (2017-12-26) of the copy on the pigwa.net mirror, in the
`nir_dary_cds` collection.

The Wayback Machine also has the page on the atarimax.com mirror
(`www.atarimax.com/jindroush.atari.org/afmtatr.html`), but those copies are a later version of
the page (1999-12-05) with a different layout. The pigwa.net copy is the version of
1999-04-21.

The section index is `ATR-FMT.sections.txt`. It has no section lines, so a citation is only the
ID: `ATR-FMT`.
