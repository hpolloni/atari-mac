# R6520: Rockwell R6520 Peripheral Interface Adapter (PIA) data sheet

The data sheet of the Rockwell R6520 PIA, a second source of the MCS6520. It gives the
registers, the control register bits, the interrupt control and the bus timing. The file is a
scan (12 pages) from the archive.org item `rockwell_r6520_pia`.

The section index is `R6520.sections.txt`. The headings are not numbered, so each heading,
table and figure has a short key, for example `R6520 table-2` or `R6520 control-registers`.
