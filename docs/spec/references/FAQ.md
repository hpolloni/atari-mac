# FAQ: Atari 8-Bit Computers Frequently Asked Questions List

The FAQ list of the comp.sys.atari.8bit newsgroup, maintained by Michael D. Current. It is a
second source (OI-041): when it does not agree with the HRM, the requirement follows the
HRM. The section index is [`FAQ.sections.txt`](FAQ.sections.txt). A citation is
`FAQ <section number> <question>`, for example `FAQ 1.7 What is the Atari 65XE?`.

The site updates the file in place at the same URL. The copy in
[`reference/`](../../../reference/README.md) is the frozen edition. The `url` is the place
where the file was downloaded.
