# GTIA-SPEC: GTIA chip (NTSC)

The Atari drawing CO14805 Rev. A, "GTIA CHIP (NTSC)", as scanned by The Atari Historical
Society; the URL is the Wayback Machine copy of the file on retromicro.com. The PDF has 41
pages and no text layer (image scan). PDF pages 34-41 are logic schematics. The section
index is `GTIA-SPEC.sections.txt`.

## License

No license text was found. Sheet 1 (PDF page 1) has the stamp "CONFIDENTIAL" and the line
"The Atari Historical Society www.atari-history.com". The title block of the schematic on
PDF page 34 has a block of small text that seems to start "TO ALL PERSONS RECEIVING THIS
DRAWING". The scan (150 dpi) is too coarse to read that text, so it is not quoted here. The project does not redistribute
the file. It is pinned by its URL and SHA-256, and it is not in git.
