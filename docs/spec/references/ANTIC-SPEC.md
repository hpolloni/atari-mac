# ANTIC-SPEC: ANTIC (NTSC) chip specification

The Atari drawing CO12296 Rev. D, "ANTIC (NTSC)", as scanned by The Atari Historical
Society and attached to an AtariAge forum post; the URL is the Wayback Machine copy of the
attachment. The PDF has 37 pages; the drawing has 45 sheets. Sheets 27-33 and 41 are not
in the file, so sections 8.0-12.0 and 13.5 are missing. The section index is
`ANTIC-SPEC.sections.txt`; its header comment lists the missing sections.
