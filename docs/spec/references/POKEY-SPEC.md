# POKEY-SPEC: POKEY chip

The Atari drawing CO12294 Rev. B, "POKEY CHIP", as scanned by The Atari Historical
Society. The file was on visual6502.org; the URL is the Wayback Machine snapshot of
2014-12-24, which has the same SHA-256 as the file on the live host. The PDF has 46 pages
and no text layer (image scan). The section index is `POKEY-SPEC.sections.txt`.
