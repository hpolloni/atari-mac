# HRM: Altirra Hardware Reference Manual

The main hardware source of the specification (OI-041). When another reference does not
agree with the HRM, the requirement follows the HRM. The section index is
[`HRM.sections.txt`](HRM.sections.txt). A citation is `HRM <section number> <section title>`,
for example `HRM 4.9 WSYNC`.

The site updates the file in place at the same URL. The copy in
[`reference/`](../../../reference/README.md) is the frozen edition. The `url` is the place
where the file was downloaded.
