# Section index of TRN: Atari Home Computer System Technical Reference Notes, CO16555 Rev. A,
# 1982. Format: one section per line, key<TAB>title. Lines that start with # are comments.
#
# The document has three parts, and the parts use the same numbers again. A key therefore
# starts with the part:
#   OS-   Operating System User's Manual (PDF pages 2-259). Chapters 1-11 and appendices A-L
#         are numbered: OS-9, OS-APP-K. Appendix L has the lettered groups A-R (there are no
#         groups I, O and Q): OS-APP-L.H.
#   SRC-  Operating System Source Listing (PDF pages 260-415). The listing has no sections.
#         The keys are the labels of its "MODULE ORIGIN TABLE" (assembler lines 20-32, PDF
#         page 263), and SRC-EQUATES is the equate file before the first module. A citation
#         can give the assembler line number after the title.
#   HW-   Hardware Manual (PDF pages 416-537). Sections I-VI with lettered subsections, and
#         appendices A-C: HW-II.A, HW-III.B, HW-APP-A.
# A heading that has no number gets the key of its parent, a "/", and the words of its title
# (letters and digits only) joined with "-": OS-6/Usage-Notes/POKEY-Interrupt-Mask,
# HW-II.A/Cycle-Counting. In HW-III the key after the "/" is the register name, or the
# first and the last name of a register group: HW-III.B/NMIEN, HW-III.D/COLPF0-COLPF3.
#
# Missing pages: chapters 3 and 4 of the OS part (printed pages 25-40) are not in this scan.
# Their sections are comment lines ("# missing:"), so that no requirement can cite them.
#
# How it was made: from the text layer of the PDF (Adobe Paper Capture OCR), with each OCR
# error corrected against the page image ("1/0" is "I/O", "CIa" is "CIO", "as" is "OS",
# "Q." is "G.", "~." is "J.").
#   OS-   the table of contents, PDF pages 4-15: chapters, appendices and the second level;
#         the third level only in chapter 6 (interrupts), in the serial bus part of chapter 9,
#         and in groups H (SIO) and P (interrupts) of appendix L.
#   SRC-  the module origin table, PDF page 263.
#   HW-   the table of contents, PDF page 418 (sections and lettered subsections); the
#         underlined run-in headings of section II, PDF pages 422-453; the register headings
#         of section III, PDF pages 454-476 (hexadecimal addresses as printed, with the OCR
#         "O" corrected to "0").
