# TRN: Atari Home Computer System Technical Reference Notes

The scan from bitsavers, in the archive.org item
`bitsavers_atari40080mputerTechnicalReferenceNotes1982_20170986`. The PDF has 537 pages and
an OCR text layer. It has three parts: the Operating System User's Manual (PDF pages
2-259), the Operating System Source Listing (PDF pages 260-415) and the Hardware Manual
(PDF pages 416-537). The section index is `TRN.sections.txt`; its header comment gives the
key rule for the three parts.
