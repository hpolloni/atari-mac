# OI-045: PIA interrupt flag after control line mode changes

## Question

After the writes `$3C`, `$34`, `$3C`, `$14` to `PACTL`, is bit 6 of `PACTL` set?

## Context

HRM 2.5 says that a spurious transition occurs when CA2 was "pulled low recently". The REQ-231 Notes use a project reading: only the last output mode counts. That reading gives bit 6 = 0 for this sequence.

ACID800 `pia_irq` expects bit 6 = 1 for this sequence. It also shows that the pulse mode `101` clears the pending condition, and that the handshake mode `100` keeps it. The HRM does not say this.

## Options

1. Keep the project reading (bit 6 = 0).
2. Follow ACID800: the pending condition stays through the handshake mode, and the pulse mode clears it (bit 6 = 1).

## Recommendation

Option 2. ACID800 is a test on real hardware, and the HRM does not contradict it.

## Decision

Not decided.
