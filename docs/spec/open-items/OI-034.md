# OI-034: Write-protect status bit

## Question

Is the write-protect error in bit 3 or bit 4 of status byte 0?

## Context

HRM Table 44 gives bit 3 ("failed due to write protected disk") and bit 4 as "motor running". HRM 10.15 says "bit 4 of drive status". REQ-627 uses Table 44.

## Options

1. Bit 3 (Table 44).
2. Bit 4 (HRM 10.15).

## Recommendation

Option 1. The table is more specific.

## Decision

Not decided.
