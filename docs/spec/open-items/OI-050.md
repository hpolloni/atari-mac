# OI-050: Key presses for a tape boot

## Question

With `--cas <file>`, does the emulator hold START (and OPTION) at power-on and press a key after the prompt tone, or does the user do this?

## Context

TRN OS-10/Cassette-Booted-Software: "You must be pressing the [START] key as power is applied to the system. [...] When you are given the audio prompt by the cassette handler you must press the [RETURN] key."

FAQ 1.7 (65XE), cassette boot: "With BASIC or with cartridge (cartridge disables BASIC): Hold down [START] while turning on the computer. With no cartridge and without BASIC: Hold down both [START] and [OPTION] while turning on the computer. (system buzzer sounds) [...] Press [RETURN] on the computer."

TRN SRC-CASORG (assembler lines 3163-3166): the OPEN for input sounds one tone, waits for a key, and then starts the motor.

In the window, F2 is START and F4 is OPTION, but the emulator starts at once, so a user cannot hold START before the power-on. The user can hold F2 and press F10 (cold reset). `Machine::start_xex` already holds OPTION for an XEX boot (`docs/design/media.md`).

A tape with a BASIC program (`CSAVE`, `SAVE "C:"`) is not a boot tape. The user loads it with `CLOAD` or `RUN "C:"` at the `Ready` prompt (FAQ 7.2.2). An automatic boot of such a tape fails.

## Options

1. The user does it: `--cas` only inserts the tape. The user holds F2 (and F4), presses F10, and presses RETURN after the tone.
2. `--cas` holds START at power-on (BASIC stays on). The user presses RETURN after the tone.
3. `--cas` holds START and OPTION at power-on (BASIC off) and presses RETURN at a fixed time after the power-on (frame 180 NTSC, frame 150 PAL). The user does nothing.
4. Option 3, and a second option (for example `--cas-basic <file>`) only inserts the tape with BASIC on, for `CLOAD`.

## Recommendation

Option 3 now, and option 4 as a later addition if the user wants BASIC tapes. Most boot-tape games need BASIC off on the XL/XE. REQ-081 follows option 3 now.

## Decision

Not decided.
