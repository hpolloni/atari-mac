# OI-004: Duplicate cartridge requirements

| Field | Value |
| --- | --- |
| Status | Decided |
| Area | System, media |
| Affects | REQ-206, REQ-210, REQ-232, REQ-601, REQ-602, REQ-603 |
| Raised | 2026-11-19, specification review |

## Question

Which requirement of each duplicate pair stays?

## Context

REQ-601 duplicates REQ-210 (cartridge priority). REQ-602 duplicates REQ-206 (writes to ROM). REQ-603 duplicates REQ-232 (`TRIG3` sense).

## Options

1. Keep the system requirements. Withdraw REQ-601 to REQ-603, and move their extra criteria into the system requirements.
2. Keep the media requirements, and withdraw the system requirements.

## Recommendation

Option 1. The memory map belongs to the system area. Keep the media test images.

## Decision

Decided on 2026-11-19 by the lead (an integration defect: two teams wrote the same requirements). The system requirements stay, because the memory map belongs to the system area.

1. REQ-601, REQ-602 and REQ-603 are `Withdrawn`. Their IDs stay.
2. Their extra criteria moved: REQ-210 criterion 4 (no cartridge, BASIC off: RAM), REQ-206 criteria 5 and 6 (16 KB cartridge at `$8000`; write with RD5 inactive goes to RAM), REQ-232 criteria 7 and 8 (16 KB cartridge; RD5 active again).
3. The media test plan maps its tests to REQ-206, REQ-210 and REQ-232.

Changed: REQ-206, REQ-210, REQ-232, REQ-601 to REQ-603, `media.md` (test images, test plan).
