# OI-039: Machine cycle order and the ANTIC contract in system.md

| Field | Value |
| --- | --- |

| Raised | 2026-11-19, integration check |

## Question

In which order does the machine call the chips in one machine cycle?

## Context

`system.md` ran POKEY after the CPU access. `pokey.md` requires POKEY to run before the CPU access. `system.md` also had its own ANTIC contract (`AnticCycle`, `tick(mem, &mut gtia)`), which contradicted `antic.md`. The spec review found this after the open items were written.

## Options

1. Use one interface in both designs.

## Recommendation

Option 1.

## Decision

Decided on 2026-11-19 by the lead (an integration defect).

`system.md`, "Timing", is now the only definition of the cycle order: ANTIC `tick`; serial line and POKEY `tick`; NMI and IRQ levels to the CPU; the CPU access (unless ANTIC halts the CPU); ANTIC `end_cycle` and GTIA `clock` with the data bus value; PIA `tick`, then the serial bytes and the command line to the SIO bus. `architecture.md` gives a summary and refers to it. The ANTIC contract in `system.md` now refers to `antic.md` (OI-001).

Changed: `system.md` ("ANTIC", "Memory bus", "Timing"), `architecture.md` ("Scheduling model").
