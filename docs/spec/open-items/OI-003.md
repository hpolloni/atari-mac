# OI-003: Cartridge interface signatures

| Field | Value |
| --- | --- |
| Status | Open |
| Area | System, media |
| Affects | REQ-210, REQ-232, REQ-600 to REQ-609; system.md; media.md |
| Raised | 2026-11-19, specification review |

## Question

Which Rust interface does the cartridge have?

## Context

`system.md` asks for `read(&mut self)`, `peek`, `write` and `access_control(..) -> Option<u8>`. `media.md` gives `read(&self)` and an `access_control` that returns nothing. A `$D5xx` read must be able to return a byte that the cartridge drives.

## Options

1. Use the `system.md` interface.
2. Use the `media.md` interface, and add a return value to `access_control`.

## Recommendation

Option 1. It supports cartridges that drive `$D5xx` reads and ANTIC side effects (OI-002).

## Decision

Not decided.
