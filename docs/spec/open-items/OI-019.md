# OI-019: Fifth player priority

## Question

How does the fifth player (`PRIOR` bit 4) change the priority logic?

## Context

The HRM gives no equations for it. The model in REQ-426 disagrees with 3 cells of HRM Table 16, and with the HRM text for `PRIOR` = `$18`. The reviewer checked the cells again with a script.

## Options

1. Change the model until it matches all of Table 16.
2. Use Table 16 as a lookup table for the fifth-player cases.
3. Compare with Altirra.

## Recommendation

Option 2 if no model matches. REQ-426 is Should, so it is not in SLICE-01.

## Decision

Decided by the user on 2026-11-19: the fifth player (`PRIOR` bit 4) is out of scope. REQ-426 is withdrawn, and the fifth player is a non-goal (`docs/spec/README.md`). REQ-424 is checked with `PRIOR` bit 4 = 0 only.
