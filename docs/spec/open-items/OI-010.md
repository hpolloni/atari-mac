# OI-010: Cycle of the CA2/CB2 pulse

## Question

On which cycle is the CA2/CB2 pulse output low?

## Context

The HRM says "low for one cycle" but not which cycle. The reviewer chose the cycle after the access.

Second sources (OI-041): R6520 `figure-4` says that "CA2 goes low on the first negative (high-to-low) φ2 clock transition following a read of Output Register A" and returns high on the next negative transition. MCS6500-HW 1.5.5.1 (Figures 1.31b and 1.31c) says that CA2 "goes low for one cycle after a Read A Data operation". Both support option 1. The REQ-227 Notes give these citations.

## Options

1. The cycle after the access.
2. The cycle of the access.

## Recommendation

Option 1, unless a source says otherwise. Mark it as a project decision.

## Decision

Not decided.
