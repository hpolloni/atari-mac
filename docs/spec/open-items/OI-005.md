# OI-005: Chip state that a test can compare

## Question

How does a test copy and compare the state of a chip?

## Context

REQ-217 compares the GTIA and POKEY states before and after the RESET key. REQ-018 (save states) needs the complete machine state. The designs do not define a common state type.

## Options

1. Each chip derives `Clone` and `PartialEq`, and the test compares the chip values.
2. Each chip has a `debug_state()` that returns a plain struct.

## Recommendation

Option 1 now, because it is simple. REQ-018 can add a serialization format later.

## Decision

Decided on 2026-11-19 by the lead (an integration gap: REQ-217 needed an interface that no chip design gave).

Each chip type (`Cpu`, `Antic`, `Gtia`, `Pokey`, `Pia`, the media types) and `Machine` derive `Debug`, `Clone` and `PartialEq`. A test clones a chip and compares it with `==`. REQ-018 (save states) can add a serialization format later.
