# OI-028: Linked timer reload cycle

## Question

Is the second reload of a linked timer pair at T+9 or T+10?

## Context

The HRM text gives T+9. The N+7 period formula gives T+10. No criterion depends on it.

Second sources (OI-041): in the code of ACID800 `pokey_timertiming`, linked timers with `$0010` give the low timer fires on T+24 and T+47 and the high timer fires on T+27 and T+50. This agrees with a period of N+7. The comment table in the same file shows a spacing of 20 cycles, which does not agree with its code. This is partial evidence only.

## Options

1. T+9.
2. T+10.

## Recommendation

Check with Altirra when the timers are implemented.

## Decision

Not decided.
