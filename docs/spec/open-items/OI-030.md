# OI-030: 65XE keyboard layout

| Field | Value |
| --- | --- |
| Status | Decided |
| Area | POKEY |
| Affects | REQ-523, REQ-009 |
| Raised | 2026-11-19, specification review |

## Question

Does the 65XE have the same keys as the 130XE?

## Context

The HRM shows only the 130XE layout (Table 12). The author assumed that the 65XE has the same keys.

## Options

1. Accept the 130XE layout for the 65XE.

## Recommendation

Option 1. Both machines have the same keyboard. Confirm it with a second source.

## Decision

Decided on 2026-11-19 by the lead (an integration defect between the POKEY and SIO bus designs).

POKEY does not report a byte through `take_serial_byte` if `SKCTL` bit 7 (force break) was 1 in any cycle of its frame. SIO DATA OUT was 0 for that time, so no device can receive the byte (REQ-532).

Changed: `pokey.md` (call contract item 7, state `out_break_seen`, open issue 15), `media.md` (call contract item 2).
