# OI-046: Cassette device code that SIO intercepts

## Question

Does the OS send a request to the cassette code when `DDEVIC` is `$5F` or when it is `$60`?

## Context

HRM 9.1: "DDEVIC=$5F is what is intercepted". REQ-623 criterion 5 depends on this.

The TRN OS source listing (400/800 OS, assembler lines 1611 and 1732) has `CASET = $60` and `CMP #CASET`. With `DUNIT` = 0, `DDEVIC` `$60` gives the bus ID `$5F`, so the HRM may mean the bus ID. No reference was checked for the XL OS or AltirraOS.

The cassette deck of SLICE-08 (REQ-641 to REQ-643) does not depend on this item: the OS cassette code drives POKEY and the motor line, and the emulator does not intercept it. REQ-643 criterion 5 checks only that the SIOV shortcut does not handle the cassette requests. A cassette shortcut (OI-051 option 3) would depend on this item.

### Evidence from AltirraOS (2026-11-20, SLICE-05 WP-2)

The test of REQ-623 criterion 5 ran with AltirraOS. A request with `DDEVIC` = `$5F` and `DUNIT` = `$D3` is not routed to the cassette code: the OS sends it on the bus as bus ID `$31`, also with the SIOV shortcut off, so D1: answers and the buffer holds `$02`. A request with `DDEVIC` = `$60` and `DUNIT` = 1 does not reach D1:. Thus AltirraOS intercepts `DDEVIC` = `$60`, as the TRN listing does, and not `$5F`. Criterion 5 fails with AltirraOS because of the OS, not because of the emulator. The SIOV shortcut never handles `$5F`. The test is ignored until this item is decided.

## Options

1. Keep `$5F` (HRM text).
2. Use `$60` (TRN listing), and state that `$5F` is the bus ID.
3. Check the XL OS and AltirraOS first.

## Recommendation

Option 2. AltirraOS agrees with the TRN listing (see the evidence above). REQ-623 criterion 5 then uses `DDEVIC` = `$60` and `DUNIT` = `$D2` (bus ID `$60 + $D2 - 1` = `$31` with 8-bit wrap). The XL OS was not checked.

## Decision

Decided by the user on 2026-11-21: option 2. The SIO routine sends a request to the cassette code when `DDEVIC` is `$60`. With `DUNIT` = 0, the bus ID `DDEVIC + DUNIT - 1` is `$5F`, the value in the HRM text. REQ-623 criterion 5 uses `DDEVIC` = `$60` and `DUNIT` = `$D2`. The tape shortcut (REQ-644) uses `DDEVIC` = `$60`. The user chose the tape shortcut to make tape loads faster (2026-11-21).
