# OI-046: Cassette device code that SIO intercepts

## Question

Does the OS send a request to the cassette code when `DDEVIC` is `$5F` or when it is `$60`?

## Context

HRM 9.1: "DDEVIC=$5F is what is intercepted". REQ-623 criterion 5 depends on this.

The TRN OS source listing (400/800 OS, assembler lines 1611 and 1732) has `CASET = $60` and `CMP #CASET`. With `DUNIT` = 0, `DDEVIC` `$60` gives the bus ID `$5F`, so the HRM may mean the bus ID. No reference was checked for the XL OS or AltirraOS.

The cassette deck of SLICE-08 (REQ-641 to REQ-643) does not depend on this item: the OS cassette code drives POKEY and the motor line, and the emulator does not intercept it. REQ-643 criterion 5 checks only that the SIOV shortcut does not handle the cassette requests. A cassette shortcut (OI-051 option 3) would depend on this item.

## Options

1. Keep `$5F` (HRM text).
2. Use `$60` (TRN listing), and state that `$5F` is the bus ID.
3. Check the XL OS and AltirraOS first.

## Recommendation

Option 3. The emulator uses AltirraOS, and the 400/800 listing may not apply.

## Decision

Not decided.
