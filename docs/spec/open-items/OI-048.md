# OI-048: CAS chunk types that the emulator supports

## Question

Which CAS chunk types does the emulator support, and what does it do with a chunk type that it does not support?

## Context

CAS-FMT gives these chunk types:

- `FUJI`: the tape description. "A CAS file must begin with a FUJI chunk."
- `baud`: "the baudrate of the following data chunks". The default is 600.
- `data`: "a standard tape record as read or written by Atari's SIO", with the inter-record gap in ms.
- `fsk `: "a raw sequence of lengths of FSK signals (0s and 1s). It is needed to store special signals written on a tape, or any data that could not be recognised as a standard tape record." Copy-protected tapes use it.
- `pwms`, `pwmc`, `pwmd`, `pwml`: turbo formats. "In turbo transmission, bits are encoded using PWM".

HRM 9.17 (Turbo modifications): "A popular modification to Atari cassette tape recorders involves adding a turbo mode that bypasses the FSK bandpass filters. [...] This is often activated by lowering the command line." A turbo tape needs a modified deck and its own loader. HRM C.2: "The hardware only requires a baud rate in range with the correct FSK tones and supports an arbitrary bit stream."

FAQ 9.1: "The .CAS format was extended by Tomasz Krasuski to support non-standard data (copy prevention mechanisms)".

## Options

1. `FUJI`, `baud` and `data` only. An `fsk ` chunk and the turbo chunks are errors.
2. `FUJI`, `baud`, `data` and `fsk `. The turbo chunks and unknown types are errors (`CasChunkType`).
3. Option 2, but the emulator ignores an unknown chunk and a turbo chunk, and shows a warning.
4. All chunk types, with an emulated turbo deck (the command line selects the turbo mode, HRM 9.17).

## Recommendation

Option 2. Standard tapes and most copy-protected tapes load. The `fsk ` chunk is a small addition to the tape signal. An error is better than a warning for a turbo tape, because the tape cannot load without a turbo deck. Option 4 is a scope question for later.

REQ-639, REQ-640 and REQ-642 follow option 2 now.

## Decision

Not decided.
