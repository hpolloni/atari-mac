# OI-012: PAL vertical sync lines

## Question

Are the PAL vertical sync lines 275-277 or 275-278?

## Context

HRM 6.2 gives 275-277. HRM 4.6 gives 275-278.

## Options

1. 275-277.
2. 275-278.

## Recommendation

Option 1 (the GTIA chapter, which describes the signal). Not in SLICE-01, because SLICE-01 is NTSC only.

## Decision

Decided by the user on 2026-11-19: 275-277. HRM 6.2 describes the ANx bus code that ANTIC sends, and gives three lines, as for NTSC. The value 275-278 in HRM 4.6 is a side note. REQ-306 and REQ-346 keep 275-277.
