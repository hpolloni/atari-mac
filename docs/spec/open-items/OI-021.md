# OI-021: PAL chroma blending of row 0

## Question

What is the output of row 0 when PAL chroma blending is on?

## Context

Blending mixes each row with the row above it. Row 0 has no row above it.

## Options

1. Blend row 0 with black.
2. Do not blend row 0.

## Recommendation

Option 2. REQ-412 is Could.

## Decision

Decided by the user on 2026-11-19: option 2. Row 0 is not blended: its output is the RGB value of its own bytes. REQ-412 criterion 6 states this.
