## Question

What is the output of row 0 when PAL chroma blending is on?

## Context

Blending mixes each row with the row above it. Row 0 has no row above it.

## Options

1. Blend row 0 with black.
2. Do not blend row 0.

## Recommendation

Option 2. REQ-412 is Could.
