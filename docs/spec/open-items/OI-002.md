# OI-002: Side effects of ANTIC DMA reads in $D500-$D5FF

| Field | Value |
| --- | --- |
| Status | Open |
| Area | System, media |

| Raised | 2026-11-19, specification review |

## Question

Can an ANTIC DMA read of `$D500-$D5FF` switch a cartridge bank?

## Context

REQ-609 requires it (HRM 8.1 warns about it). REQ-213 says that DMA reads have no side effects. The draft trait `DmaMemory::dma_read(&self)` cannot change state.

## Options

1. DMA reads of `$D5xx` reach the cartridge control. `dma_read` takes `&mut self`.
2. DMA reads have no side effects. REQ-609 criterion 2 is withdrawn.
3. ANTIC reports each DMA address to the machine, and the machine calls the cartridge.

## Recommendation

Option 1. It follows the hardware. Change REQ-213 to name this one exception.

## Decision

Not decided.
