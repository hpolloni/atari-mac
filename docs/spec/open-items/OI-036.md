## Question

Are the file format details that are marked "to verify" correct?

## Context

The HRM does not describe the ATR, XEX or CAR formats, the OS SIO call at `$E459`, the device control block or the boot sector header. The open details: ATR header bytes 7-15; old double-density images with 256-byte boot sectors; the fast SIO bus ID formula, status codes and return registers for AltirraOS and a real OS; the boot header layout; the run behavior of an XEX without `RUNAD`.

## Options

1. Check each detail against a written specification of each format and the Atari OS manual.
2. Check each detail against Altirra.

## Recommendation

Option 1 before the media slice. Add each source to `docs/spec/README.md`.

## Decision

Not decided.
