# OI-041: Frozen references other than the HRM

## Question

Which references other than the HRM does the specification cite, how are they frozen, and which reference is correct when two references do not agree?

## Context

The HRM was the only hardware source. 220 of the 272 requirements that are not withdrawn cite it, and only 11 have no HRM reference. `scripts/fetch-roms.sh` downloaded the HRM from a URL where the file "is updated in place", with a fixed SHA-256. When the file changed or the site was down, `make test`, `make pre-commit` and CI failed.

Three teammates checked 29 documents and the license text of each. The HRM license says: "Permission is granted to redistribute this document in verbatim form as long as it is done free of charge and for non-commercial purposes." The Atari 8-Bit FAQ says: "Feel free to reproduce this file, in whole or in part, so long as the content of that portion reproduced is not modified, and so long as credit is given". Acid800, SingleStepTests 65x02 and the perfect6502 code have the MIT license. Every official Atari, MOS Technology, Synertek and Rockwell document has "All Rights Reserved" or no license.

## Options

1. Keep the HRM as the only source, and commit it to git.
2. Add the references below. Commit each reference whose license permits redistribution. Pin each other reference by its URL and SHA-256.
3. Remove the HRM, and cite no fixed reference.

## Recommendation

Option 2. The HRM stays the main source, because it is the only reference with the cycle detail that the requirements need. The other references are second sources and make the HRM errors (OI-024, OI-031) easier to find.

## Decision

Decided by the user on 2026-11-19: option 2, with all the references of the table. The HRM is correct when two references do not agree. A requirement also cites each other reference that is relevant to it, and its `Notes` section states each difference from the HRM. A pinned reference is frozen by its URL and its SHA-256; it is not in git. REQ-020 and REQ-046 state the rules.

The lead chose the storage of `ACID800`, `SST` and `PERFECT6502`: pin, not commit. `ACID800` contains ROM and ATR files, which are not in git, `SST` is 1.1 GB, and no code uses `PERFECT6502`.
