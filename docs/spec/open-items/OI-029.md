# OI-029: Force break and the SIO bus model

## Question

When force break holds the serial output line at 0, does the SIO bus model receive a byte?

## Context

In the current design, the bus model still receives a reported byte, although the line stays at 0.

## Options

1. The bus model receives no byte during force break.
2. Keep the current behavior.

## Recommendation

Option 1. REQ-532 is Could.

## Decision

Decided on 2026-11-19 by the lead (an integration defect between the POKEY and SIO bus designs).

POKEY does not report a byte through `take_serial_byte` if `SKCTL` bit 7 (force break) was 1 in any cycle of its frame. SIO DATA OUT was 0 for that time, so no device can receive the byte (REQ-532).

Changed: `pokey.md` (call contract item 7, state `out_break_seen`, open issue 15), `media.md` (call contract item 2).
