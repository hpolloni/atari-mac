# OI-011: Reads of unmapped I/O

| Field | Value |
| --- | --- |
| Status | Open |
| Area | System |
| Affects | REQ-214 |
| Raised | 2026-11-19, specification review |

## Question

What does a read of an unused I/O address return?

## Context

The design returns `$FF`. The HRM does not say whether the 65XE has data bus pull-ups. Without pull-ups, a read returns the last value on the bus.

## Options

1. `$FF`.
2. The last data bus value.

## Recommendation

Option 1 for SLICE-01. Change it only if software needs the floating bus.

## Decision

Not decided.
