# OI-008: REQ-210 covers $8000-$9FFF

## Question

Does REQ-210 also cover the cartridge at `$8000-$9FFF`?

## Context

A criterion tested `$8000-$9FFF`, but the statement did not cover it. The reviewer extended the statement and cited HRM 8.1.

Second sources (OI-041): TRN `HW-VI.A` says that cartridges deselect RAM in `$8000-$BFFF`. FAQ 1.14 says that a 16 KB cartridge disables RAM at `$8000-$BFFF`, and FAQ 1.15 names RD4 "RAM Deselect $8000-$9FFF". These support option 1.

## Options

1. Keep the extended statement.
2. Delete the criterion.

## Recommendation

Option 1. 16 KB cartridges need this range.

## Decision

Not decided.
