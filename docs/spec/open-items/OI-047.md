# OI-047: Power-on bank of CAR type 42

## Question

Which bank does a CAR type 42 cartridge select at power-on?

## Context

REQ-607 criterion 4 expects bank 0 for the 8 Mbit cartridge, and its Notes say "to verify". The HRM does not give the power-on bank.

CART-TXT type 42 (the "old" 1 MB Atarimax): "Upon power up, bank $7F is selected". CART-TXT type 75 (the "new" 1 MB Atarimax) selects bank 0. REQ-605 uses type 42. CART-TXT gives no power-on bank for type 41. CART-TXT also says that only a write to the control range selects a bank for types 41 and 42, but the HRM says that a read or a write selects it (REQ-608, REQ-609 follow the HRM).

## Options

1. Keep bank 0 for type 42.
2. Use bank `$7F` for type 42, as CART-TXT says. Bank 0 stays for type 41.
3. Use bank `$7F` for type 42, and add type 75 with bank 0.

## Recommendation

Option 2. CART-TXT is the only source that gives the power-on bank. Type 75 is a scope question for later.

## Decision

Not decided.
