# OI-054: Last HPOS at which the horizontal blank sets hires

## Question

Up to which HPOS can the horizontal blank code `%011` set the hires state, when a write of `$00` to `PRIOR` ends a GTIA mode near the start of a scanline?

## Context

HRM 6.8 (Pseudo ANTIC mode E): "High resolution mode is forced off whenever any of the GTIA special modes are active ... The high resolution flip-flop can only be set at horizontal blank, but it resets any time PRIOR[7:6] is activated and stays off for the rest of the scan line even if those bits are reset to 00." The HRM gives no exact cycle.

The ACID800 test `gtia_psuedomodee` runs a mode F line with `PRIOR` = `$80` from the scanline before, player 0 at `$80` and all playfield bytes `$E4`. A write of `$00` to `PRIOR` on machine cycle 14 must give `P0PF` = `$04` (hires is set). A write on machine cycle 15 must give `P0PF` = `$0F` (hires stays off, pseudo mode E).

With the `PRIOR` delay of REQ-434 criterion 4, the cycle 14 write takes effect at HPOS `$1E` and the cycle 15 write at HPOS `$20`. ANTIC sends the code `%011` at HPOS `$00-$21` (REQ-306, a project decision). So with a code `%011` that can set hires on each of those clocks, the cycle 15 write also sets hires, and the second ACID800 check fails.

## Options

1. The code `%011` sets the hires state on each clock of HPOS `$00-$21` while `PRIOR` bits 6-7 are `%00`. This follows the HRM text and REQ-306. The cycle 14 check of ACID800 passes, and the cycle 15 check fails.
2. The code `%011` sets the hires state only at HPOS `$00-$1F`. GTIA then samples the end of the horizontal blank 2 color clocks before ANTIC ends it. Both ACID800 checks pass. The value `$1F` comes from the test, not from the HRM text.
3. Keep REQ-306 and REQ-434, and look for an error in them first (the `PRIOR` delay or the HPOS range of the code `%011`), with other ACID800 tests.

## Recommendation

Option 2. ACID800 is a test of real hardware by the HRM author, and the HRM does not give a cycle. Record it as a difference from REQ-306 in the Notes of REQ-432. If a later test shows an error in REQ-306 or REQ-434 (option 3), the lead changes this item.

## Decision

Not decided.
