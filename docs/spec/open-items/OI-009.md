# OI-009: POKEY reset at power-on

| Field | Value |

## Question

What does a power-on reset set in POKEY?

## Context

HRM 5.7 says POKEY has no reset pin. REQ-216 resets POKEY at power-on. REQ-501 gives fixed power-on values, with `SKCTL` = `$00`.

## Options

1. A power-on gives the REQ-501 values. The RESET key does not change POKEY.
2. Power-on POKEY state is random.

## Recommendation

Option 1. The core must be deterministic (REQ-014).

## Decision

Decided on 2026-11-19 by the lead (an integration defect: REQ-216 reset POKEY, but POKEY has no reset pin).

`Pokey::reset` sets the power-on state of REQ-501, the same state as `Pokey::new`. The machine calls it only at power-on. The Reset button does not change POKEY (REQ-217).

Changed: REQ-216 (Notes), `system.md` (open issue 9).
