## Question

## Context

REQ-605 covers CAR types 1 and 2. REQ-608 covers Atarimax bank switching, which needs types 41 and 42. The type numbers are marked "to verify".

## Options

1. Add the types to REQ-605.
2. Add a new requirement.

## Recommendation

Option 1, after a check of the type numbers. REQ-608 is Could.

## Decision

Not decided.
