# OI-049: Tape writing

## Question

Can a program write to the emulated tape (for example `CSAVE` in BASIC), and does the emulator save the result as a CAS file?

## Context

HRM 9.17: "When recording, the SIO bus data is recorded directly onto the tape. This is normally done with two-tone mode with timers 1 and 2 clocked with the 64KHz clock with divisors of 6 and 8 (AUDF1=5 and AUDF2=7), giving 5327Hz and 3995Hz as the two tones." HRM 5.6 (Two-tone mode) describes the POKEY side, which REQ-533 covers. TRN OS-APP-K/ATARI-410-TM-Program-Recorder: "In order for recording to take place, the user must press both the REC and PLAY buttons on the cassette."

To write, the emulator must decode the POKEY serial output while the motor runs, make `data` chunks with the gaps, and save a CAS file. The deck needs a record mode (the REC button).

## Options

1. Out of scope. The deck only plays. The POKEY serial output goes nowhere while the motor runs. Add "Tape writing" to the non-goals.
2. Write support: a `--cas-write <file>` option, or a menu item, records the serial output to a new CAS file.
3. Out of scope now, and a scope question for a later slice.

## Recommendation

Option 3. The user asked to load a boot tape. Writing needs a record mode and a file save, which are larger than the load.

## Decision

Not decided.
