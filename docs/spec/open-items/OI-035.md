# OI-035: Bank-switched cartridge types without a source

## Question

Which bank-switched cartridge types are in scope, and what is the source for them?

## Context

HRM 8.1 describes only the address windows. The only bank-switched types in the HRM are the Atarimax types (HRM 8.2). OSS, XEGS and Williams cartridges are common, but the HRM does not describe them.

## Options

1. Keep only the Atarimax types.
2. Find a second source (for example the Altirra cartridge type documentation) and add OSS, XEGS and Williams.

## Recommendation

Option 2 in a later slice. Many programs use these types.

## Decision

Not decided.
