## Question

After a Write Percom block with the enhanced-density (ED) block, does Format `$21` make ED or SD?

## Context

REQ-632 gives a kept ED geometry no effect on Format `$21`. REQ-635 says that Format `$21` uses the kept ED geometry.

## Options

1. ED.
2. SD.

## Recommendation

Decide when REQ-635 (Could) is planned. Make REQ-632 and REQ-635 agree.

## Decision

Not decided.
