# OI-007: IRQ after PLP followed by SEI

| Field | Value |
| --- | --- |
| Status | Open |
| Area | CPU |
| Affects | REQ-119, REQ-120; cpu.md open issue 2 |
| Raised | 2026-11-19, specification review |

## Question

When `PLP` clears `I` and the next instruction is `SEI`, does an IRQ run?

## Context

HRM 3.4 says that these pairs dispatch no IRQ. The HRM rule in REQ-119 (an IRQ comes after the instruction that follows a `PLP` that clears `I`) gives an IRQ after the `SEI`. The design gives an IRQ.

WP-1 finding (2026-11-19): the CPU follows the poll rule of `cpu.md`, so `PLP`+`SEI` and `PLP`+`PLP` dispatch an IRQ. REQ-120 criterion 3 and HRM 3.4 say that they do not. The test `pairs_without_irq_dispatch` covers only `CLI`+`RTI` and `PLP`+`RTI` until this item is decided.

## Options

1. No IRQ (HRM 3.4 text).
2. An IRQ (the polling rule).

## Recommendation

Option 2, if the SingleStepTests data or Altirra agree. Check this before the test `pairs_without_irq_dispatch` is written.

## Decision

Not decided.
