# OI-037: SIO timing statements that conflict

## Question

Which values are correct for these SIO timings?

## Context

HRM 9.1 text gives 10-18 ms for the delay from ACK to the data frame; the HRM timing table gives 1.0-1.8 ms. HRM 10.15 says that the OS sends at 94 cycles per byte; the divisor formula gives 94 cycles per bit. The 810 text gives the format timeout as `$E0` = 224 vertical blanks; HRM Table 44 gives units of 64 vertical blanks. The design does not depend on the first value, and uses 94 cycles per bit and the byte value `$E0` only.

## Options

1. Accept the design choices.

## Recommendation

Option 1. Check the delay with a real OS boot in the media slice.

## Decision

Not decided.
