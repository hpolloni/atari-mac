# OI-014: Line buffer when playfield DMA is off

## Question

When playfield DMA is off in the middle of a line, does ANTIC reuse the line buffer names, or load the data bus value?

## Context

HRM 4.4 says that ANTIC reuses the line buffer names. HRM 4.11 says that the buffer loads the data bus value, and it refers to a "previous case" that is not in the text copy.

## Options

1. Reuse the names (HRM 4.4).
2. Load the data bus value (HRM 4.11).

## Recommendation

Read HRM 4.11 in the PDF first. REQ-344 is Could, so this does not block a slice.

## Decision

Decided by the user on 2026-11-19: after the playfield start, a name or bitmap fetch cycle with DMA off loads the data bus value into the line buffer and advances the memory scan counter (REQ-344 criterion 5). If DMA is off at the playfield start, the line buffer does not change. REQ-344 criterion 8 (the codes in IR modes 2 and 3) is removed until a comparison with Altirra is possible.
