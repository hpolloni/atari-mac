# OI-027: Audio sample rate out of range

| Field | Value |
| --- | --- |
| Status | Open |
| Area | POKEY |
| Affects | REQ-538, REQ-016 |
| Raised | 2026-11-19, specification review |

## Question

What happens when the sample rate is outside 8,000 to 192,000 Hz?

## Context

REQ-538 accepts 8,000 to 192,000 Hz. It does not say what happens outside the range. The core must not panic (REQ-016).

## Options

1. `Machine::new` returns a `ConfigError`.
2. The core clamps the rate into the range.

## Recommendation

Option 1. An error is visible, a clamp is not.

## Decision

Not decided.
