# OI-052: Tape position at a cold reset

## Question

Does the tape go back to the start at a cold reset (power-on, F10), and does the user get tape controls (rewind, eject)?

## Context

A real tape does not move when the computer is switched off. The user rewinds it with the REWIND button. HRM 9.17: "The SIO motor control line enables the 410/1010 recorder motor under computer control, allowing the tape to be stopped on demand. The Play or Record button must also be pressed on the 410 for the motor to activate."

If a boot fails (for example, the RETURN key came too late), the user must start the tape again from the start. FAQ 7.2.2 tells the user to "Use Rewind or Advance/F.Fwd on the recorder, if necessary, to bring the tape to the position where the program is located."

The RESET key does not stop a program that reads the tape. It must not change the tape position, as on the real computer.

## Options

1. As the real deck: the tape position stays at a cold reset. A key (for example F8) rewinds the tape.
2. A cold reset rewinds the tape to the start. The RESET key does not change the position. No other control.
3. Option 2, and a key that rewinds the tape without a cold reset.

## Recommendation

Option 2. With `--cas`, a cold reset then boots the tape again, which is what the user wants after a failed boot. REQ-641 criterion 5 follows option 2 now. Option 3 is a small addition if the user wants it for tapes with more than one program.

## Decision

Decided by the user on 2026-11-20: option 2. A cold reset rewinds the tape, and RESET keeps the position. REQ-641 criterion 5 already follows option 2.
