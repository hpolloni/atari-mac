# OI-025: Serial output complete interrupt and IRQEN

## Question

Does the serial-output-complete IRQ need `IRQEN` bit 3?

## Context

HRM 5.6 and 5.7 say that the interrupt stays asserted even when `IRQEN` bit 3 is 0. HRM 14.4 suggests that the IRQ needs bit 3. The reviewer's reading: the `IRQST` status bit ignores `IRQEN`, but the IRQ line needs bit 3. The OS runs with bit 3 at 0 while the output is idle, which supports this reading.

## Options

1. Status ignores `IRQEN`; the IRQ line needs bit 3.
2. The IRQ line is asserted without bit 3.

## Recommendation

Option 1. Without it, the OS would get IRQs all the time.

## Decision

Not decided.
