# OI-017: NMI start cycle contract with the CPU

| Field | Value |
| --- | --- |
| Status | Open |
| Area | ANTIC, CPU |
| Affects | REQ-116, REQ-334; antic.md; cpu.md |
| Raised | 2026-11-19, specification review |

## Question

Does the CPU accept that ANTIC asserts the NMI line on cycle 9 (cycle 10 after an `NMIEN` write on cycle 7)?

## Context

The ANTIC design needs this to satisfy three HRM statements about `NMIEN` deadlines. The CPU design polls the NMI line in the real 6502 cycles.

## Options

1. Accept the ANTIC contract, and add a joint test that checks the NMI start cycles of REQ-334 with the real CPU.

## Recommendation

Option 1. The joint test goes into SLICE-01.

## Decision

Not decided.
