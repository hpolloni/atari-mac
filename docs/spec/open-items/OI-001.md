## Question

What is the exact interface from ANTIC to GTIA for each machine cycle?

## Context

The two designs differ. `gtia.md` uses `Gtia::tick(&GtiaCycle { line, cycle, an, pm_dma, bus })` and puts the AN codes of cycle C at HPOS 2C-4 and 2C-3. `antic.md` uses `Gtia::clock(&CycleOutput, data_bus)`, puts them at HPOS 2C-2 and 2C-1, sends no scanline number, and gives the P/M data as the halt pattern, the DMA kind and the data bus. HRM 6.10 says that a color register write on cycle 65 shows at HPOS `$81`, one color clock later. So cycle C shows on screen at HPOS 2C-2. The GTIA value 2C-4 can be the position at the GTIA input, before a pipeline delay.

## Options

1. Use the ANTIC design, and change `gtia.md` to it.
2. Use the GTIA design, and change `antic.md` to it.
3. Write a third interface that takes the parts of both.

## Recommendation

Option 1, with one check first: confirm that the 2-color-clock difference is a GTIA pipeline delay and not an error. The SLICE-01 video package (WP-2) owns both chips and settles this item.

## Decision

Not decided.
