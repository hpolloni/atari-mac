# OI-022: Frontend setting for display filters

## Question

How does the user turn artifacting and PAL blending on and off?

## Context

Both filters are off by default. No requirement gives a frontend setting.

## Options

1. Command-line flags `--artifacting` and `--pal-blending`.
2. A key in the window.

## Recommendation

Option 1. Add a frontend requirement when REQ-411 or REQ-412 is planned.

## Decision

Decided by the user on 2026-11-19: option 1, the command-line flags `--artifacting` and `--pal-blending`. REQ-019 states this.
