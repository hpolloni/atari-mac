## Question

Are the derived ANTIC DMA cycles correct?

## Context

The HRM DMA timing charts are images. The text copy does not have them. The ANTIC authors calculated some exact cycles from the HRM prose, for example refresh on cycle 98 in normal mode 2, on cycle 105 in narrow mode 2 with `HSCROL` = 14, and on cycle 106 in wide mode 2.

## Options

1. Read the chart images in the PDF, and compare.
2. Compare with the behavior of the Altirra emulator.

## Recommendation

Option 1 before WP-2 starts. Option 2 is a second check.

## Decision

Not decided.
