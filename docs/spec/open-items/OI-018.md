# OI-018: Playfield DMA on cycle 105

## Question

Can playfield DMA occur on cycle 105?

## Context

HRM 4.9 and 4.14 say that it can. HRM 4.12 says that cycles 105-111 are suppressed for abnormal DMA. The author allows real DMA up to and including cycle 105.

## Options

1. Allow DMA on cycle 105 (HRM 4.9, 4.14).
2. Suppress it.

## Recommendation

Option 1. HRM 4.12 is about abnormal DMA only.

## Decision

Decided by the user on 2026-11-19: option 1. Normal playfield DMA can occur on cycle 105 (HRM 4.9, 4.14). The HRM 4.12 suppression of cycles 105-111 and 0 applies only to abnormal playfield DMA (REQ-345).
