# OI-023: Palette parameters

## Question

Are the palette parameters accepted?

## Context

The palette uses the HRM D.2 formula with a hue step of 24 degrees (the nominal value in HRM 6.3) and a saturation of 0.233 (the 130XE value; the HRM has no 65XE or PAL value). PAL uses the ideal angles of HRM Table 14. Luminance quirks, gamma and color correction are not modeled.

## Options

1. Accept these values.
2. Use the palette of another emulator.

## Recommendation

Option 1. The frontend can add a palette file later.

## Decision

Not decided.
