# OI-057: Where the user types the monitor commands

## Question

Where does the user open the monitor and type its commands (REQ-088 to REQ-090)?

## Context

The monitor stops the emulation, shows the registers, the memory and the disassembly, and takes short commands. The frontend has a window (minifb) and is started from a terminal. F8 is the only free function key.

## Options

1. The terminal that started the emulator. F8 in the window, or Ctrl+C in the terminal, stops the emulation. The monitor reads the commands from standard input and writes to standard output. The window shows the last frame.
2. A text area that the window draws over the Atari screen. F8 opens it. The commands are typed in the window.
3. A remote debug protocol (for example the GDB remote protocol on a TCP port), so that an external debugger connects.

## Recommendation

Option 1. It needs no text drawing in the window, the output can be copied, and a test drives it through standard input. Option 3 can come later.

## Decision

Not decided.
