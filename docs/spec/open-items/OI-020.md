# OI-020: Artifacting scope

## Question

Is artifacting NTSC only, and are the reviewer's thresholds accepted?

## Context

The source names PAL artifacting (HRM D.5), but the criteria and the design are NTSC only. The thresholds 32 and plus or minus 34 are the reviewer's values. The artifact hues are not specified.

## Options

1. NTSC only, with the thresholds.
2. NTSC and PAL.

## Recommendation

Option 1. REQ-411 is Could.

## Decision

Decided by the user on 2026-11-19: NTSC only, with the thresholds 32 and plus or minus 34. PAL artifacting (HRM D.5) is removed from REQ-411.
