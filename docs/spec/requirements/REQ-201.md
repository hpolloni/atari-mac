# REQ-201: Scan line and frame length

## Requirement

The emulator shall use 114 machine cycles in each scan line, 262 scan lines (29,868 cycles) in each NTSC frame, and 312 scan lines (35,568 cycles) in each PAL frame.

## Rationale

All display, interrupt and audio timing is relative to the scan line and the frame.

## Acceptance criteria

1. From cycle 0 of scan line 0, 114 machine cycles bring the machine to cycle 0 of scan line 1.
2. An NTSC machine runs one frame from cycle 0 of scan line 0. The machine cycle counter advances by 29,868, and the machine is at cycle 0 of scan line 0 again (262 scan lines).
3. A PAL machine runs one frame from cycle 0 of scan line 0. The machine cycle counter advances by 35,568, and the machine is at cycle 0 of scan line 0 again (312 scan lines).
4. The frame rate computed from the machine clock and the cycles in one frame is 59.92 Hz for NTSC and 49.86 Hz for PAL, within 0.01 Hz.

## Notes

TRN HW-II.A/Cycle-Counting gives 60 frames per second for NTSC, and TRN HW-II.A/NTSC-vs-PAL-Systems gives 50 Hz for PAL. These are rounded values. FAQ 1.1 gives 59.92 Hz and 49.86 Hz, the values of criterion 4.
