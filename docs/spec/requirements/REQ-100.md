# REQ-100: Documented instruction set

## Requirement

The emulator shall execute the 151 documented 6502 opcodes with the register, memory and flag results of the NMOS 6502.

## Rationale

AltirraOS, Altirra BASIC, the Atari OS ROM and all ordinary software use the documented instructions. The 6502C in the 65XE uses the NMOS 6502 core (HRM 3.6).

## Acceptance criteria

1. The test `single_step_documented_opcodes` runs all cases of the SingleStepTests 6502 file of each of the 151 documented opcodes. For each case, the final `A`, `X`, `Y`, `S`, `P`, `PC` and all RAM bytes of the `final` state agree with the file.
2. Start: `X` = `$80`, `C` = 1, `D` = 1, `$2170` = `$5A`. `LDA $20F0,X` gives `A` = `$5A`, `C` = 1 and `D` = 1. The operand read is at `$2170`.
3. Start: `A` = `$0F`, `$0010` = `$C0`. `BIT $10` gives `N` = 1, `V` = 1 and `Z` = 1. `A` stays `$0F`.
4. Start: `A` = `$40`, `$0010` = `$40`. `BIT $10` gives `N` = 0, `V` = 1 and `Z` = 0.

## Notes

The HRM does not give a table of the documented instruction results. The SingleStepTests 6502 suite is the test reference for the exact results (project decision). The decimal mode results of `ADC` and `SBC` are in REQ-108.

MCS6500-PRG 4.2.2.1 states the `BIT` results of criteria 3 and 4: bit 7 of the memory goes into `N` and bit 6 goes into `V`, independent of `A`.
