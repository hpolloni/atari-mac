# REQ-012: Media from the command line

## Requirement

The frontend shall load a cartridge, an executable or a disk image that is given on the command line.

## Rationale

This is the main way to start software.

## Acceptance criteria

1. `atari-mac --headless --frames 1 --cart <file>` exits with status 0 for a valid 8,192-byte cartridge image. The same is true for `--xex` with a valid executable and `--disk` with a valid ATR image.
2. With a 100-byte file, each of `--cart`, `--xex` and `--disk` writes a message to standard error that names the file, and exits with status 2.

## Notes

Project decision: a rule of the macOS frontend. The HRM does not cover it.
