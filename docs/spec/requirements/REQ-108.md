# REQ-108: Decimal mode ADC and SBC

## Requirement

The emulator shall do BCD correction in `ADC` and `SBC` when `D` = 1, and shall compute `N`, `Z` and `V` from the result before decimal correction, as the NMOS 6502 does.

## Rationale

Floating point arithmetic in the OS and BASIC uses decimal mode. Pole Position depends on the `N` flag in decimal mode (HRM 3.9).

## Acceptance criteria

1. Start: `D` = 1, `C` = 0, `A` = `$0F`. `ADC #$0F` gives `A` = `$14`.
2. Start: `D` = 1, `C` = 0, `A` = `$99`. `ADC #$01` gives `A` = `$00`, `C` = 1 and `N` = 1.
3. Start: `D` = 1, `C` = 0, `A` = `$FF`. `ADC #$01` gives `A` = `$66` and `Z` = 1.
4. Start: `D` = 1, `C` = 1, `A` = `$00`. `SBC #$01` gives `A` = `$99` and `C` = 0 (borrow).
5. Start: `D` = 1, `C` = 1, `A` = `$10`. `SBC #$01` gives `A` = `$09` and `C` = 1 (no borrow).
6. The test `single_step_decimal` runs all SingleStepTests 6502 cases with `D` = 1 in the files of `ADC` (`$61`, `$65`, `$69`, `$6D`, `$71`, `$75`, `$79`, `$7D`) and `SBC` (`$E1`, `$E5`, `$E9`, `$EB`, `$ED`, `$F1`, `$F5`, `$F9`, `$FD`). The final registers, the RAM bytes and the `cycles` list agree with the file.
7. Start: `D` = 1. `ADC #$01` takes 2 cycles and `ADC $10` takes 3 cycles. These are the same counts as with `D` = 0.

## Notes

HRM 3.2 says that 6 is added when a nibble result exceeds 10. The HRM example `$0F + $0F` = `$14` shows that the correction occurs for nibble results above 9. The tests use the HRM examples and the SingleStepTests data. The extra cycle in decimal mode is a 65C02 property (HRM 3.2).

NMS decimal-nutshell says that 6 is added when a nibble is above 9. The HRM text says "exceeds 10", but the HRM example shows a correction above 9. This requirement follows the HRM example, which agrees with NMS. NMS decimal-nutshell also says that `Z` is set from the binary result, before the BCD correction. The HRM example `$FF` + `$01` = `$66` with `Z` set agrees. MCS6500-PRG 2.2.1.2 and 2.2.2.2 give the decimal results for valid BCD values only. ACID800 cpu_decimal checks two `ADC` results and their flags.
