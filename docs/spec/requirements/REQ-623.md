# REQ-623: Fast SIO

## Requirement

When fast SIO is on and the CPU is about to execute the instruction at SIOV (`$E459`) with the OS ROM enabled, the emulator shall do the request in the device control block at once for an emulated device, shall put the result status in `DSTATS` and Y, shall set the N flag from bit 7 of the status, and shall return to the address after the `JSR` of the caller.

## Rationale

At 19200 baud, a disk of 90 KB loads in more than one minute. Users want programs to load fast. SIOV is the documented entry point of the OS SIO routine in AltirraOS and in the Atari XL/XE OS.

## Device control block

| Address | Name | Use |
| --- | --- | --- |
| `$0300` | `DDEVIC` | Device bus ID base |
| `$0301` | `DUNIT` | Unit number |
| `$0302` | `DCOMND` | Command |
| `$0303` | `DSTATS` | In: direction (bit 6 = receive, bit 7 = send). Out: status. |
| `$0304-$0305` | `DBUFLO`, `DBUFHI` | Buffer address |
| `$0306` | `DTIMLO` | Timeout |
| `$0308-$0309` | `DBYTLO`, `DBYTHI` | Buffer length |
| `$030A-$030B` | `DAUX1`, `DAUX2` | AUX1 and AUX2 |

| Result | Status in `DSTATS` and Y |
| --- | --- |
| Complete | `$01` |
| Timeout | `$8A` |
| Device NAK | `$8B` |
| Checksum error | `$8F` |
| Device Error | `$90` |

## Acceptance criteria

The test program is in the boot sector of the SD test image of REQ-619 (each byte of sector `n` holds `n & $FF`). It fills the device control block, executes `JSR $E459`, and then stores Y at `$0680` and the processor status (with `PHP`, `PLA`) at `$0681`. Then it writes `$A5` to `$0600` and loops. The test runs until `$0600` holds `$A5`, for at most 600 frames. Unless a criterion states another value, `DDEVIC` = `$31`, `DUNIT` = `$01`, `DTIMLO` = `$07` and the buffer is at `$4000`.

1. With AltirraOS and fast SIO on, a Read (`DCOMND` = `$52`, `DSTATS` = `$40`, `DBYT` = 128, `DAUX` = 2): `$4000-$407F` holds 128 bytes of `$02`, `$0680` holds `$01`, `$0303` (`DSTATS`) holds `$01`, and bit 7 of `$0681` is 0.
2. The same Read with `DAUX` = 0 (sector 0): `$0680` holds `$8B`, `$0303` holds `$8B`, and bit 7 of `$0681` is 1.
3. A Put (`DCOMND` = `$50`, `DSTATS` = `$80`, `DBYT` = 128, `DAUX` = 5) with 128 bytes of `$5A` at `$4000`: `$0680` holds `$01`, and sector 5 of the image in D1: then holds 128 bytes of `$5A`.
4. A Read with `DUNIT` = `$02` (bus ID `$32`, no emulated device): the emulator does not do the request. The OS routine runs, and `$0680` holds `$8A`.
5. A Read with `DDEVIC` = `$5F` and `DUNIT` = `$D3` (the bus ID `$5F + $D3 - 1` is `$31` with 8-bit wrap): the emulator does not do the request. The test does not wait for `$0600`. After 300 frames, `$4000-$407F` does not hold 128 bytes of `$02`.
6. The test program disables IRQ and NMI (`SEI`, `NMIEN` = `$00`), sets `PORTB` bit 0 = 0 (OS ROM disabled), puts `A0 77 60` (`LDY #$77`, `RTS`) in RAM at `$E459`, and executes `JSR $E459` with a valid Read in the device control block. Then `$0680` holds `$77`, and `$4000-$407F` is not changed.
7. Criteria 1 and 2 also pass with a user-supplied Atari XL/XE OS ROM (REQ-004). When the user has not supplied this ROM, the test prints a message that names the missing ROM and passes with no check.
8. The boot test of REQ-636 criterion 1 reaches `$0600` = `$A5` in fewer frames with fast SIO on than with fast SIO off.

## Notes

To verify: the bus device ID is `DDEVIC + DUNIT - 1`, the status codes, and the return state (Y and the N flag) for both OS ROMs. Criterion 4 gives `$8A` from the OS routine itself, so it also checks the timeout code.

Criterion 5 checks the cassette rule. The test does not check the result of the OS cassette code.

With fast SIO, the POKEY serial registers do not change, and no serial interrupt occurs. Programs that use their own SIO code, not SIOV, use the real serial path.
