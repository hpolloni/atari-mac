# REQ-111: Stable undocumented opcodes

| Field | Value |

## Requirement

The emulator shall execute the stable undocumented opcodes with the results and bus cycles of the NMOS 6502.

## Rationale

Some Atari games and demos use undocumented opcodes. The 6502C has them because it uses the NMOS core (HRM 3.6).

## Acceptance criteria

1. Start: `$0010` = `$41`, `A` = `$50`, `C` = 1, `D` = 0. `ISB $10` (`$E7`) takes 5 cycles, the same as `INC $10`. It writes `$42` to `$0010` and gives `A` = `$0E` and `C` = 1.
2. Start: `$0010` = `$80`. `LAX $10` (`$A7`) gives `A` = `$80`, `X` = `$80`, `N` = 1 and `Z` = 0.
3. Start: `A` = `$F0`, `X` = `$3C`. `SAX $10` (`$87`) writes `$30` to `$0010`. `P` does not change.
4. Start: `X` = `$80`. `NOP $20F0,X` (`$1C`) takes 5 cycles. Cycle 4 reads `$2070` and cycle 5 reads `$2170`. `A`, `X`, `Y`, `S` and `P` do not change.
5. Start: `X` = `$10`. `NOP $2000,X` (`$1C`) takes 4 cycles.
6. The test `single_step_undocumented_stable` runs all SingleStepTests 6502 cases of these opcodes: the 42 opcodes of `SLO`, `RLA`, `SRE`, `RRA`, `DCP` and `ISB` (Table 2), `LAX` (`$A3`, `$A7`, `$AF`, `$B3`, `$B7`, `$BF`), `SAX` (`$83`, `$87`, `$8F`, `$97`), `ANC` (`$0B`, `$2B`), `ASR` (`$4B`), `ARR` (`$6B`), `SBX` (`$CB`), `LAS` (`$BB`), `SBC` (`$EB`) and the 27 `NOP` opcodes in the Notes. The final registers, the RAM bytes and the `cycles` list agree with the file.

## Notes

HRM 3.5 lists `SAX` as $87, 8F, 97, 9F. Table 2 shows $83 as `SAX (zp,X)` and $9F as `SHA abs,Y`. This requirement uses Table 2. HRM 3.5 lists `ANC` as $0B only. Table 2 also shows $2B as `ANC`. This requirement uses Table 2. The HRM `NOP` list contains $4C, which is `JMP abs` in Table 2. The list does not contain $3A, $5C, $C2 and $E2, which Table 2 shows as `NOP`. This requirement uses Table 2: the `NOP` opcodes are $04, $0C, $14, $1A, $1C, $34, $3A, $3C, $44, $54, $5A, $5C, $64, $74, $7A, $7C, $80, $82, $89, $C2, $D4, $DA, $DC, $E2, $F4, $FA and $FC. The HRM shows stable and unstable opcodes by color, which the text copy does not show. This requirement treats as unstable the opcodes that have a warning in the HRM text and the opcodes in REQ-112.
