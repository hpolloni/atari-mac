# REQ-527: Serial clock modes

## Requirement

The emulator shall select the serial input clock, the serial output clock and the direction of the bidirectional clock line from `SKCTL` bits 4-6 as HRM Table 10 states. Each serial clock shall toggle on each fire of its timer.

## Rationale

The OS uses mode `001` or `011` to receive and mode `010` to send.

## Acceptance criteria

In criteria 1-4, `AUDCTL` = `$28`, `AUDF3` = `$28`, `AUDF4` = `$00` (timer 4 fires every 47 cycles) and `AUDF2` = `$00` (timer 2 fires every 28 cycles). Where SIO CLOCK IN is an input, the test toggles it every 100 cycles. Mode m is the value of `SKCTL` bits 6-4, and `SKCTL` = `$03` + `$10` x m.

1. A byte written to `SEROUT` goes out on SIO DATA OUT with a bit time of 94 cycles in modes `010` and `100`, 56 cycles in modes `110` and `111`, and 200 cycles in modes `000` and `001`.
2. In modes `011` and `101`, SIO CLOCK OUT does not change while SIO DATA IN stays at 1 for 10000 cycles. While a frame is received, SIO CLOCK OUT changes on each fire of timer 4.
3. A frame for `$43` makes `SERIN` read `$43` and `SKSTAT` bit 7 read 1 in these cases: in modes `000` and `100`, with a bit time of 200 cycles and bit changes on the changes of SIO CLOCK IN from 0 to 1; in modes `010` and `110`, with a bit time of 94 cycles and bit changes on the changes from 0 to 1 of the level that POKEY drives on SIO CLOCK IN; in modes `001`, `011`, `101` and `111`, with a bit time of 94 cycles and any start cycle.
4. In modes `010` and `110`, `serial_clock_in_drive()` returns a level that changes on each fire of timer 4. In the other 6 modes, it returns `None`.
5. In mode `000`, with SIO CLOCK IN held at one level for 10000 cycles after a `SEROUT` write, SIO DATA OUT and `IRQST` bit 4 do not change.
6. In mode `000`, SIO DATA OUT changes only on cycles on which SIO CLOCK IN changes from 0 to 1. The input shift register takes the SIO DATA IN level of the cycle on which SIO CLOCK IN changes from 1 to 0.
7. In mode `010`, with `AUDF3` = `$CC` and `AUDF4` = `$05` (timer 4 fires every 1491 cycles), the bit time on SIO DATA OUT is 2982 cycles.
8. For `AUDC3` = `AUDC4` = `$00`, `$1F`, `$8F` and `$AF`, criteria 1 and 7 give the same bit times.

## Notes

HRM Table 10:

| `SKCTL` bits 6-4 | Input clock | Output clock | Bidirectional clock |
| --- | --- | --- | --- |
| `000` | External | External | Input |
| `001` | Channel 3+4 (async) | External | Input |
| `010` | Channel 4 | Channel 4 | Output channel 4 |
| `011` | Channel 3+4 (async) | Channel 4 (async) | Input |
| `100` | External | Channel 4 | Input |
| `101` | Channel 3+4 (async) | Channel 4 (async) | Input |
| `110` | Channel 4 | Channel 2 | Output channel 4 |
| `111` | Channel 3+4 (async) | Channel 2 | Input |

The output clock drives SIO CLOCK OUT. The bidirectional clock line is SIO CLOCK IN. An external clock is the level of SIO CLOCK IN. The 810 disk drive ignores the clock lines. The fastest internal rate is 128 kbit/s.

The HRM states that the `AUDCTL` bits 0 and 3-6 change the serial clocks through the timers. Criterion 7 checks this for the timer period.
