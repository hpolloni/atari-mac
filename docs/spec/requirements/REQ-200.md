# REQ-200: Machine clock and color clock

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | System: clocks, memory map, bank switching, reset, PIA |
| Source | HRM 2.2 Clocks; HRM 3.3 Cycle timing (Clock speed); HRM 4.2 Display timing |
| Verification | Test |
| Depends on | None |

## Requirement

The emulator shall run the machine clock at 1.789773 MHz for NTSC and 1.773447 MHz for PAL, with the color clock at twice the machine clock for both standards.

## Rationale

The CPU and the memory bus run at the machine clock (HRM 2.2). Audio pitch, serial port speed and real-time speed depend on it.

## Acceptance criteria

1. The NTSC machine clock frequency of the emulator is 1,789,773 Hz, within 1 Hz.
2. The PAL machine clock frequency of the emulator is 1,773,447 Hz, within 1 Hz.
3. For both standards, one scan line has 114 machine cycles and 228 color clocks (2 color clocks for each machine cycle).
4. A machine created with the PAL standard in its configuration runs frames of 35,568 machine cycles. A machine created with the NTSC standard runs frames of 29,868 machine cycles (REQ-201).

## Notes

HRM 4.2 gives the master clocks as 14.31818 MHz and 14.18757 MHz, and the machine clock as the master clock divided by 8. For PAL, 14.18757 MHz / 8 is 1.7734463 MHz, but the HRM states 1.773447 MHz and 2/5 of the color subcarrier (HRM 3.3). The 1 Hz tolerance covers this rounding difference. On PAL, color pixels are produced at twice the machine clock, although the PAL color subcarrier is 4.43 MHz (HRM 2.2). The video standard does not change while the machine runs (project decision, see the system design).
