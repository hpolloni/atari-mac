# REQ-020: Pinned test data

## Requirement

The test harness shall download its test data from sources pinned to commits, and shall verify each file with a checksum.

## Rationale

Tests must use the same data on every computer.

## Acceptance criteria

1. Each URL in `scripts/fetch-roms.sh` contains a commit hash, except the HRM URL, which has a SHA-256 checksum.
2. When a downloaded file has a different checksum, the script deletes the file, prints `checksum mismatch` and exits with a status that is not 0.
3. `scripts/fetch-roms.sh --single-step` gives 256 files in `test-data/single-step/6502/`, each with the git blob SHA-1 in `scripts/single-step-6502.sha1`.
