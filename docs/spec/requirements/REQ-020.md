# REQ-020: Pinned test data

## Requirement

The test harness shall download its test data and the pinned references from sources pinned to commits or to archive snapshots, and shall verify each file with a checksum.

## Rationale

Tests must use the same data on every computer, and a change at a download site must not stop the tests.

## Acceptance criteria

1. Each URL in `scripts/fetch-roms.sh` contains a commit hash.
2. When a downloaded file has a different checksum, the script deletes the file, prints `checksum mismatch` and exits with a status that is not 0.
3. `scripts/fetch-roms.sh --single-step` gives 256 files in `test-data/single-step/6502/`, each with the git blob SHA-1 in `scripts/single-step-6502.sha1`.
4. `scripts/fetch-roms.sh` without `--references` downloads no reference. `make roms`, `make test`, `make pre-commit` and CI do not download a reference.
5. `scripts/fetch-roms.sh --references` (`make reference`) downloads each registry entry with the storage `pin` (REQ-046) from its `url` to its `file`, and verifies the file with its `sha256`, as in criterion 2.
