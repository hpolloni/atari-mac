# REQ-630: Put and Write sector

## Requirement

For Put (`$50`) and Write (`$57`) with a valid sector number and a write-enabled image, the disk drive shall receive a data frame of the sector size, put it into that sector of the image, and send ACK and then Complete.

## Rationale

DOS writes files with these commands. Put writes with no verify. Write also verifies the sector. For an image, both commands have the same result.

## Acceptance criteria

The test images are the SD and DD files of REQ-625 (data byte `i` holds `i & $FF`), write enabled. In each criterion, the computer sends the data frame and its checksum (REQ-616), and the drive sends `41`, then `41` after the data frame, and then `43`.

1. Put sector 400 of the SD image with 128 bytes of `$5A`. A Read of sector 400 then gives 128 bytes of `$5A`.
2. Write sector 400 of the SD image with 128 bytes of `$A5`. A Read of sector 400 then gives 128 bytes of `$A5`.
3. DD image: Put sector 2 with 128 bytes of `$5A` gets `41`, `41`, `43`, and a Read of sector 2 then gives 128 bytes of `$5A`. Put sector 10 with 256 bytes of `$5A` gets `41`, `41`, `43`, and a Read of sector 10 then gives 256 bytes of `$5A`.
4. Before a Put, the image reports no change. After the Put of criterion 1, the image reports a change (REQ-637).
5. After criterion 1, the export of the image (REQ-637) is equal to the input file in all bytes except file bytes 51,088 to 51,215 (sector 400).

## Notes

Write takes one more disk revolution than Put on a real drive. REQ-638 gives this time.
