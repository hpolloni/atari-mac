# REQ-044: Requirement structure

## Requirement

Each requirement file that is not withdrawn shall have the sections `Requirement`, `Rationale` and `Acceptance criteria` in this order, a requirement statement with the word `shall`, and at least one numbered acceptance criterion.

## Rationale

A fixed structure makes each requirement complete and lets the gates find each part.

## Acceptance criteria

1. A file without one of the three sections, or with the sections in another order, makes the check fail.
2. A requirement statement without the word `shall` makes the check fail.
3. An `Acceptance criteria` section without a line that starts with `1. ` makes the check fail.
4. A section heading other than `Requirement`, `Rationale`, `Acceptance criteria` and `Notes` makes the check fail.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
