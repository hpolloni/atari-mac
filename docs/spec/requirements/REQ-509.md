# REQ-509: Distortion selection

## Requirement

On each fire of its timer, the emulator shall change the output flip-flop of a channel as `AUDCx` bits 5-7 select: toggle it for a pure tone, or copy the 4-bit or 9/17-bit noise bit. When bit 7 is 0, it shall ignore the fires that the 5-bit noise generator masks.

## Rationale

The distortion modes give the noise and tone effects of almost all Atari games.

## Acceptance criteria

In criteria 1-6, `AUDF3` = `$00`, an `STIMER` write starts the timers, and timer 3 fires every 4 cycles. "Output" is the channel 3 digital output (test accessor).

1. With `AUDCTL` = `$20` and `AUDC3` = `$AF`, the output changes on each fire of timer 3 and on no other cycle.
2. With `AUDCTL` = `$20` and `AUDC3` = `$CF`, the outputs after 15 consecutive fires contain 7 ones and 8 zeros. The sequence of outputs after the fires repeats with a period of 15 fires.
3. With `AUDCTL` = `$A0` and `AUDC3` = `$8F`, the sequence of outputs after the fires repeats with a period of 511 fires and has 255 ones in each period.
4. With `AUDCTL` = `$20` and `AUDC3` = `$8F`, the sequence of outputs after the fires repeats with a period of 131071 fires and has 65535 ones in each period.
5. With `AUDCTL` = `$20` and `AUDC3` = `$2F`, the output changes on exactly 15 of each 31 consecutive fires. The pattern of changes repeats with a period of 31 fires.
6. With `AUDCTL` = `$20` and `AUDC3` = `$0F` or `$4F`, the output changes only on fires on which the output changes in criterion 5 (the fires that the 5-bit generator lets through). The test runs criterion 5 and criterion 6 from the same `SKCTL` write cycle and the same `STIMER` write cycle.
7. With `AUDCTL` = `$28`, `AUDF3` = `$28`, `AUDF4` = `$00`, `SKCTL` = `$23` and `IRQEN` = `$04`, the cycles on which `IRQST` bit 2 goes to 0 and the cycles on which SIO CLOCK OUT changes are the same for each of the 8 values of `AUDC4` bits 7-5.

## Notes

Table 8 of the HRM:

| `AUDCx` bits 7-4 | Output |
| --- | --- |
| `0000` | Poly-5 masked poly-9/17 |
| `0010`, `0110` | Poly-5 masked square wave |
| `0100` | Poly-5 masked poly-4 |
| `1000` | Poly-9/17 |
| `1010`, `1110` | Square wave |
| `1100` | Poly-4 |
| `xxx1` | Volume-only (REQ-510) |

The digital output of a channel is the on/off signal before the volume DAC (HRM E.2).

The HRM does not state which level of the 5-bit generator lets a fire through. The project decision is: a fire goes through when the 5-bit bit is 1. The 5-bit pattern has 15 ones in 31 bits, so criterion 5 uses this decision. With the other level, the result is 16 of 31. A period of 4 cycles is relatively prime to 15, 31, 511 and 131071, so criteria 2-5 sample all bits of each pattern. The counts of ones in criteria 2-4 follow from HRM 5.5: each pattern has one more 0 bit than 1 bits.
