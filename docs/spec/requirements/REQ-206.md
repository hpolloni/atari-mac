# REQ-206: Writes to ROM areas

## Requirement

The emulator shall ignore a write to an address that shows OS ROM, BASIC ROM, self-test ROM or cartridge ROM, and shall not change the RAM under it.

## Rationale

The MMU maps addresses only by address. It is not possible to write through the ROM (HRM 2.6).

## Acceptance criteria

1. RAM at `$E000` = `$AA`. `PORTB` pins = `$FF` (OS ROM on). The CPU writes `$55` to `$E000`. Then `PORTB` pins = `$FE` (OS ROM off). A CPU read of `$E000` returns `$AA`.
2. RAM at `$A000` = `$AA`, a BASIC image in the configuration. `PORTB` pins = `$FD` (BASIC on). The CPU writes `$55` to `$A000`. Then `PORTB` pins = `$FF` (BASIC off). A CPU read of `$A000` returns `$AA`.
3. RAM at `$B000` = `$AA`, a cartridge that shows ROM at `$A000-$BFFF`. The CPU writes `$55` to `$B000`. RAM at `$B000` is still `$AA`, and a CPU read of `$B000` returns the cartridge byte.
4. RAM at `$5000` = `$AA`. `PORTB` pins = `$7F` (self-test on). The CPU writes `$55` to `$5000`. RAM at `$5000` is still `$AA`, and a CPU read of `$5000` returns OS image byte `$1000`.
5. RAM at `$8000` = `$77`, a 16 KB cartridge (ROM at `$8000-$BFFF`). The CPU writes `$00` to `$8000`. RAM at `$8000` is still `$77`, and a CPU read of `$8000` returns the cartridge byte.
6. RAM at `$A000` = `$00`, a test cartridge with RD5 inactive, `PORTB` pins = `$FF` (BASIC off). The CPU writes `$33` to `$A000`. RAM at `$A000` is `$33`, because no ROM shows there.
