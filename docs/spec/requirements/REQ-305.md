# REQ-305: Display list region and vertical blank

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | ANTIC |
| Source | HRM 4.6 Display list (Valid display list range); HRM 4.13 Player/missile DMA (P/M DMA timing) |
| Verification | Test |
| Depends on | REQ-304 |

## Requirement

The emulator shall run the display list only on scan lines 8 to 247, suspend it at the start of scan line 248, and resume it on scan line 8 of the next frame.

## Rationale

A display list can have a maximum of 240 scan lines, for NTSC and for PAL. Scan lines 248 to the end of the frame and scan lines 0 to 7 are vertical blank.

## Acceptance criteria

1. With `DMACTL` = `$3E` and a display list that fills scan lines 8-247 with mode E lines, `out.dma` is `Refresh` or `None` on every cycle of scan lines 0-7 and 248-261 (NTSC) or 248-311 (PAL).
2. The display list is 29 × `$70`, `$30`, `$82`. The `$82` mode line starts on scan line 244. With `NMIEN` = `$C0`, `NMIST` bit 7 stays 0 on scan lines 244-247, and the only `out.nmi` in the frame is the VBI on scan line 248.
3. A display list at `$1000` is 59 × `$70`, `$60`, `$01 $00 $10` (480 scan lines). The test writes `DLISTL`/`DLISTH` = `$1000` once, in vertical blank. The instruction fetch on scan line 8 reads `$1000` in the next frame, `$101E` in the frame after that, and `$1000` again in the third frame.
4. The test writes `DLISTL`/`DLISTH` = `$1234` on scan line 0. No display list fetch occurs on scan lines 0-7. The instruction fetch on cycle 1 of scan line 8 reads `$1234`.
5. With IR = `$41` at scan line 248, every `video` code on scan lines 0-7 and 248 to the last scan line is `%001`, `%010` or `%011` (no playfield and no background code, see REQ-306).
