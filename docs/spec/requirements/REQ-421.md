# REQ-421: P/M to player collisions

## Requirement

The emulator shall set bit m of `PnPL` and bit n of `PmPL` when players n and m (n not equal to m) are active at the same color clock, and bit m of `MnPL` when missile n and player m are active at the same color clock.

## Rationale

Games use these registers for hit tests between sprites.

## Acceptance criteria

In all criteria, the objects overlap on background pixels in HPOS `$22-$DD` of scanlines 8-247, the collision registers are clear before the test (`HITCLR`), and all collision registers that the criterion does not name read `$00` after the frame.

1. Players 0, 1 and 2 at the same pixels set `P0PL` = `$06`, `P1PL` = `$05`, `P2PL` = `$03` and `P3PL` = `$00`.
2. Missile 2 on player 3 sets `M2PL` = `$08`.
3. Missiles 0 and 1 at the same pixels, with no player, set no collision bit.
4. Player 0 alone sets no collision bit (`P0PL` = `$00`).
5. With `COLPM0` = `COLPM1` = `$46`, players 0 and 1 at the same pixels set `P0PL` = `$02` and `P1PL` = `$01`.
