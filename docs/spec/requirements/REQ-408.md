# REQ-408: High resolution playfield colors

## Requirement

When the last horizontal blank code was `%011` and `PRIOR` bits 6-7 are `%00`, the emulator shall show each code `%1xx` as two half color clock pixels that use the `COLPF2` layer, with the luminance of `COLPF1` where the pixel bit is 1.

## Rationale

ANTIC modes 2, 3 and F (GRAPHICS 0 and 8) use this mode. The OS text screen uses mode 2.

## Acceptance criteria

In all criteria, `COLBK` = `$02`, `COLPF1` = `$CA`, `COLPF2` = `$94`, the last horizontal blank code is `%011` and `PRIOR` = `$00`, except where the criterion states other values.

1. With an ANTIC mode F line at normal width, `HSCROL` = 0 and first byte `$AA`, the columns for HPOS `$30-$33` (columns 32-39) are `$9A`, `$94`, `$9A`, `$94`, `$9A`, `$94`, `$9A`, `$94`.
2. In a GTIA unit test, code `%101` at HPOS `$40` gives `$94` in column 64 and `$9A` in column 65. Code `%110` at HPOS `$41` gives `$9A` in column 66 and `$94` in column 67. Code `%111` gives `$9A` in both columns. Code `%100` gives `$94` in both columns.
3. With `PRIOR` = `$01`, `COLPM0` = `$46` and player 0 on code `%110`, the left column is `$4A` and the right column is `$46`.
4. With `PRIOR` = `$04` (playfield over players), `COLPM0` = `$46` and player 0 on code `%100`, both columns are `$94`.
5. Code `%000` gives `$02` in both columns.
6. After the horizontal blank code `%010`, code `%101` gives `$CA` in both columns and code `%110` gives `$94` in both columns.

## Notes

The left-pixel order comes from the caption of HRM Figure 14: "%101 (off+on hires pixels)". The priority logic sees `PF2` for all of the hires playfield. The luminance change is applied after the priority logic, on top of players, missiles and the fifth player.
