# REQ-204: 64 KB RAM

## Requirement

The emulator shall have 64 KB of RAM at `$0000-$FFFF`, visible at each address where no ROM and no hardware register is mapped.

## Rationale

The 65XE has 64 KB of RAM. With all ROMs disabled, 62 KB of RAM is available (HRM 2.6).

## Acceptance criteria

1. `PORTB` pins = `$FE` (OS ROM, BASIC and self-test off), no cartridge. For each address outside `$D000-$D7FF`, a CPU write of `$A5` and then a CPU read give `$A5`. A CPU write of `$5A` and then a CPU read give `$5A`.
2. `PORTB` pins = `$7D` (OS ROM, BASIC and self-test on), an 8 KB cartridge at `$A000-$BFFF`. For each address in `$0000-$4FFF`, `$5800-$7FFF` and `$8000-$9FFF`, a CPU write and then a CPU read give the written value.
