# REQ-302: ANTIC reset behavior

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | ANTIC |
| Source | HRM 4.1 Basic operation (Reset behavior) |
| Verification | Test |
| Depends on | REQ-301 |

## Requirement

The emulator shall clear `NMIEN`, `DMACTL` and the playfield DMA clock when ANTIC receives a power-on reset or a RESET key reset, and shall keep all other ANTIC state unchanged.

## Rationale

On XL/XE hardware, the RESET key also resets ANTIC (HRM 4.1). The OS warm start then starts with DMA and NMIs off.

## Acceptance criteria

1. ANTIC runs a display list of mode 2 lines with DLI bits set, with `NMIEN` = `$C0` and `DMACTL` = `$3E`. The test calls the reset on scan line 100, cycle 50. For the rest of that frame and all of the next frame, `out.dma` is `Refresh` or `None` on every cycle, and `out.nmi` is never set.
2. Directly after the reset in criterion 1, the debug state shows `DMACTL` = `$00`, `NMIEN` = `$00` and a playfield DMA clock of 0.
3. Before a reset on scan line 100, cycle 50, the test writes `HSCROL` = `$05`, `VSCROL` = `$03`, `PMBASE` = `$30`, `CHBASE` = `$E0`, `CHACTL` = `$02` and `DLISTL`/`DLISTH` = `$3000`, and latches the light pen on scan line 64, cycle 32. After the reset, the debug state shows the same `HSCROL`, `VSCROL`, `PMBASE`, `CHBASE`, `CHACTL`, display list address, memory scan counter and refresh row counter as before the reset. Reads of `PENH`, `PENV` and `NMIST` return the same values as before the reset.
4. ANTIC is at scan line 128, cycle 50. The test calls the reset. Then `scanline()` returns 128, `cycle()` returns 50, and a read of `VCOUNT` returns `$40`.
5. A write to `WSYNC` on cycle 50 of scan line 100 is followed by a reset before the tick of cycle 52. `out.rdy` is `false` on cycles 52 to 104 and `true` on cycle 105.

## Notes

On the 400/800, only power-on resets ANTIC. This does not apply to the 65XE.

HRM 4.1 also lists the pending reset NMI (RNMI) as an item that a reset keeps. The 65XE does not connect the RNMI input (HRM 4.8), and the design does not model it. Thus no criterion checks it.

In the full machine, the System Reset button calls the ANTIC reset (REQ-217).
