# REQ-528: Asynchronous receive mode

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | POKEY: audio, timers, keyboard, interrupts, serial port |
| Source | HRM 5.6 Serial port (Asynchronous receive mode; Shift timing; Figure 10) |
| Verification | Test |
| Depends on | REQ-526, REQ-527 |

## Requirement

When `SKCTL` bit 4 is 1, the emulator shall hold timers 3 and 4 in reset while the serial input waits for a start bit, start them at the falling edge of the start bit, sample the start bit one timer 4 period later and each next bit two periods later, and hold them again after the stop bit.

## Rationale

Serial input from disk drives is not reliable without asynchronous mode. The mode also makes the typical tone of disk loads on channel 4.

## Acceptance criteria

In all criteria, `SKCTL` = `$13`, `AUDCTL` = `$28`, `AUDF3` = `$28` and `AUDF4` = `$00`. The frames are those of REQ-526, with the start edge on cycle S.

1. With `IRQEN` = `$04` and SIO DATA IN at 1 for 10000 cycles, timers 3 and 4 do not fire, and `IRQST` bit 2 reads 1.
2. After a start edge on cycle S, the first fire of timer 4 is on a cycle from S+39 to S+55. The next fires are 47 cycles apart.
3. For each received byte, timer 4 fires 19 times from cycle S to the cycle on which `IRQST` bit 5 goes to 0 (with `IRQEN` = `$20`). Timer 4 does not fire after that cycle until the next start edge.
4. Frames for `$43` and `$A5` with a bit time of 91 cycles, and again with a bit time of 97 cycles, make `SERIN` read the sent value and `SKSTAT` bit 7 read 1.
5. With SIO DATA IN at 1 and `AUDC3` = `AUDC4` = `$AF`, the channel 3 and channel 4 digital outputs do not change for 10000 cycles. With `AUDC3` = `$1F` and `AUDC1` = `AUDC2` = `AUDC4` = `$00`, the mix level is 15.

## Notes

Figure 10 of the HRM shows that `SERIN`, `IRQST` bit 5 and the `SKSTAT` error bits update when the stop bit is sampled, 19 timer periods (9.5 bits) after the start edge.

The bit times in criterion 2 differ from 94 cycles by about 3 %. This is a project decision for the test.
