# REQ-328: Vertical scrolling

## Requirement

The emulator shall start the row counter at `VSCROL` for a mode line that has IR bit 5 set after a mode line with bit 5 clear, and shall end a mode line that has bit 5 clear after a mode line with bit 5 set when its row counter equals `VSCROL`.

## Rationale

Many games use fine vertical scrolling. Numen uses the 4-bit row counter to make mode F lines four scan lines high (HRM 4.16).

## Acceptance criteria

1. With `VSCROL` = 3, the instructions `$22`, `$22`, `$02` follow a mode line with bit 5 clear. They start on scan line N. The instruction fetches occur on scan lines N, N + 5 and N + 13, and the next instruction fetch occurs on scan line N + 17 ((8 - 3) + 8 + (3 + 1) = 17).
2. In criterion 1, the second `$22` line has rows 0-7 (it neither starts nor ends the region).
3. A write of `$F3` to `VSCROL` gives the same result as a write of `$03` (bits 7-4 have no effect).
4. With `VSCROL` = 13, a `$2F` line after a mode line with bit 5 clear has rows 13, 14, 15 and 0 (4 scan lines). `Bitmap` DMA occurs only on its first scan line, and the next instruction fetch occurs 4 scan lines after its instruction fetch.
5. With `VSCROL` = 2, a `$70` line after a `$22` line has 3 scan lines (rows 0-2). With `VSCROL` = 4, a `$70` line after a `$02` line has 8 scan lines. With `VSCROL` = 2, a jump `$01` after a `$22` line has 3 scan lines.
6. With `DMACTL` = `$02` (display list DMA off), IR = `$22` and `VSCROL` = 4, the mode 2 line that starts on scan line 8 has 8 scan lines (rows 0-7), because ANTIC keeps bit 5 of the mode line before vertical blank.

## Notes

Example of criterion 6: if every mode line has bit 5 set, no line starts or ends a region, so no scrolling occurs. Chicken ends a scrolled region with a blank line (HRM 4.16).

TRN HW-III.D/VSCROL and ANTIC-SPEC 7.2 show only bits 2-0 of `VSCROL` for the 8-line modes, and bits 3-0 for the 16-line modes. The HRM says that `VSCROL` and the row counter are 4-bit counters in all modes. This requirement follows the HRM. ACID800 antic_vscroll also uses `VSCROL` values above 7 with mode 2 lines.
