# REQ-010: Joystick input

## Requirement

The frontend shall map host keys to joystick 1: the arrow keys to the four directions and Left Alt (Option) to the trigger.

## Rationale

Most games need a joystick.

## Acceptance criteria

1. A unit test of the frontend key map checks that Up, Down, Left and Right give the joystick 1 directions, and Left Alt gives the joystick 1 trigger.
2. With Up and Left held, `JoystickState` has `up` and `left` set, and no other field set.

## Notes

Game controller support is a Could requirement for a later version.
