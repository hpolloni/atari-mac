# REQ-424: Priority logic

## Requirement

The emulator shall select the visible layers at each color clock with the priority equations of HRM 6.7 and output the bitwise OR of the color registers of the selected layers, or `$00` when no layer is selected.

## Rationale

`PRIOR` bits 0-3 set which of the players and playfields show on top. Games use all four standard modes.

## Acceptance criteria

In criteria 2-8, `COLPM0-3` = `$12`, `$24`, `$36`, `$48`, `COLPF0-3` = `$5A`, `$6C`, `$7E`, `$80` and `COLBK` = `$92`. Each criterion uses one color clock with only the stated objects and playfield.

1. A unit test evaluates the equations in the Notes in the test code, for all 64 values of `PRIOR` bits 0-5 and all 512 combinations of the inputs `P0-P3`, `PF0-PF3` and "any missile". The inputs are: `P0-P3` = player n, or missile n when `PRIOR` bit 4 = 0. `PF3` = playfield 3, or any missile when `PRIOR` bit 4 = 1. `PRI0-PRI3` = `PRIOR` bits 0-3 and `MULTI` = `PRIOR` bit 5. For each case with `PRIOR` bit 4 = 0, the color byte of GTIA is the OR of `COLPM0-3`, `COLPF0-3` and `COLBK` for the true outputs `SP0-SP3`, `SF0-SF3` and `SB`, or `$00` when no output is true.
2. With `PRIOR` = `$01`, player 0 on `PF0` shows `$12`.
3. With `PRIOR` = `$04`, player 0 on `PF0` shows `$5A`.
4. With `PRIOR` = `$08`, player 0 on `PF2` shows `$12`, and player 0 on `PF0` shows `$5A`.
5. With `PRIOR` = `$02`, player 0 on `PF0` shows `$12`, and player 2 on `PF1` shows `$6C`.
6. With `PRIOR` = `$01`, players 0 and 1 at the same color clock show `$12`.
7. With `PRIOR` = `$01`, missile 2 on `PF0` shows `$36`.
8. With no object and no playfield, the color clock shows `$92`.

## Notes

The equations are: `SP0 = P0 * /(PF01*PRI23) * /(PRI2*PF23)`, `SP1 = P1 * /(PF01*PRI23) * /(PRI2*PF23) * (/P0 + MULTI)`, `SP2 = P2 * /P01 * /(PF23*PRI12) * /(PF01*/PRI0)`, `SP3 = P3 * /P01 * /(PF23*PRI12) * /(PF01*/PRI0) * (/P2 + MULTI)`, `SF0 = PF0 * /(P23*PRI0) * /(P01*PRI01) * /SF3`, `SF1 = PF1 * /(P23*PRI0) * /(P01*PRI01) * /SF3`, `SF2 = PF2 * /(P23*PRI03) * /(P01*/PRI2) * /SF3`, `SF3 = PF3 * /(P23*PRI03) * /(P01*/PRI2)`, `SB = /P01 * /P23 * /PF01 * /PF23`. `PRI01 = PRI0 + PRI1`, `PRI12 = PRI1 + PRI2`, `PRI23 = PRI2 + PRI3`, `PRI03 = PRI0 + PRI3`. `P01 = P0 + P1`, `P23 = P2 + P3`, `PF01 = PF0 + PF1`, `PF23 = PF2 + PF3`. The HRM uses `*` for AND, `+` for OR and `/` for NOT.
