# REQ-081: Boot a tape image from the command line

## Requirement

When the command line has `--cas <file>`, the emulator shall insert the CAS tape image in the cassette deck and hold START at the power-on cold reset, so that the OS asks for the tape, and shall press no other key.

## Rationale

The user wants to load a boot-tape game from a `.cas` file. On the real computer, the user holds START at power-on, presses PLAY, and presses a key after the tone. The emulator always has PLAY pressed and holds START for the user. The user presses RETURN after the tone, as on the real computer (OI-050).

## Acceptance criteria

The boot test tape is the tape of REQ-643.

1. `atari-mac --headless --frames 1 --cas <file>` exits with status 0 for the boot test tape.
2. A file of 100 bytes of `$00` gives exit code 2 before the machine starts, and a message on standard error that names the file and the error `CasSignature` (REQ-640). A file that does not exist or cannot be read gives exit code 2 and a message that names the file.
3. With `--cas`, the emulator holds START from the power-on cold reset until frame 60. It does not press OPTION, RETURN or any other key, so BASIC stays on.
4. With the boot test tape and `--cas`, a test presses RETURN from frame 180 to frame 186 (NTSC) or from frame 150 to frame 156 (PAL), as the user does. Then `$0600` holds `$A5` within 2,400 frames (NTSC) and within 2,000 frames (PAL) after the start.
5. `--help` lists `--cas <file>`.
6. `--cas` together with `--bas` gives exit code 2 and a message that names both options.

## Notes

Project decision: a rule of the macOS frontend. The HRM does not cover it.

The key presses (criterion 3) are the decision of OI-050 (option 2, decided by the user on 2026-11-20). BASIC stays on. A tape that needs BASIC off needs OPTION at the cold reset: the user holds F2 (START) and F4 (OPTION) and presses F10 (FAQ 1.7: "With no cartridge and without BASIC: Hold down both [START] and [OPTION] while turning on the computer"). The test program of REQ-643 does not need BASIC, so criterion 4 passes with BASIC on.

The option name `--cas` is a project decision. The load speed in the window is REQ-082 (OI-051).

The README options table gets the row for `--cas` when the help text has the option: the README gate (REQ-056 criterion 6) rejects an option that `--help` does not list.
