# REQ-081: Boot a tape image from the command line

## Requirement

When the command line has `--cas <file>`, the emulator shall insert the CAS tape image in the cassette deck, hold START and OPTION at the cold reset, and press RETURN after the OS prompt tone, so that the OS boots the tape with no action of the user.

## Rationale

The user wants to load a boot-tape game from a `.cas` file. On the real computer, the user holds START at power-on, presses PLAY, and presses a key after the tone. The emulator always has PLAY pressed, and it does the key presses for the user.

## Acceptance criteria

The boot test tape is the tape of REQ-643.

1. `atari-mac --headless --frames 1 --cas <file>` exits with status 0 for the boot test tape.
2. A file of 100 bytes of `$00` gives exit code 2 before the machine starts, and a message on standard error that names the file and the error `CasSignature` (REQ-640). A file that does not exist or cannot be read gives exit code 2 and a message that names the file.
3. With `--cas`, the emulator holds START and OPTION from the cold reset until frame 60, and presses RETURN from frame 180 to frame 186 (NTSC) or from frame 150 to frame 156 (PAL). No other key is pressed by the emulator.
4. With the boot test tape, `$0600` holds `$A5` within 2,400 frames (NTSC) and within 2,000 frames (PAL) after the start.
5. `--help` lists `--cas <file>`.
6. `--cas` together with `--bas` gives exit code 2 and a message that names both options.

## Notes

Project decision: a rule of the macOS frontend. The HRM does not cover it.

The automatic key presses (criterion 3) are the recommended option of OI-050, which is open. With OPTION held at the cold reset, the XL/XE OS disables BASIC (FAQ 1.7: "With no cartridge and without BASIC: Hold down both [START] and [OPTION] while turning on the computer"). The test program of REQ-643 does not need BASIC, so criterion 4 passes with BASIC off and with BASIC on.

The option name `--cas` is a project decision. The emulator loads the tape at real-time speed. A load acceleration is open (OI-051).

The README options table gets the row for `--cas` when the help text has the option: the README gate (REQ-056 criterion 6) rejects an option that `--help` does not list.
