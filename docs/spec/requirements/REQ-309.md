# REQ-309: Playfield DMA fetch timing

## Requirement

The emulator shall do playfield DMA on the cycles in the table below, when horizontal scrolling is off.

| Modes | Fetch | Interval | First cycle: narrow / normal / wide | Fetches: narrow / normal / wide |
| --- | --- | --- | --- | --- |
| 2-5 | Character name | 2 cycles | 26 / 18 / 10 | 32 / 40 / 48 |
| 6-7 | Character name | 4 cycles | 26 / 18 / 10 | 16 / 20 / 24 |
| 2-7 | Character data | Same as name | Name cycle + 3 | Same as name |
| D-F | Bitmap data | 2 cycles | 28 / 20 / 12 | 32 / 40 / 48 |
| A-C | Bitmap data | 4 cycles | 28 / 20 / 12 | 16 / 20 / 24 |
| 8-9 | Bitmap data | 8 cycles | 28 / 20 / 12 | 8 / 10 / 12 |

## Rationale

Playfield DMA sets the CPU speed and the timing of DLI handlers. Many programs depend on exact cycle counts.

## Acceptance criteria

1. With `DMACTL` = `$22`, on the first scan line of a mode E line, `out.dma` is `Bitmap` on cycles 20, 22, ..., 98 (40 cycles) and on no other cycles.
2. With `DMACTL` = `$22`, on the first scan line of a mode 2 line, `out.dma` is `CharacterName` on cycles 18, 20, ..., 96 and `CharacterData` on cycles 21, 23, ..., 99.
3. On scan lines 2-8 of the same mode 2 line, `out.dma` is `CharacterData` on cycles 21, 23, ..., 99, and never `CharacterName`.
4. With `DMACTL` = `$21`, on the first scan line of a mode 8 line, `out.dma` is `Bitmap` on cycles 28, 36, ..., 84 (8 cycles) and on no other cycles.
5. For each IR mode 2-F and each `DMACTL` width (`$21`, `$22` and `$23`), the first scan line has its name or bitmap fetches on the cycles F + k × I, for k = 0 to N - 1. F, I and N are the first cycle, the interval and the number of fetches in the table. In modes 2-7, a character data fetch occurs 3 cycles after each name fetch. The fetches on cycle 105 or earlier set `out.halt`. The fetches on cycle 106 or later do not set `out.halt` (REQ-311).
6. For each IR mode and width of criterion 5, the memory scan counter after the mode line is the LMS address plus N.

## Notes

The HRM 4.14 DMA timing charts (PDF pages 90-96) confirm the start cycles, rates and fetch counts of this requirement (OI-006). The fetch window is 64, 80 or 96 cycles for narrow, normal or wide (HRM 4.14). Fetches on cycle 106 or later are virtual (REQ-311).
