# REQ-635: Write Percom block

## Requirement

In reply to Write Percom block (`$4F`) with a 12-byte data frame that gives the SD, ED or DD geometry of REQ-634, the disk drive shall keep that geometry for the next Format `$21`, and shall send Complete.

## Rationale

DOS versions that support double density write the Percom block to select the format of the next Format command.

## Acceptance criteria

The test image is the SD file of REQ-625, write enabled. The computer sends each block with its checksum (REQ-616).

1. Write Percom block with the DD block of REQ-634: the drive sends `41`, receives the block, sends `41`, then `43`. The next Format `$21` gives an image of 720 sectors, with 128-byte sectors 1-3 and 256-byte sectors 4-720.
2. Write Percom block with the DD block, then Write Percom block with the SD block of REQ-634, then Format `$21`: the image has 720 sectors of 128 bytes.
3. Write Percom block with the block `50 00 00 12 00 04 01 00 FF 00 00 00` (80 tracks): the drive sends `41`, receives the block, sends `41`, then `45`. The next Format `$21` gives an image of 720 sectors of 128 bytes.
4. After the Write Percom block of criterion 1, and before the Format, the image is unchanged: it has 720 sectors of 128 bytes, its sectors hold the same bytes, and it reports no change (REQ-637).
5. Write Percom block with the DD block, then insertion of the SD file again, then Format `$21`: the image has 720 sectors of 128 bytes.
6. Write Percom block with the DD block with byte 1 (step rate) changed to `$03` and byte 8 (drive present) changed to `$00`: the drive sends `41`, `41`, `43`. The next Format `$21` gives the DD geometry of criterion 1.

## Notes

The drive compares only the tracks, sectors per track, sides, density and sector size fields (criterion 6).

REQ-632 gives that Format `$21` uses only a kept DD geometry. Thus a kept ED geometry has no effect on Format `$21`. To decide: whether Format `$21` after a Write Percom block with the ED block gives ED or SD. The HRM states that drives check different fields and that some drives return Error for a geometry that they do not support.
