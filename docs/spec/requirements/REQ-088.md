# REQ-088: Monitor stop and step

## Requirement

The emulator shall have a monitor that stops the emulation between two CPU instructions, steps one instruction or one frame, and continues the emulation.

## Rationale

The user must stop the machine at an exact point and look at its state.

## Acceptance criteria

1. The user opens the monitor while the emulation runs (OI-057). The emulation stops before the next CPU instruction, and the monitor shows the next instruction line in the format of REQ-086 criterion 1.
2. The command `s` (step) runs one CPU instruction, with the DMA cycles before it, and shows the next instruction line.
3. The command `f` (frame) runs until the first instruction of the next frame and shows its line.
4. The command `g` (go) continues the emulation in real time.
5. After the same key input, a run with stops and steps gives the same frame buffer and the same RAM as a run without stops at the same machine cycle.
6. While the monitor is open, the emulated machine does not run, and the audio is silent. This is not an underrun (REQ-011).
