# REQ-621: Complete and Error delay

## Requirement

A disk drive shall start the Complete (`$43`) or Error (`$45`) byte at least 250 µs after the end of the ACK byte before it.

## Rationale

The OS needs time to read the ACK byte and to prepare for the next byte. The HRM states that this delay is dead time, from the end of the ACK byte to the start of the result byte.

## Acceptance criteria

1. For Status, Read sector 1 and Put sector 1 of the SD test image of REQ-619, the start bit of the Complete byte `43` begins at least 448 machine cycles (NTSC) or 444 machine cycles (PAL) after the end of the stop bit of the ACK byte before it. For Put, this is the second ACK byte (the ACK of the data frame).
2. For Read sector 1 with no image in D1: (REQ-633), the start bit of the Error byte `45` begins at least 448 machine cycles (NTSC) or 444 machine cycles (PAL) after the end of the stop bit of the ACK byte.
3. Criteria 1 and 2 pass for NTSC and for PAL.

## Notes

The cycle counts are 250 µs at the CPU clocks in REQ-618, rounded up.
