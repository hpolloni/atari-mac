# REQ-222: Port B read

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | System: clocks, memory map, bank switching, reset, PIA |
| Source | HRM 2.5 Peripheral Interface Adapter (PIA) (I/O direction, Floating inputs); HRM 2.6 Bank switching (ROM control) |
| Verification | Test |
| Depends on | REQ-219 |

## Requirement

For a read of the port B data register, the emulator shall return the output register value for output bits, 1 for input bits 0, 1 and 7, and the floating value of REQ-223 for input bits 2-6.

## Rationale

A port B output bit always reads back the output state (HRM 2.5). Software reads `PORTB` to check the memory configuration.

## Acceptance criteria

1. `PBCTL` = `$3C`, `DDRB` = `$FF`, port B output register = `$FD`. A read of `PORTB` returns `$FD`.
2. After a PIA reset and a write of `$04` to `PBCTL`, a read of `PORTB` returns `$83` (bits 0, 1 and 7 = 1, bits 2-6 = 0).
3. `PBCTL` = `$3C`, `DDRB` = `$FF`, port B output register = `$00`. A read of `PORTB` returns `$00`: the pull-ups on bits 0, 1 and 7 do not change output bits.
4. The floating value of bits 2-6 is tested in REQ-223.
