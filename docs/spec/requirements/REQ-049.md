# REQ-049: Test plans match the code

## Requirement

When the work package of a requirement is `Done`, each test that the design test plan names for that requirement shall exist in the code with a `Verifies` comment for that requirement, and each test that names the requirement shall be in its test plan.

## Rationale

Traceability must work in both directions: from the requirement to the test, and from the test to the requirement.

## Acceptance criteria

1. For a `Done` package, a test named in the test plan that does not exist as a `#[test]` function makes the check fail.
2. For a `Done` package, a named test without a `Verifies` comment for the requirement makes the check fail.
3. A test with a `Verifies` comment for a requirement whose test plan does not name the test makes the check fail.
4. The check identifies a test by its file and its function name.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
