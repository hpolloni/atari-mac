# REQ-049: Test plans match the code

## Requirement

Each test that the design test plan names for a requirement shall exist in the code as a `#[test]` function with a `Verifies` comment for that requirement, and each test that names the requirement shall be in its test plan. Until the work package of the requirement is `Done`, the test can be ignored (REQ-027).

## Rationale

Traceability must work in both directions: from the requirement to the test, and from the test to the requirement.

## Acceptance criteria

1. A test named in the test plan that does not exist as a `#[test]` function makes the check fail. This applies to all packages, also to packages that are not `Done`.
2. A named test without a `Verifies` comment for the requirement makes the check fail.
3. A test with a `Verifies` comment for a requirement whose test plan does not name the test makes the check fail.
4. The check identifies a test by its file and its function name.
