# REQ-220: Port A read

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | System: clocks, memory map, bank switching, reset, PIA |
| Source | HRM 2.5 Peripheral Interface Adapter (PIA) (I/O direction); HRM 2.9 Examples (Caverns of Mars) |
| Verification | Test |
| Depends on | REQ-219, REQ-221 |

## Requirement

For a read of the port A data register, the emulator shall return the external pin level for input bits, and the AND of the output register and the external pin level for output bits.

## Rationale

A port A output bit reads as 0 if the PIA or an external device pulls the line low (HRM 2.5). Caverns of Mars sets the upper four bits to output 0 and fails if the read does not show this (HRM 2.9).

## Acceptance criteria

1. `PACTL` = `$3C`, `DDRA` = `$F0`, port A output register = `$00`, all external pins high. A read of `PORTA` returns `$0F`.
2. `PACTL` = `$3C`, `DDRA` = `$F0`, port A output register = `$F0`, an external device pulls bit 4 low. A read of `PORTA` returns `$EF`.
3. `PACTL` = `$3C`, `DDRA` = `$00`, an external device pulls bit 2 low. A read of `PORTA` returns `$FB`.
