# REQ-110: Klaus Dormann functional test

## Requirement

The emulator shall run `6502_functional_test.bin` to its success trap.

## Rationale

The Klaus Dormann functional test is an independent check of all documented instructions, flags and decimal mode. It can find errors in instruction sequences that a test of single opcodes does not find.

## Acceptance criteria

1. The test `klaus_dormann_functional_test` in `crates/harness/tests/cpu_functional.rs` loads `test-data/klaus/6502_functional_test.bin` at `$0000`, sets `PC` = `$0400`, and runs the CPU on a flat 64 KB RAM bus.
2. After each instruction, the test compares `PC` with the value before the instruction. If the values are equal (a trap: a `JMP` or a branch to itself) and `PC` = `$3469`, the test passes.
3. If the CPU stops at a trap with `PC` other than `$3469`, the test fails and reports the `PC` value.
4. If the CPU does not reach a trap in 100,000,000 cycles, the test fails.

## Notes

The HRM does not cover this test. The load, start and success addresses are the values of the standard build of the test. Confirm the success address against the listing file of the binary in `test-data/klaus/`.
