# REQ-514: 9/17-bit polynomial counter and RANDOM

## Requirement

The emulator shall step the 9/17-bit polynomial counter once per machine cycle, with 9 bits (1 + x^4 + x^9) when `AUDCTL` bit 7 is 1 and 17 bits (1 + x^12 + x^17) when it is 0, and shall return 8 of its bits, inverted, in `RANDOM`.

## Rationale

Games read `RANDOM` for random numbers. The OS and BASIC (`RND`) also use it. The counter also makes the noise of distortions 0 and 8.

## Acceptance criteria

1. With `AUDCTL` = `$80`, the reads of `RANDOM` on 511 consecutive cycles are a rotation of the 511 entries of the HRM 14.4 table (entry 0 = `$00`, entry 1 = `$80`, entry 2 = `$40`, entry 3 = `$20`, entry 4 = `$10`, entry 5 = `$88`, ...). The read on cycle C + 511 is equal to the read on cycle C.
2. With `AUDCTL` = `$80`, there is a cycle C in each 511 consecutive cycles on which the reads of `RANDOM` on cycles C, C+114, C+228, C+342 and C+456 are `$00`, `$DF`, `$EE`, `$16` and `$B9`.
3. With `AUDCTL` = `$80`, after at least 18 cycles of initialization mode, a read of `RANDOM` 4 cycles after the `SKCTL` = `$03` write returns `$1F`.
4. With `AUDCTL` = `$00`, the read of `RANDOM` on cycle C + 131071 is equal to the read on cycle C, for 131071 consecutive values of C. The reads on these cycles are not all equal.
5. After a write of `SKCTL` = `$00` on cycle I, each read of `RANDOM` from cycle I+9 to cycle I+1000 returns `$FF`.

## Notes

The HRM calls the counter XNOR-based in HRM 5.5 and XOR-based in HRM 14.4. The two are the same if the bits are inverted. `docs/design/pokey.md` gives a model that matches the HRM 14.4 table for all 511 entries.

`RANDOM` shifts right by one bit in each cycle. The HRM does not give a table for 17-bit mode. 131071 is a prime number, so criterion 4 shows that the period is exactly 131071 cycles.

TRN HW-III.F/RANDOM and POKEY-SPEC 6 state that `RANDOM` reads the high-order 8 bits of the counter. POKEY-SPEC 6 states that initialization mode sets the counter to all ones, so the CPU reads `$FF`. ACID800 pokey_noise checks `RANDOM` in initialization mode, and on fixed cycles after initialization mode starts and ends, in 9-bit and 17-bit mode.
