# REQ-407: Low resolution playfield colors

## Requirement

In low resolution state with `PRIOR` bits 6-7 = `%00` and no P/M object active, the emulator shall show ANx code `%000` as `COLBK` and codes `%100`, `%101`, `%110`, `%111` as `COLPF0`, `COLPF1`, `COLPF2`, `COLPF3`.

## Rationale

ANTIC sends one 3-bit code per color clock on the ANx bus. GTIA converts each code to a color register. This gives the colors of ANTIC modes 4-7 and 8-E.

## Acceptance criteria

1. With `COLBK` = `$02`, `COLPF0` = `$14`, `COLPF1` = `$26`, `COLPF2` = `$38`, `COLPF3` = `$4A`, `PRIOR` = `$00`, the last horizontal blank code `%010` and no P/M graphics, a GTIA unit test sends codes `%000`, `%100`, `%101`, `%110`, `%111` at HPOS `$40-$44`. Columns 64-73 of the row are `$02`, `$02`, `$14`, `$14`, `$26`, `$26`, `$38`, `$38`, `$4A`, `$4A`.
2. On the full machine, with the colors of criterion 1, `HSCROL` = 0 and an ANTIC mode E line at normal width with first byte `$1B`, HPOS `$30`, `$31`, `$32`, `$33` show `$02`, `$14`, `$26`, `$38`.

## Notes

ANTIC selects the code for each pixel (ANTIC requirements, REQ-3xx). The two-color, four-color and five-color mode classes of HRM 4.3 are ANTIC behavior. GTIA only converts the codes. Codes `%010` and `%011` are horizontal blank, and code `%001` is vertical sync. GTIA shows no color for these codes (REQ-406).
