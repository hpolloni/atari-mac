# REQ-602: Writes to cartridge ROM

## Requirement

This requirement is withdrawn. REQ-206 states it (OI-004).

## Rationale

The MMU selects the device from the address only. A write to ROM does not "write through" to the RAM below it. Some programs write to the cartridge area by accident.

## Acceptance criteria

1. None. The criteria are in REQ-206.

## Notes

The criteria of this requirement were merged into REQ-206. The ID is kept, because IDs never change (see `docs/spec/README.md`).
