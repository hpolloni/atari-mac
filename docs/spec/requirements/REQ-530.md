# REQ-530: Direct serial input in SKSTAT

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Should |
| Area | POKEY: audio, timers, keyboard, interrupts, serial port |
| Source | HRM 5.6 Serial port (Direct input); HRM 14.4 POKEY registers (SKSTAT) |
| Verification | Test |
| Depends on | REQ-500 |

## Requirement

The emulator shall show the current level of SIO DATA IN in `SKSTAT` bit 4, for all serial settings and also when all clocks stop, and shall always read `SKSTAT` bit 0 as 1.

## Rationale

The OS cassette handler measures the baud rate through `SKSTAT` bit 4.

## Acceptance criteria

1. For each of the 256 `SKCTL` values, a call of `set_serial_in(false)` before the tick of cycle X makes `SKSTAT` bit 4 read 0 on cycle X. A call of `set_serial_in(true)` before the tick of cycle Y makes `SKSTAT` bit 4 read 1 on cycle Y.
2. `SKSTAT` bit 0 reads 1 for each of the 256 `SKCTL` values, with SIO DATA IN at 0 and at 1, and with the A key and Shift down. It also reads 1 on each cycle of the frame receive of REQ-526 criterion 1.
