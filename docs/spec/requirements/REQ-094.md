# REQ-094: Disk shortcut option

## Requirement

The frontend shall turn on the SIOV shortcut (REQ-623) unless the command line has `--no-fast-disk`.

## Rationale

A disk of 90 KB takes more than one minute at 19,200 baud. With the shortcut, a disk that loads through SIOV loads in seconds. A disk with a loader that the shortcut breaks still loads with `--no-fast-disk`. The tape has the same rule (REQ-091).

## Acceptance criteria

1. Without `--no-fast-disk`, the machine of the frontend has the SIOV shortcut on, also with `--xex` and with no media.
2. With `--no-fast-disk`, the machine has the SIOV shortcut off, and a disk loads through the POKEY serial port as in REQ-636.
3. The boot test disk of REQ-636 criterion 1, with `--disk` and no other option, boots in fewer frames than with `--no-fast-disk`.
4. `--help` lists `--no-fast-disk`.

## Notes

Project decision (OI-056, decided on 2026-11-21, the same rule as the tape). The option name follows `--no-fast-tape`.
