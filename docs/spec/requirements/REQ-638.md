# REQ-638: Seek and verify timing

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Could |
| Area | Media |
| Source | HRM 10.15 1050 disk drive (Seek timing); HRM 10.1 Introduction (Rotational latency); HRM 10.2 Basic protocol (Write ($57)) |
| Verification | Test |
| Depends on | REQ-621, REQ-629, REQ-630 |

## Requirement

Before the Complete or Error byte of Read, Put and Write, the disk drive shall add 20 ms for each track that the head moves and 20 ms of head settle time after a move, and for Write it shall add one disk revolution of 208 ms.

## Rationale

Some programs and copy-protection checks measure the time of disk access. The 1050 steps 10 ms for each half track (20 ms for each track) and then waits 20 ms for the head to settle. The disk turns at 288 RPM, so one revolution takes 208 ms.

## Acceptance criteria

All criteria use the SD or ED file of REQ-625 and NTSC timing. The time of a command is the time from the end of the stop bit of the last ACK byte to the start of the Complete byte. Each criterion compares two runs from the same start state: a new drive with the image inserted (head on track 0) and then the given first command. 1 ms is 1,789.77 machine cycles, so ± 0.1 ms is ± 179 machine cycles.

1. SD image, first command Read sector 1. Read sector 19 (track 1) takes 40 ms ± 0.1 ms more than Read sector 2 (track 0).
2. SD image, first command Read sector 1. Read sector 37 (track 2) takes 60 ms ± 0.1 ms more than Read sector 2.
3. SD image, first command Read sector 37 (track 2). Read sector 1 (track 0) takes 60 ms ± 0.1 ms more than Read sector 38 (track 2).
4. ED image, first command Read sector 1. Read sector 27 (track 1) takes 40 ms ± 0.1 ms more than Read sector 2 (track 0).
5. SD image, first command Read sector 1. Write sector 2 takes 208 ms ± 0.1 ms more than Put sector 2.
6. SD image, first command Read sector 1. Put sector 19 (track 1) takes 40 ms ± 0.1 ms more than Put sector 2.

## Notes

The track of a sector is `(sector - 1) / 18` for SD and DD, and `(sector - 1) / 26` for ED.

Out of scope: rotational latency for each sector, interleave, motor spin-up, and the extra inward half steps of the 1050 seek. These need a model of the sector positions on the track (HRM 10.5 Table 53).
