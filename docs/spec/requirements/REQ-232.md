# REQ-232: Cartridge sense with TRIG3

## Requirement

The emulator shall set the GTIA trigger 3 input to 1 while a cartridge shows ROM at `$A000-$BFFF` (RD5 active), and to 0 at all other times.

## Rationale

The XL/XE OS uses `TRIG3` to find a cartridge (HRM 2.8). It must not start a cartridge that is absent or disabled.

## Acceptance criteria

In these criteria, the GTIA trigger latch is off (`GRACTL` bit 2 = 0).

1. No cartridge. A read of `TRIG3` (`$D013`) returns `$00`.
2. An 8 KB cartridge at `$A000-$BFFF` (RD5 active). A read of `TRIG3` returns `$01`.
3. A MaxFlash 1Mbit cartridge (REQ-608) makes RD5 inactive on an access to `$D510`. After `LDA $D510`, the next read of `TRIG3` returns `$00`.
4. No cartridge, `PORTB` pins = `$FD` (BASIC on). A read of `TRIG3` returns `$00`.
5. A read of `TRIG2` (`$D012`) returns `$01`.
6. With the 8 KB cartridge of criterion 2, the first read of `TRIG3` after power-on and the first read after the Reset button return `$01`.
7. A 16 KB cartridge (RD4 and RD5 active). A read of `TRIG3` returns `$01`.
8. The cartridge of criterion 3 makes RD5 active again (bank 1) on an access to `$D501`. After `LDA $D501`, the next read of `TRIG3` returns `$01`.

## Notes

The GTIA trigger latch can also affect `TRIG3` (HRM 2.8). The latch is in the REQ-400 range. The SECAM FGTIA delay is out of scope.

REQ-603 was merged into this requirement (OI-004). A bank-switched cartridge (REQ-608) is a test cartridge in the sense of criteria 3 and 8.
