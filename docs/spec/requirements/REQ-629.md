# REQ-629: Read sector

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Media |
| Source | HRM 10.2 Basic protocol (Read ($52)); HRM 10.3 Extended protocols (Double density); HRM 10.1 Introduction (Boot sectors) |
| Verification | Test |
| Depends on | REQ-619, REQ-625, REQ-628 |

## Requirement

In reply to Read (`$52`) with a valid sector number, the disk drive shall send Complete and then the data of that sector: 128 bytes for an SD or ED image and for sectors 1-3 of a DD image, and 256 bytes for the other sectors of a DD image.

## Rationale

All DOS and boot software reads the disk with this command. The OS boot loader can read only 128-byte sectors, so the first three sectors of a DD disk are 128 bytes.

## Acceptance criteria

The test images are the SD, ED and DD files of REQ-625 (data byte `i` holds `i & $FF`). In each criterion, the drive sends `41`, `43`, the data frame and the checksum byte.

1. SD image, sector 1: the data frame is equal to file bytes 16 to 143.
2. SD image, sector 720: the data frame is equal to file bytes 92,048 to 92,175.
3. ED image, sector 1040: the data frame is equal to file bytes 133,008 to 133,135.
4. DD image, sector 3: the data frame has 128 bytes, equal to file bytes 272 to 399.
5. DD image, sector 4: the data frame has 256 bytes, equal to file bytes 400 to 655.
6. In criteria 1 to 5, the checksum byte is equal to the checksum of the data frame (REQ-616).
