## Requirement

The test harness shall run all SingleStepTests 6502 cases for each opcode that is not a `JAM` opcode, and shall compare the registers, the memory and each bus cycle.

## Rationale

The suite checks the exact bus access of every cycle, which accurate ANTIC timing needs.

## Acceptance criteria

1. The test runs all 10,000 cases of each of the 244 non-`JAM` opcode files.
2. A case passes only when `A`, `X`, `Y`, `S`, `P`, `PC`, every listed RAM byte and the complete list of `(address, value, read or write)` bus cycles are equal to the case data.
3. For each failure, the output gives the opcode, the case name and the first difference.
4. The test passes only when no case fails, except opcodes in an explicit list in the test, each with a reason and a requirement ID.
