# REQ-004: User-supplied ROMs

| Field | Value |

| Status | Draft |
| Priority | Must |

## Requirement

The emulator shall accept an OS ROM of 16,384 bytes and a BASIC ROM of 8,192 bytes from files that the user selects.

## Rationale

Some software runs only with the original Atari OS.

## Acceptance criteria

1. `Machine::new` accepts an OS ROM of 16,384 bytes and a BASIC ROM of 8,192 bytes. After `run_frame`, `peek($FFFC)` gives byte `$3FFC` of the given OS ROM.
2. `Machine::new` with an OS ROM of 16,383 bytes returns `ConfigError::OsRomSize(16383)`.
3. `Machine::new` with a BASIC ROM of 8,193 bytes returns `ConfigError::BasicRomSize(8193)`.
4. `atari-mac --os <file>` with a file of 100 bytes writes a message that contains `16384` to standard error, and exits with status 2.
