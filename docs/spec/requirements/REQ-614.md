# REQ-614: Executable run address

## Requirement

After the last segment, the emulator shall jump to the address in RUNAD (`$02E0-$02E1`) if a segment wrote RUNAD, and to the start address of the first segment if no segment wrote RUNAD.

## Rationale

RUNAD gives the entry point of most programs. Some files do not set RUNAD and expect the program to start at its first byte.

## Acceptance criteria

All criteria use AltirraOS (NTSC). The test starts the file (REQ-612) and runs until `$0600` is not `$00`, for at most 600 frames.

1. Test file: a segment at `$2000` with `A9 5A 8D 00 06 4C 05 20` (writes `$5A`), a segment at `$3000` with `A9 A5 8D 00 06 4C 05 30` (writes `$A5`), and a segment at `$02E0` with `00 30` (RUNAD = `$3000`). Then `$0600` holds `$A5`.
2. Test file: a segment at `$2000` with `A9 A5 8D 00 06 4C 05 20`, and a segment at `$3000` with `A9 5A 8D 00 06 4C 05 30`, with no RUNAD segment. Then `$0600` holds `$A5`.
3. Criteria 1 and 2 pass with the SIOV shortcut off and with the SIOV shortcut on (REQ-623).

## Notes

Project decision: a rule for a file format or a host tool, not hardware behavior (Atari DOS 2 binary load format). The HRM does not cover it.

The fallback to the first segment is a project decision. Atari DOS 2 returns to the DOS menu when RUNAD is not set. To verify: the fallback that other emulators use.
