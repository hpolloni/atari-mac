# REQ-086: CPU instruction trace

## Requirement

When the command line has `--trace <file>`, the emulator shall write one line to the file for each CPU instruction and each interrupt sequence in the frames that the trace options select.

## Rationale

A timing bug or a loader that fails needs the exact order of the instructions, with the beam position and the cycle of each one.

## Acceptance criteria

1. Each instruction line has this format:
   `<frame> <scanline> <hpos> <cycle> <PC>: <bytes> <instruction>  A=<a> X=<x> Y=<y> S=<s> P=<flags>`
   The frame, scanline, horizontal position and cycle are decimal and give the first cycle of the instruction. `<PC>` is 4 hexadecimal digits. `<bytes>` are the 1 to 3 instruction bytes in hexadecimal, padded to 8 characters. `<instruction>` is the disassembly of REQ-087. The registers are 2 hexadecimal digits and show the values before the instruction. `<flags>` is `NV-BDIZC`, with `.` for each clear flag.
2. An interrupt sequence (NMI, IRQ or RESET) has its own line, `<frame> <scanline> <hpos> <cycle> <NMI|IRQ|RESET> vector <address>`, before the first instruction of the handler.
3. `--trace-from <frame>` gives the first frame of the trace (default 0). `--trace-frames <n>` gives the number of frames (default 1). The trace starts at the first instruction of the first frame and stops after the last instruction that starts in the last frame.
4. A test runs 3 frames of the boot of AltirraOS with `--trace-from 1 --trace-frames 1`. The file has a line for each instruction that the CPU starts in frame 1, and the cycle of each line increases by the cycle count of the instruction before it, or of the DMA cycles and the halt cycles between them.
5. The machine does not depend on the trace: the frame buffer and the RAM are the same with and without `--trace`.
6. A file that cannot be written gives exit code 2 and a message that names the file.
7. `--help` lists `--trace <file>`, `--trace-from <frame>` and `--trace-frames <n>`.

## Notes

Project decision (2026-11-21, SLICE-10). The HRM does not cover it. The line format is like the trace of other emulators, so that two traces can be compared with a text tool.
