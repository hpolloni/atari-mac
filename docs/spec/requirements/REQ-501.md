# REQ-501: Power-on state

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | POKEY: audio, timers, keyboard, interrupts, serial port |
| Source | HRM 5.2 Initialization (Power-up state); project decision for the values |
| Verification | Test |
| Depends on | REQ-500 |

## Requirement

At each power-on, the emulator shall put POKEY in one fixed state: `IRQEN`, `SKCTL`, `AUDCTL`, `AUDF1-4` and `AUDC1-4` equal to `$00`, no latched interrupt, and the register read values in the acceptance criteria.

## Rationale

Tests must give the same result on each run. The OS initializes POKEY at boot, so a fixed state does not hide software errors that the OS corrects.

## Acceptance criteria

1. After `Pokey::new`, the test accessor gives `AUDF1-4`, `AUDC1-4`, `AUDCTL`, `SKCTL` and `IRQEN` equal to `$00`.
2. After `Pokey::new`, `IRQST` reads `$F7`. Only bit 3 is 0, because the serial output is idle. `irq()` returns false.
3. After `Pokey::new`, `KBCODE` reads `$FF`, `SERIN` reads `$00`, `SKSTAT` reads `$FF`, `RANDOM` reads `$FF`, `ALLPOT` reads `$00` and `POT0-POT7` read `$00`.
4. The test runs this script on two instances of `Pokey::new(VideoStandard::Ntsc, 48000)`: `SKCTL` = `$03`, `AUDF1` = `$48`, `AUDC1` = `$AF`, `POTGO`, the A key down for 20000 cycles, and then 298680 cycles in total (10 NTSC frames). On each cycle, the reads of all 16 registers are the same for the two instances. The samples are bit-identical.
5. After the script of criterion 4, `reset()` gives the same register reads and test accessor values as `Pokey::new`.

## Notes

The HRM states that real POKEY has no RESET line and powers up in an indeterminate state. The real state can include enabled and asserted interrupts. The emulator does not copy this. The values in this requirement are a project decision.

`SKCTL` = `$00` means that POKEY starts in initialization mode (REQ-502). The 15 kHz and 64 kHz clocks stay stopped until software writes `SKCTL`.

The RESET key does not change POKEY, because POKEY has no RESET line. The machine calls the power-on function only for a cold start.
