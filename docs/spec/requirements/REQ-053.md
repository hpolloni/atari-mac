# REQ-053: Open item records

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Quality |
| Source | Project decision |
| Verification | Test |
| Depends on | REQ-043 |

## Requirement

Each open item file shall have YAML frontmatter with `id`, `title`, `status`, `area` and `affects`, and an open item with the status `decided` shall have a decision text.

## Rationale

The gates and the index use the status of open items.

## Acceptance criteria

1. `status` is `open` or `decided`. `affects` is a list of requirement IDs and file paths that exist.
2. A `decided` item whose `Decision` section is empty or says `Not decided.` makes the check fail.
3. An `open` item whose `Decision` section has text other than `Not decided.` makes the check fail.
4. The index `docs/spec/open-items/README.md` is generated, and it is up to date.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
