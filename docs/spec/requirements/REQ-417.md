# REQ-417: P/M size

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | GTIA, color palette, joystick and paddle inputs |
| Source | HRM 6.5 Player/missile graphics (Size control); HRM 14.3 GTIA registers (SIZEP0-SIZEP3, SIZEM) |
| Verification | Test |
| Depends on | REQ-416 |

## Requirement

The emulator shall show each bit of an object for 1 color clock for size code `%00` or `%10`, 2 color clocks for `%01` and 4 color clocks for `%11`, from the left edge to the right.

## Rationale

Programs use double and quadruple width players. `SIZEPn` bits 0-1 set the size of player n. `SIZEM` bits `2n+1` and `2n` set the size of missile n.

## Acceptance criteria

In all criteria, `COLPM0` = `$46`, `COLPM1` = `$94` and `COLBK` = `$02`.

1. With `GRAFP0` = `$80` and `HPOSP0` = `$80`: `SIZEP0` = `$00` shows `$46` at HPOS `$80` only, `$01` at HPOS `$80-$81` only, `$03` at HPOS `$80-$83` only and `$02` at HPOS `$80` only.
2. With `GRAFP0` = `$FF`, `HPOSP0` = `$40` and `SIZEP0` = `$03`, HPOS `$40-$5F` show `$46` and HPOS `$60` shows `$02`.
3. With `GRAFM` = `$08`, `HPOSM1` = `$90` and `SIZEM` = `$0C`, HPOS `$90-$93` show `$94` and HPOS `$94` shows `$02`.
4. With `GRAFP0` = `$80` and `HPOSP0` = `$80`, `SIZEP0` = `$FC` gives the same frame buffer row as `$00`, and `$FD` gives the same row as `$01`.
