# REQ-225: CA1 and CB1 inputs

## Requirement

The emulator shall set control register bit 7 on a CA1 or CB1 transition in the direction that bit 1 selects (0 = negative, 1 = positive), also when bit 0 disables the interrupt.

## Rationale

CA1 is the SIO proceed line and CB1 is the SIO interrupt line (HRM 2.5). MidiTrack III and the R-Verter handler poll these status bits without the interrupt enabled (HRM 2.9).

## Acceptance criteria

1. `PACTL` = `$3C` (bit 1 = 0). CA1 goes from high to low. `PACTL` bit 7 = 1.
2. `PACTL` = `$3C`, CA1 low, `PACTL` bit 7 = 0 (after a read of `PORTA`). CA1 goes from low to high. `PACTL` bit 7 stays 0.
3. `PBCTL` = `$3E` (bit 1 = 1), CB1 low. CB1 goes from low to high. `PBCTL` bit 7 = 1.
4. In criteria 1 and 3, bit 0 = 0, and the PIA does not assert IRQ. With `PACTL` = `$3D` (bit 0 = 1), the transition of criterion 1 makes the PIA assert IRQ.
5. After power-on, with no device on the SIO bus, `PACTL` = `$3C` and `PBCTL` = `$3C`: bit 7 of both registers stays 0 for 10 frames. The same occurs with `PACTL` = `$3E` and `PBCTL` = `$3E`.

## Notes

The idle level of CA1 and CB1 without a device is a project decision. The HRM does not state it.
