# REQ-404: Color registers

## Requirement

The emulator shall keep nine color registers (`COLPM0-3`, `COLPF0-3`, `COLBK`) and store each written value with bit 0 cleared.

## Rationale

All playfield, background and P/M colors come from these registers. Bit 0 of a color register is ignored by the hardware, so a color register can only give 128 colors.

## Acceptance criteria

1. For each of the 9 color registers, after a write of `$FF`, the pixels of its layer (player 0-3, `PF0-PF3` or background) in the frame buffer are `$FE`.
2. After a write of `$95` to `COLPF2`, a pixel of playfield 2 in the frame buffer is `$94`.
3. With `COLPF0` = `$28` and a write of `$C6` to `COLPF0` in horizontal blank of scanline 100, the `PF0` pixels of rows 0-91 are `$28` and the `PF0` pixels of rows 92-239 are `$C6`.

## Notes

Bits 4-7 of a color register are the hue and bits 1-3 are the luminance (HRM 6.3). The palette requirements REQ-409 and REQ-410 check this meaning.
