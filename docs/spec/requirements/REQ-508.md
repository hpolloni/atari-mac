# REQ-508: Timer interrupts

## Requirement

When timer 1, 2 or 4 fires and bit 0, 1 or 2 of `IRQEN` is 1, the emulator shall set bit 0, 1 or 2 of `IRQST` to 0.

## Rationale

Music players and some games use the timer IRQs. Timer 3 has no IRQ.

## Acceptance criteria

1. With `AUDCTL` = `$00`, `AUDF1-4` = `$00`, `IRQEN` = `$07`, an `STIMER` write while `SKCTL` = `$00`, and a write of `SKCTL` = `$03` on cycle W, `IRQST` reads `$F7` on cycle W+23 and `$F0` on cycle W+24.
2. With `AUDCTL` = `$20`, `AUDF3` = `$00`, `AUDF1` = `AUDF2` = `AUDF4` = `$FF`, `IRQEN` = `$FF`, no key down, SIO DATA IN at 1 and an `STIMER` write on cycle T, `IRQST` reads `$F7` on each cycle from T+1 to T+1000. Timer 3 fires every 4 cycles in this time.
3. With `AUDCTL` = `$50`, `AUDF1` = `$40`, `AUDF2` = `$01` and `IRQEN` = `$02`, timer 2 fires every 327 cycles. After each event, the test writes `IRQEN` = `$00` and then `IRQEN` = `$02`. `IRQST` bit 1 goes to 0 exactly once in each 327-cycle period, on the fire cycle of timer 2.
4. With `AUDCTL` = `$00`, `AUDF1` = `$00` and `IRQEN` = `$00`, timer 1 fires on cycles E and E+28. A write of `IRQEN` = `$01` on cycle E+1 makes `IRQST` bit 0 read 1 on cycles E+1 to E+27 and 0 on cycle E+28.
5. With the setup of REQ-506 criterion 1, `IRQST` bit 0 reads 0 first on cycle T+8 for each of `AUDC1` = `$00`, `$0F`, `$1F`, `$2F`, `$8F`, `$AF` and `$CF`.

## Notes

The HRM does not state if the low timer of a linked pair sets its own `IRQST` bit when it fires. ACID800 pokey_timertiming checks that timer 1 sets `IRQST` bit 0 when timers 1 and 2 are linked (`AUDCTL` = `$50`). See the open issues in `docs/design/pokey.md`.

TRN HW-II.D/IRQ-Interrupts, POKEY-SPEC 5 and POKEY-SPEC 8 state that only timers 1, 2 and 4 have an IRQ. ACID800 pokey_timerirq checks the IRQs of timers 1 and 2.
