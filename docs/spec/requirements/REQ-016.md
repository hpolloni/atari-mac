# REQ-016: No panics on bad input

## Requirement

The emulator shall not panic for any ROM, media file or CPU program. It shall report each error as a value.

## Rationale

A crash loses the user's work and hides the cause of the error.

## Acceptance criteria

1. The production code has no `unwrap`, `expect` or `panic!` (the lints in `Cargo.toml` enforce this).
2. A test with a fixed seed loads 1,000 random byte arrays of random length (0 to 70,000 bytes) as each media type. No load panics.
3. A test with a fixed seed fills RAM with random bytes, sets `PC` to `$0600` and runs 600 frames. No call panics.
