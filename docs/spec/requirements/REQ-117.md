# REQ-117: Interrupts only at instruction boundaries

## Requirement

The emulator shall start an interrupt sequence only at an instruction boundary, after the current instruction is complete.

## Rationale

The 6502 does not abort or resume instructions (HRM 3.4). DLI timing depends on the length of the current instruction.

## Acceptance criteria

1. Start: `X` = `$00`. `INC $1000,X` runs in cycles C to C+6. The NMI line goes high in cycle C. All 7 cycles of the `INC` execute. The NMI sequence starts in cycle C+7.
2. Opcode `$13` (`SLO ($40),Y`) runs in cycles C to C+7. The NMI line goes high in cycle C. All 8 cycles execute. The NMI sequence starts in cycle C+8.
3. With `I` = 0 and the IRQ line asserted in cycle C instead of the NMI line, criteria 1 and 2 give the same cycles for the IRQ sequence.
