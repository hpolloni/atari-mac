# REQ-002: Video standards

## Requirement

The emulator shall emulate both the NTSC and the PAL versions of the 65XE, selected when the machine is created.

## Rationale

The 65XE was sold in both versions. Software uses the PAL register in GTIA to find the version.

## Acceptance criteria

1. With `VideoStandard::Ntsc`, `Machine::cycle_count` increases by exactly 29,868 (262 x 114) from one `run_frame` to the next.
2. With `VideoStandard::Pal`, `Machine::cycle_count` increases by exactly 35,568 (312 x 114) from one `run_frame` to the next.
3. `MachineConfig` with no explicit standard (`VideoStandard::default()`) gives NTSC.
4. `atari-mac --headless --frames 50 --pal` runs a PAL machine: it prints a run time for 50 frames of 35,568 cycles, and `--help` lists `--pal`. Without `--pal`, the machine is NTSC.

## Notes

The value of the GTIA PAL register is REQ-403. The option `--pal` is a project decision of 2026-11-19 (the user), so that REQ-019 criterion 3 can run from the command line.
