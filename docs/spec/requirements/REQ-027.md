# REQ-027: Requirement traceability

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Test harness |
| Source | Project decision |
| Verification | Inspection |
| Depends on | None |

## Requirement

Each requirement with the verification method `Test` shall have at least one test that names the requirement ID in its documentation comment.

## Rationale

Traceability shows which requirements are tested.

## Acceptance criteria

1. A script lists each `Test` requirement that no test names. The script output is empty.
