# REQ-523: 65XE key codes

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | POKEY: audio, timers, keyboard, interrupts, serial port |
| Source | HRM 5.8 Keyboard scan (Key codes; Table 11; Table 12) |
| Verification | Test |
| Depends on | REQ-518 |

## Requirement

The emulator shall give each key of the 65XE keyboard the 6-bit key code in the table in Notes.

## Rationale

The OS converts key codes to characters with a table. A wrong code types a wrong character.

## Acceptance criteria

1. For each of the 54 keys in the table, with `SKCTL` = `$03` and Shift and Control up, a press of that key alone makes `KBCODE` read the code in the table.
2. `keyboard::KEYS` has 54 entries. Each entry has the code and the name of one key in the table. Each named key constant in `crates/atari-core/src/keyboard.rs` has the code of its key in the table. The test has its own copy of the table.
3. No entry of `KEYS` has one of the codes `$03`, `$04`, `$09`, `$13`, `$14`, `$19`, `$24`, `$29`, `$31` or `$3B`.
4. `KEYS` has no entry for START, SELECT, OPTION, RESET, Shift, Control or BREAK.

HRM Table 12 shows the 130XE keyboard. The 65XE has the same keys. This is a project assumption, because the HRM shows no separate 65XE table. A reviewer must check the 65XE keyboard against Table 12.

The function keys F1-F4 exist only on the 1200XL. The six codes marked "No key" are not in the keyboard matrix.
