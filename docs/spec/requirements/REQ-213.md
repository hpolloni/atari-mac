# REQ-213: ANTIC DMA and the memory map

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | System: clocks, memory map, bank switching, reset, PIA |
| Source | HRM 2.3 Memory system (Floating I/O data bus, Memory refresh) |
| Verification | Test |
| Depends on | REQ-207, REQ-210 |

## Requirement

The emulator shall use the same ROM and RAM mapping for ANTIC DMA reads as for CPU reads. An ANTIC DMA read shall have no side effect, except that a DMA read of `$D500-$D5FF` reaches the cartridge control (REQ-609).

## Rationale

ANTIC reads character data from the OS ROM at `$E000-$E3FF` (HRM 2.3). Programs that copy the character set to RAM under the OS ROM need the same mapping.

## Acceptance criteria

1. `PORTB` pins = `$FF`. An ANTIC DMA read of `$E000` returns OS image byte `$2000`.
2. `PORTB` pins = `$FE`, RAM at `$E000` = `$AA`. An ANTIC DMA read of `$E000` returns `$AA`.
3. For `PORTB` pins `$FF`, `$FE`, `$FD`, `$7F` and `$7E`, with no cartridge and with a test cartridge with RD4 and RD5 active, an ANTIC DMA read of each address in `$0000-$CFFF` and `$D800-$FFFF` returns the same value as a CPU read of that address.
4. `PACTL` = `$3C`, `PACTL` bit 7 = 1. An ANTIC DMA read of `$D300` leaves `PACTL` bit 7 = 1. A test cartridge that counts its `$D5xx` accesses counts exactly one access for one ANTIC DMA read of `$D500` (REQ-609).

## Notes

The HRM does not state the value that an ANTIC DMA read of `$D000-$D7FF` returns. The system design returns `$FF` (`docs/design/system.md`, "ANTIC DMA"). Criterion 3 is a project decision.

The `$D5xx` exception was decided in OI-002: HRM 8.1 warns that ANTIC reads of this range can switch cartridge banks.
