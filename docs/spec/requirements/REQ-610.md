# REQ-610: Executable file parsing

## Requirement

The emulator shall parse an Atari DOS 2 binary load file (XEX) into an ordered list of segments, each with a start address and its data.

## Rationale

Most programs for the Atari 8-bit computers are distributed as XEX files. The HRM does not describe this format.

## Format

1. The file starts with the two bytes `$FF $FF`.
2. A segment has a start address (2 bytes, low byte first), an end address (2 bytes, low byte first), and `end - start + 1` data bytes.
3. The two bytes `$FF $FF` can occur again before any segment header. The parser skips them.
4. The segments follow each other to the end of the file.

## Acceptance criteria

1. The file `FF FF 00 20 02 20 A9 00 60` gives one segment: start `$2000`, data `A9 00 60`, and no defect (REQ-611).
2. The file `FF FF 00 20 00 20 11 FF FF 00 30 00 30 22` gives two segments, in this order: `$2000` with data `11`, and `$3000` with data `22`.
3. The file `FF FF 00 20 00 20 11 00 30 00 30 22` gives the same two segments.
4. The file `FF FF FF FF 00 20 00 20 11` gives one segment: start `$2000`, data `11`.
5. The file `FF FF 00 20 00 20 11 FF FF` gives one segment: start `$2000`, data `11`, and no defect (REQ-611).
6. The file `FF FF 00 00 FF FF` followed by 65536 data bytes gives one segment: start `$0000`, 65536 data bytes.
