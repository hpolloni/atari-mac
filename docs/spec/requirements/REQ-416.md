# REQ-416: P/M horizontal position

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | GTIA, color palette, joystick and paddle inputs |
| Source | HRM 6.2 Display generation (Horizontal positions); HRM 6.5 Player/missile graphics (Player/missile positioning, Shift triggering and timing) |
| Verification | Test |
| Depends on | REQ-413, REQ-406 |

## Requirement

The emulator shall start the image of a player or missile at the color clock where the GTIA horizontal position equals the `HPOSPn` or `HPOSMn` value, also for positions in horizontal blank.

## Rationale

Programs set the left edge of each sprite with these registers. The HRM states that position `$22` just touches the left edge and `$DE` is just off the right edge.

## Acceptance criteria

In all criteria, `GRAFP0` = `$FF`, `SIZEP0` = `$00`, `COLPM0` = `$46` and `COLBK` = `$02`, except where the criterion states other values.

1. With `GRAFP0` = `$80` and `HPOSP0` = `$80`, HPOS `$80` (columns 192-193) shows `$46` and HPOS `$7F` and `$81` show `$02`.
2. With `HPOSP0` = `$1E`, HPOS `$22-$25` (columns 4-11) show `$46` and HPOS `$26-$DD` show `$02`.
3. With `HPOSP0` = `$DA`, HPOS `$DA-$DD` (columns 372-379) show `$46` on each scanline, and HPOS `$22-$D9` show `$02`. The image does not continue at the left edge of the next scanline.
4. With `HPOSP0` = `$DE`, HPOS `$22-$DD` of the scanline show `$02`.
