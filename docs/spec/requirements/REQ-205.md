# REQ-205: Hardware register area

## Requirement

The emulator shall always map `$D000-$D7FF` to hardware: GTIA at `$D0xx`, POKEY at `$D2xx`, PIA at `$D3xx`, ANTIC at `$D4xx` and the cartridge control area at `$D5xx`.

## Rationale

The 2K block of hardware registers at `$D000-$D7FF` cannot be disabled (HRM 2.6).

## Acceptance criteria

1. RAM at `$D40B` = `$FF`. For each of the 256 `PORTB` pin values, a CPU read of `$D40B` returns the ANTIC `VCOUNT` value, not `$FF`.
2. `PORTB` pins = `$FE`, RAM at `$D000-$D7FF` = `$AA`. The CPU writes `$55` to `$D0FF`, `$D1FF`, `$D2FF`, `$D3FF`, `$D4FF`, `$D5FF`, `$D6FF` and `$D7FF`. After the writes, each of these RAM bytes is still `$AA`.
3. A CPU read of `$D47B` returns `VCOUNT` (ANTIC uses the low 4 address bits, HRM 4.1). A CPU write of `$3C` to `$D3FF` sets `PBCTL` to `$3C` (the PIA uses the low 2 address bits, REQ-218). A CPU write of `$A0` to `$D2F0` has the same effect on POKEY as a write of `$A0` to `$D200` (POKEY uses the low 4 address bits, HRM 5.1).
4. No cartridge. RAM at `$D013` = `$AA`. A CPU read of `$D013` returns `TRIG3` (`$00`, REQ-232), not `$AA`.

## Notes

`$D100-$D1FF` and `$D600-$D7FF` are the PBI areas. PBI devices are out of scope. REQ-214 covers reads of these areas.
