# REQ-333: Vertical blank interrupt

## Requirement

The emulator shall request a VBI at the start of scan line 248 of each frame, and shall send an NMI to the CPU for it if `NMIEN` bit 6 is set.

## Rationale

The OS runs its vertical blank handler from the VBI. The OS does not boot without it.

## Acceptance criteria

1. With `NMIEN` = `$40` and a display list without DLI bits, `out.nmi` is set exactly once in each frame, on scan line 248, for 3 frames (NTSC and PAL).
2. With `NMIEN` = `$00` and a write to `NMIRES` on scan line 100, `out.nmi` is never set, and `NMIST` bit 6 reads 1 from cycle 7 of scan line 248.
3. With AltirraOS, after the boot, the byte at `$14` (`RTCLOK`, which the OS VBI handler increments) increases by 1 in each frame, for 10 frames.
