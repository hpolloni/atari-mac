# REQ-604: Raw cartridge images

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Media |
| Source | Project decision |
| Verification | Test |
| Depends on | REQ-600, REQ-016 |

## Requirement

The emulator shall load a raw cartridge image of 8192 bytes as a standard 8 KB cartridge and a raw image of 16384 bytes as a standard 16 KB cartridge, and shall reject a raw image of any other size.

## Rationale

Many cartridge dumps are raw ROM files with no header. Only the size identifies the type. Other sizes can be many types, so they need a CAR file (REQ-605).

## Acceptance criteria

1. A raw image of 8192 bytes loads with no error, and the cartridge kind is standard 8 KB (`CartKind::Standard8k`).
2. A raw image of 16384 bytes loads with no error, and the cartridge kind is standard 16 KB (`CartKind::Standard16k`).
3. Raw images of 0, 4096, 8193 and 32768 bytes give the errors `BadSize(0)`, `BadSize(4096)`, `BadSize(8193)` and `BadSize(32768)`. No load panics.
