# REQ-061: Media parsers accept any input

## Requirement

Each function that reads the bytes of a file that the user supplies shall return a value or an error for any input, and shall not panic.

## Rationale

The user loads ROM, cartridge, disk, tape, executable and save state files from any source. A damaged file must give an error message, not a crash.

## Acceptance criteria

1. The functions are `Cartridge::from_raw`, `Cartridge::from_car`, `Disk::from_atr`, `Tape::from_cas`, `Xex::parse`, `Machine::new` (the ROM bytes of `MachineConfig`) and `Machine::load_state`.
2. A property test gives each function at least 1000 random inputs of 0 to 4096 bytes, and at least 1000 inputs that start with a valid header of the format (the signature and the header fields) and continue with random bytes. Each call returns, and no call panics.
3. For each input that a function accepts, a machine that uses the result runs 10 frames and does not panic.
4. The tests are deterministic: the random generator has a fixed seed, and the same seed gives the same inputs on each run.
5. The tests run in `make test` and in `make pre-commit`.

## Notes

Project decision: the user asked for this gate on 2026-11-21. A panic that a test finds is a defect of the parser, and the package fixes the parser. The formats are in REQ-604 and REQ-605 (cartridges), REQ-625 (ATR), REQ-639 (CAS), REQ-612 (XEX) and REQ-018 (save states).
