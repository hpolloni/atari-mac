# REQ-603: TRIG3 cartridge sense

## Requirement

This requirement is withdrawn. REQ-232 states it (OI-004).

## Rationale

The XL/XE OS reads `TRIG3` to find a cartridge. If `TRIG3` is wrong, the OS does not start the cartridge, or the OS starts a cartridge that is not there.

## Acceptance criteria

1. None. The criteria are in REQ-232.

## Notes

The criteria of this requirement were merged into REQ-232. The ID is kept, because IDs never change (see `docs/spec/README.md`).
