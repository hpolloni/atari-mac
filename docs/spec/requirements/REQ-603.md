# REQ-603: TRIG3 cartridge sense

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Media |
| Source | HRM 2.8 Miscellaneous connections (Cartridge sense) |
| Verification | Test |
| Depends on | REQ-600 |

## Requirement

The emulator shall make `TRIG3` (`$D013`) read 1 while a cartridge maps `$A000-$BFFF` (RD5 asserted), and 0 while no cartridge maps `$A000-$BFFF`.

## Rationale

The XL/XE OS reads `TRIG3` to find a cartridge. If `TRIG3` is wrong, the OS does not start the cartridge, or the OS starts a cartridge that is not there.

## Acceptance criteria

The GTIA trigger latch is off (`GRACTL` bit 2 = 0) in all criteria.

1. With no cartridge and `PORTB` bit 1 = 1, a read of `TRIG3` gives `$00`.
2. With no cartridge and `PORTB` bit 1 = 0 (BASIC enabled), a read of `TRIG3` gives `$00`.
3. With an 8 KB cartridge, a read of `TRIG3` gives `$01`.
4. With a 16 KB cartridge, a read of `TRIG3` gives `$01`.
5. With a MaxFlash 1Mbit cartridge (REQ-608), the first read of `TRIG3` after an access to `$D510` (disable) gives `$00`. The first read of `TRIG3` after a later access to `$D500` gives `$01`.

## Notes

The HRM states that the internal BASIC ROM does not affect `TRIG3`.

The HRM states that `TRIG3` follows RD5 also when bank switching disables the cartridge. Thus the value must change at the time of the bank switch, not only at a cold reset.

The GTIA trigger latch can also affect `TRIG3`. The latch is in the GTIA area (REQ-400 range). This requirement applies with the latch off.

SECAM trigger delays are out of scope.

Acceptance criterion 5 applies only when REQ-608 is implemented.

REQ-232 (system area) states the same behavior.
