# REQ-017: Machine control keys

| Field | Value |

## Requirement

The frontend shall have host keys to pause, to do a cold reset and to quit.

## Rationale

The user must be able to restart a program that stopped.

## Acceptance criteria

1. A unit test of the frontend key map checks that F9 gives Pause, F10 gives Cold reset, and Command + Escape gives Quit.
2. While paused, `Machine::frame_count` does not change for 60 host frames (frontend unit test with a fake clock).
