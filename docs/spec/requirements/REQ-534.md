# REQ-534: Slow pot scan

## Requirement

In slow scan mode (`SKCTL` bit 2 = 0), a write to `POTGO` shall reset the scan counter and start a scan. The counter shall increment on each 15 kHz clock pulse up to 228. Each `POTn` shall follow the counter, with `ALLPOT` bit n = 1, until input n reaches threshold.

## Rationale

The OS reads the paddles in each vertical blank and writes `POTGO`. Paddle games and the BASIC `PADDLE` function need these values.

## Acceptance criteria

In all criteria, `SKCTL` = `$03` is written on cycle W, the capacitors are empty (no scan and `SKCTL` bit 2 = 0 for at least 100 cycles), and `POTGO` is written on cycle G. P is the cycle of the first pot counter increment after G.

1. On cycle G+1, for each input below threshold, `ALLPOT` bit n reads 1 and `POTn` reads 0.
2. With `set_pot(0, 100)`, `POT0` reads 100 after the scan. `ALLPOT` bit 0 reads 1 while `POT0` reads less than 100. It changes to 0 while the counter is 100.
3. For each input that does not reach threshold, `POTn` reads 228 from cycle P + 227 x 114 + 1. `ALLPOT` reads `$00` first on cycle P + 227 x 114 + 2.
4. P is a cycle W + 81 + 114 k (k = 0, 1, 2, ...). For an input without a paddle, `POTn` reads the old count on each cycle W + 80 + 114 k and the new count on each cycle W + 82 + 114 k, during the scan.
5. With `set_pot(0, 100)`, `ALLPOT` bit 0 changes to 0 on cycle G + 100 x 114 + 1, for each of the 114 values of (G - W) modulo 114. This cycle has no fixed relation to the pot counter increments.

## Notes

The HRM states that a read of a live counter can return a transitional value (the AND of two adjacent counts). The emulator does not emulate this. So criterion 4 does not check the read on the increment cycle. See the open issues in `docs/design/pokey.md`.

HRM 7.2 says that the `ALLPOT` bit is "set" when the capacitor reaches threshold. HRM 5.9 and HRM 14.4 say that the bit is 0 when the read is complete. The emulator follows HRM 5.9 and HRM 14.4.

Criterion 3 comes from HRM 5.9 Scan timing: the final increment is 227 x 114 cycles after the first increment, the counters show 228 on the next cycle, and `ALLPOT` reads `$00` one cycle later.
