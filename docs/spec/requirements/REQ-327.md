# REQ-327: Horizontal scrolling

## Requirement

The emulator shall, for a mode line with IR bit 4 set, use the next wider fetch width, delay the playfield fetches by (`HSCROL` >> 1) cycles, and show the playfield data `HSCROL` & `$0F` color clocks to the right, in the unchanged display window.

## Rationale

Many games use fine horizontal scrolling.

## Acceptance criteria

1. With `HSCROL` = 0 and IR = `$1E`: with `DMACTL` = `$21`, `Bitmap` fetches occur on cycles 20, 22, ..., 98. With `DMACTL` = `$22`, they occur on cycles 12, 14, ..., 106. With `DMACTL` = `$23`, they occur on the same cycles as with `DMACTL` = `$22`.
2. With `DMACTL` = `$22` and `HSCROL` = 0, a `$52` line (scrolled mode 2 with LMS address A) shows the character with the name at A + 4 at positions `$30-$33`. After the mode line, the memory scan counter is A + 48.
3. With `HSCROL` = 4, the same line shows the character with the name at A + 3 at positions `$30-$33`.
4. With `DMACTL` = `$22` and `HSCROL` = 6, the first `CharacterName` fetch of a `$12` line is on cycle 13.
5. `HSCROL` = 5 and `HSCROL` = 4 give the same `out.dma` on each cycle of a `$12` line. For each position x from `$31` to `$CF`, the code at x with `HSCROL` = 5 is equal to the code at x - 1 with `HSCROL` = 4.
6. For each `HSCROL` value 0-15, a `$1F` line (scrolled mode F) with all bytes `$FF` has code `%111` on exactly positions `$30-$CF` with `DMACTL` = `$22`, and on exactly positions `$40-$BF` with `DMACTL` = `$21`. All other positions in `$22-$DD` have code `%000`.
7. A `$1A` line (scrolled mode A, 4 scan lines) with `DMACTL` = `$22` starts with `HSCROL` = 0. A write of `$02` to `HSCROL` on cycle 110 of its first scan line moves its second scan line: for each position x from `$32` to `$CF`, the code at x on the second scan line is equal to the code at x - 2 on the first scan line.

## Notes

A wide scrolled line shows background on the left for larger `HSCROL` values. Changes to `HSCROL` in the middle of a scan line are in REQ-344.
