# REQ-500: Register addressing and mirrors

## Requirement

The emulator shall decode a POKEY access at address `$D2xy` as an access to register `$D20y`, and shall return `$FF` for a read of an address that has no readable register.

## Rationale

Software uses the mirrors of the POKEY registers. The OS and BASIC use the canonical addresses `$D200-$D20F`. The 65XE has one POKEY, so all 16 mirrors select the same chip.

## Acceptance criteria

1. A write of `$1F` to `$D2F1` makes the mix level 15 (channel 1 in volume-only mode, REQ-510). This is the same result as a write of `$1F` to `AUDC1` (`$D201`).
2. For each address `$D2xy` (x and y are `$0` to `$F`), a read returns the same value as a read of `$D20y` on the same cycle. The test makes the reads after power-on, and again after `SKCTL` = `$03`, `IRQEN` = `$FF` and 1000 cycles.
3. For each address `$D2xy`, a write of a value V changes the same register as a write of V to `$D20y`. The test reads the write-only registers through the test accessor (`docs/design/pokey.md`, "Test accessors").
4. A read of `$D20B`, `$D20C`, `$D2EB` or `$D2FC` returns `$FF` in the two states of criterion 2.
5. A write to `$D20C` does not change a register or a test accessor value.
6. For each offset, a read returns the register in the table in Notes, and a write changes the register in the table in Notes.

## Notes

| Offset | Read | Write |
| --- | --- | --- |
| `$0-$7` | `POT0-POT7` | `AUDF1`, `AUDC1`, `AUDF2`, `AUDC2`, `AUDF3`, `AUDC3`, `AUDF4`, `AUDC4` |
| `$8` | `ALLPOT` | `AUDCTL` |
| `$9` | `KBCODE` | `STIMER` |
| `$A` | `RANDOM` | `SKRES` |
| `$B` | `$FF` (no register) | `POTGO` |
| `$C` | `$FF` (no register) | No register |
| `$D` | `SERIN` | `SEROUT` |
| `$E` | `IRQST` | `IRQEN` |
| `$F` | `SKSTAT` | `SKCTL` |

The HRM states that unassigned POKEY reads return `$FF`, also on machines with a floating data bus. The stereo modification (a second POKEY on address line A4) is not part of the 65XE. It is out of scope.
