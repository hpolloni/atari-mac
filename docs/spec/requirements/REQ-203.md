# REQ-203: Side effects of all CPU bus accesses

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | System: clocks, memory map, bank switching, reset, PIA |
| Source | HRM 3.3 Cycle timing (Dead memory cycles); HRM 4.9 WSYNC (Bus activity during WSYNC) |
| Verification | Test |
| Depends on | REQ-101, REQ-202 |

## Requirement

The emulator shall send each CPU bus access, including dummy reads, dummy writes and repeated reads during RDY low, to the device at that address with the normal side effects.

## Rationale

Dummy cycles are real memory transactions (HRM 3.3). A read of a PIA data register clears pending interrupts, and cartridges can switch banks on a read of `$D5xx`.

## Acceptance criteria

1. Start: `PBCTL` = `$3C`, `PBCTL` bit 7 = 1 (after a CB1 high-to-low transition), `X` = `$11`. `LDA $D3F0,X` makes a dummy read of `$D301` and then reads `$D401`. After the instruction, `PBCTL` bits 7 and 6 are 0.
2. Start: `PBCTL` = `$3C`, `DDRB` = `$FF`, port B output register = `$FD`, code in RAM. `INC $D301` writes `$FD` and then `$FE` to `$D301`. The PIA receives 2 writes. After the instruction, `$C000` reads RAM (OS ROM disabled).
3. Start: a test cartridge that counts its `$D5xx` reads, `X` = `$20`. `LDA $D5F0,X` makes a dummy read of `$D510` and then reads `$D610`. The cartridge counts one read of `$D510`.
4. Start: a test cartridge that supplies `STA $D40A` at `$D500` and `NOP` at `$D503`. The CPU jumps to `$D500`. While RDY is low after the `STA`, the cartridge receives one read of `$D503` in each stopped cycle, and one more read for the opcode fetch.
