# REQ-429: GTIA mode 9 (16 luminances)

## Requirement

With `PRIOR` bits 6-7 = `%01`, the emulator shall show each playfield pixel p as `COLBK` OR p, treat the playfield as background for priority and collisions, and show any player or missile on top of it.

## Rationale

GRAPHICS 9 shows 16 luminances of one hue. It is the only way to set luminance bit 0, so it gives 256 colors in total.

## Acceptance criteria

1. With `PRIOR` = `$40` and `COLBK` = `$90`, pixel 7 shows `$97`.
2. With `PRIOR` = `$40` and `COLBK` = `$00`, pixel 15 shows `$0F` and pixel 14 shows `$0E`.
3. With `PRIOR` = `$44` (playfield over players) and `COLPM0` = `$46`, player 0 on pixels 1-15 shows `$46`.
4. With `PRIOR` = `$40` and `COLPM0` = `$46`, missile 0 on pixels 1-15 shows `$46`.
5. Removed: the fifth player is a non-goal (OI-019). The number is kept, so that the numbers of the other criteria do not change.
6. With `PRIOR` = `$40`, player 0 and missile 0 on pixels 1-15 set no bit in `P0PF` and `M0PF`.
