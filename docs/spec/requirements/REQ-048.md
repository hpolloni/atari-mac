# REQ-048: Each requirement has a planned verification

## Requirement

Each requirement that is not withdrawn shall be in the test plan of exactly one design document, and each requirement with the verification method `test` shall have at least one named test there.

## Rationale

The design document is the link between a requirement and its tests. A requirement without a plan cannot be verified.

## Acceptance criteria

1. A requirement that is in no test plan, or in the test plans of two design documents, makes the check fail.
2. A `test` requirement whose test plan row names no test in backticks makes the check fail.
3. An `inspection` or `demonstration` requirement whose test plan row does not name the evidence file (REQ-051) makes the check fail.
