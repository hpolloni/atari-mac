# REQ-210: Cartridge priority

## Requirement

In `$A000-$BFFF`, the emulator shall show cartridge ROM before BASIC ROM, and BASIC ROM before RAM. In `$8000-$9FFF`, the emulator shall show cartridge ROM before RAM.

## Rationale

If both the cartridge and BASIC are enabled, the cartridge is visible (HRM 2.6). Cartridge games must run with BASIC enabled.

## Acceptance criteria

1. A test cartridge with RD5 active (ROM at `$A000-$BFFF`), a BASIC image, `PORTB` pins = `$FD` (BASIC on). A CPU read of `$A000` returns the cartridge byte.
2. The test cartridge of criterion 1 makes RD5 inactive. With `PORTB` pins = `$FD`, a CPU read of `$A000` returns BASIC image byte `$0000`. With `PORTB` pins = `$FF`, a CPU read of `$A000` returns RAM.
3. A test cartridge with RD4 active (ROM at `$8000-$9FFF`). A CPU read of `$8000` returns the cartridge byte. With RD4 inactive, a CPU read of `$8000` returns RAM.
4. No cartridge, `PORTB` pins = `$FF` (BASIC off). A CPU write of `$C3` to `$A000`, then a CPU read of `$A000`, returns `$C3` (RAM).

## Notes

HRM 2.6 states the order for `$A000-$BFFF` only. HRM 8.1 gives `$8000-$9FFF` as the right cartridge window. The cartridge signals and types are in the REQ-600 range.

Criteria 2 and 4 also apply to a bank-switched cartridge that a bank switch disables (REQ-608). The media tests use the test images of `docs/design/media.md` for this. REQ-601 was merged into this requirement (OI-004).

FSM-800XL 1/Cartridge-Interface says that the hardware enables the built-in BASIC when no cartridge is plugged in. The HRM says that `PORTB` bit 1 enables the BASIC ROM (REQ-208). This requirement follows the HRM. TRN HW-VI.A, FAQ 1.14 and FAQ 1.15 (RD4, RAM deselect `$8000-$9FFF`) also show cartridge ROM before RAM at `$8000-$9FFF`.
