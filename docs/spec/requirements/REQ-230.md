# REQ-230: PIA reset

## Requirement

On a PIA reset, the emulator shall set `DDRA`, `DDRB`, both output registers, `PACTL` and `PBCTL` to `$00`, including the interrupt status bits.

## Rationale

A PIA reset disables all interrupts, selects the data direction registers, and makes all port bits inputs (HRM 2.5). The default memory map follows from this (REQ-211).

## Acceptance criteria

1. Before the reset: `DDRA` = `DDRB` = `$FF`, both output registers = `$FF`, `PACTL` = `$3D` with bit 7 = 1, `PBCTL` = `$3C`. After a PIA reset, reads of `PACTL` and `PBCTL` return `$00`.
2. After the reset, a read of `PORTA` returns `$00` (`DDRA`). A write of `$FF` to `PORTA` sets `DDRA` = `$FF`. After a write of `$04` to `PACTL`, a read of `PORTA` returns `$00` (the output register is `$00`).
3. After the reset, a write of `$FF` to `$D301` sets `DDRB` = `$FF`. Then `$C000` reads RAM (the output register is `$00`).
4. After the reset of criterion 1, the PIA does not assert IRQ.
