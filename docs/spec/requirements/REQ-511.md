# REQ-511: High-pass filters

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Should |
| Area | POKEY: audio, timers, keyboard, interrupts, serial port |
| Source | HRM 5.3 Sound generation (High-pass filter) |
| Verification | Test |
| Depends on | REQ-509, REQ-510 |

## Requirement

When `AUDCTL` bit 2 (or bit 1) is 1, the emulator shall copy the channel 1 (or 2) output flip-flop into a high-pass flip-flop on each fire of timer 3 (or 4). The channel output shall be the XOR of the two flip-flops. When the bit is 0, the high-pass flip-flop shall be 1.

## Rationale

Music players use the high-pass filter for special sounds. The inversion of channels 1 and 2 is audible when two channels play the same tone.

## Acceptance criteria

1. With `AUDCTL` = `$00`, `AUDF1` = `AUDF3` = `$10`, `AUDC1` = `AUDC3` = `$A8`, `AUDC2` = `AUDC4` = `$00` and an `STIMER` write, the mix level is 8 on each cycle for 10000 cycles.
2. With `AUDCTL` = `$00`, `AUDF1` = `AUDF2` = `$10`, `AUDC1` = `AUDC2` = `$A8`, `AUDC3` = `AUDC4` = `$00` and an `STIMER` write, the mix level is 0 or 16 on each cycle, and it changes between 0 and 16 every 476 cycles (17 x 28).
3. On NTSC, `AUDCTL` = `$64`, `AUDF1` = `$3B`, `AUDF3` = `$3C`, `AUDC1` = `$AF` and `AUDC3` = `$A0` make the channel 1 digital output repeat with a period of 4032 cycles (1789773 / 4032 = 443.9 Hz). At 48000 Hz, the measured frequency (REQ-503 Notes) of the audio output is 443.9 Hz +/- 1 Hz.
4. With `AUDCTL` = `$2A`, `AUDF2` = `$00`, `AUDF3` = `AUDF4` = `$00` and `AUDC2` = `$AF`, the channel 2 digital output changes to 1 on each fire of timer 2 and changes to 0 on the next fire of timer 4. The test selects an `STIMER` write cycle on which no fire of timer 2 is on the same cycle as a fire of timer 4.
5. With the setup of criterion 3, the channel 1 digital output is the same on each cycle for `AUDC3` = `$A0`, `$00`, `$1F`, `$8F` and `$C5`.

## Notes

The HRM states a delay of about 1.5 cycles from the high channel clock to the XOR output. The emulator works with whole cycles, so it does not show the half-cycle pulses that this delay causes. This is a project decision.
