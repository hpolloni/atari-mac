# REQ-054: Slice plans in frontmatter

## Requirement

Each slice file shall have YAML frontmatter that gives its status and, for each work package, its status and its requirement IDs.

## Rationale

The traceability check needs the packages and their status. Today it reads them from markdown tables.

## Acceptance criteria

1. The frontmatter has `id`, `title`, `status` and `packages`. Each package has `id`, `status` and `requirements`.
2. `status` is one of `planned`, `in-progress`, `done`.
3. Each requirement ID exists and is in at most one package of all slices.
4. A slice with `status: done` and a package that is not `done` makes the check fail.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
