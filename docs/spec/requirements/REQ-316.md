# REQ-316: Character modes 6 and 7

## Requirement

The emulator shall show IR modes 6 and 7 as lo-res text with 64 characters at the address `(CHBASE & $FE) << 8 | (name & $3F) << 3 | font row`, where each font bit gives one pixel of one color clock, and name bits 7-6 select the color of the 1 bits.

## Rationale

The OS uses mode 6 and mode 7 for Graphics 1 and Graphics 2.

## Acceptance criteria

1. In a mode 6 line, a character with name `$01` and font byte `$80` has code `%100` on its first color clock and code `%000` on its other 7 color clocks.
2. With font byte `$80`, the names `$01`, `$41`, `$81` and `$C1` give code `%100`, `%101`, `%110` and `%111` on the first color clock.
3. In a normal-width mode 6 line with names `$00` to `$13` and a different row 0 font byte for each name, positions `$30 + 8k` to `$37 + 8k` show the codes of the font byte of name k, for k = 0 to 19.
4. With `CHBASE` = `$E2` and a name of `$C1`, the font fetch for row 0 reads `$E208`.
5. In mode 6, row r (r = 0-7) reads font row r. In mode 7, row r (r = 0-15) reads font row r >> 1.
