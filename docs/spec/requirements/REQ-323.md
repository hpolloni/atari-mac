# REQ-323: Load memory scan counter

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | ANTIC |
| Source | HRM 4.6 Display list (Load Memory Scan (LMS) commands); HRM 4.14 Scan line timing (Display list DMA) |
| Verification | Test |
| Depends on | REQ-319 |

## Requirement

The emulator shall load the memory scan counter with the two bytes after a playfield mode instruction (IR modes 2-F) with bit 6 set, low byte first, before the playfield fetches of that mode line.

## Rationale

The memory scan counter gives the address of screen data. Every display list needs at least one LMS.

## Acceptance criteria

1. The instruction `$42 $00 $40` makes the first name fetch of that mode line read `$4000`.
2. With `DMACTL` = `$22`, the instructions `$42 $00 $40`, `$02` make the first name fetch of the second mode line read `$4028`.
3. A `$42` instruction on scan line N makes the next instruction fetch occur on scan line N + 8, the same as a `$02` instruction.
4. The address bytes are read on cycles 6 and 7 of the first scan line of the mode line (`DisplayListAddress`), the low byte on cycle 6.
