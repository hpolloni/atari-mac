# REQ-091: Tape shortcut option

## Requirement

The frontend shall turn on the tape shortcut (REQ-644) unless the command line has `--no-fast-tape`.

## Rationale

Most tapes load in seconds with the shortcut. A tape with a loader that the shortcut breaks still loads with `--no-fast-tape`.

## Acceptance criteria

1. Without `--no-fast-tape`, the machine of the frontend has the tape shortcut on.
2. With `--no-fast-tape`, the machine has the tape shortcut off, and a tape loads as in REQ-643 and REQ-082.
3. `--help` lists `--no-fast-tape`.
