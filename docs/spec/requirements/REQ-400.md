# REQ-400: GTIA register addressing and mirrors

## Requirement

The emulator shall decode each CPU access to `$D000-$D0FF` as an access to the GTIA register that address bits 0-4 select.

## Rationale

The canonical GTIA range is `$D000-$D01F`. The HRM states that accesses to `$D020-$D0FF` go to the same registers. Some software uses the mirror addresses.

## Acceptance criteria

1. After a CPU write of `$34` to `$D0FA`, the background pixels (code `%000`) of the next frame are `$34` in the frame buffer.
2. With the port 1 joystick button pressed, a read of `$D0F0` returns `$00`. With the button released, it returns `$01`.
3. For each of the 8 combinations of START, SELECT and OPTION, a read of `$D07F` returns the same value as a read of `$D01F`.
4. With at least one collision bit set in each of the 16 collision registers, a read of each address A in `$D020-$D0FF` returns the same value as a read of `$D000 + (A AND $1F)`.

## Notes

VBXE uses writes to `$D080-$D0FF` to detect a GTIA reset (HRM 6.1). The project does not emulate VBXE.
