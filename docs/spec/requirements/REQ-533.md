# REQ-533: Two-tone mode

## Requirement

When `SKCTL` bit 3 is 1, the emulator shall toggle SIO DATA OUT on each fire of timer 1 when the output data bit is 1 and on each fire of timer 2, and shall reload timers 1 and 2 two cycles after the reload of the timer that caused the toggle.

## Rationale

The OS cassette handler writes data to tape with two-tone mode.

## Acceptance criteria

1. On NTSC, with `AUDCTL` = `$00`, `AUDF1` = `$05`, `AUDF2` = `$07`, `SKCTL` = `$0B` and the output idle (data bit 1), SIO DATA OUT changes every 168 cycles (a 5327 Hz tone). With `SKCTL` = `$8B` (data bit forced to 0), SIO DATA OUT changes every 224 cycles (a 3995 Hz tone).
2. With `AUDCTL` = `$28`, `AUDF1` = `$05`, `AUDF2` = `$07`, `AUDF3` = `$CC`, `AUDF4` = `$05` and `SKCTL` = `$2B`, the test sends the byte `$55`. While a 1 bit is sent, SIO DATA OUT changes every 168 cycles. While a 0 bit is sent, it changes every 224 cycles. The test does not check the first change after each bit boundary.
3. With `AUDCTL` = `$40`, `AUDF1` = `$00`, `AUDF2` = `$FF`, `SKCTL` = `$0B`, the output idle and an `STIMER` write on cycle T, timer 1 fires on cycles T+8, T+14 and T+20, and on no other cycle from T to T+20. Timer 2 does not fire from T to T+1000.
4. In the setup of criterion 3 with `IRQEN` = `$03`, `IRQST` bit 1 reads 1 on each cycle from T to T+1000. `IRQST` bit 0 changes to 0 only on the fire cycles of timer 1.
5. In the setup of criterion 2 with `SKCTL` = `$AB`, SIO DATA OUT changes every 224 cycles during the whole frame.
6. For `AUDC1` = `AUDC2` = `$00`, `$1F`, `$8F` and `$AF`, the SIO DATA OUT levels of criterion 1 are the same on each cycle.

## Notes

Timer 2 must have the lower frequency. Otherwise timer 2 preempts timer 1, and the 1 bits have no tone. The HRM states that the Atari Hardware Manual block diagram is wrong here: the toggle input is ((channel 1 AND serial data) OR channel 2).

The tone frequencies in criterion 1 come from HRM 5.6: 1789773 / (6 x 28 x 2) = 5327 Hz and 1789773 / (8 x 28 x 2) = 3995 Hz.

TRN HW-II.C/Serial-Output and POKEY-SPEC 7 say that two-tone mode sends channel 1 in place of a 1 bit and channel 2 in place of a 0 bit. The HRM says that each fire of timer 2 toggles the output and resets timers 1 and 2, also while a 1 bit is sent (HRM 15.2 Errata). This requirement follows the HRM. ACID800 pokey_twotone checks that timer 2 fires less often while 1 bits are sent.

TRN OS-APP-K gives the cassette tones as 5327 Hz (mark) and 3995 Hz (space). The OS equates HITONE = `$05` and LOTONE = `$07` (TRN SRC-SIOORG, lines 1644-1645) are the `AUDF1` and `AUDF2` values of criterion 1. ACID800 pokey_timertiming states that in two-tone mode, the first period of timer 1 after `STIMER` has the usual length and the next periods are two cycles longer (criterion 3).
