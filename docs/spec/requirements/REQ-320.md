# REQ-320: Blank mode lines

## Requirement

The emulator shall show a display list instruction with bits 3-0 = `%0000` as a blank mode line of 1 to 8 scan lines, where bits 6-4 give the count minus one.

## Rationale

All OS display lists start with blank lines (`$70`).

## Acceptance criteria

1. For n = 0-7, an instruction `$n0` (`$00`, `$10`, ..., `$70`) on scan line N makes the next instruction fetch occur on scan line N + n + 1.
2. With `DMACTL` = `$22`, a blank mode line has code `%000` at positions `$22-$DD` on all of its scan lines, and `out.dma` is never `CharacterName`, `CharacterData` or `Bitmap`.
3. Instruction `$70` does no `DisplayListAddress` fetch on cycles 6 and 7. After a mode line with bit 5 clear, and with `VSCROL` = 4, `$70` has 8 scan lines (it does not start a scroll region).
4. With `NMIEN` = `$80`, an instruction `$F0` on scan lines N to N + 7 sets `NMIST` bit 7 on scan line N + 7 and causes one NMI there (REQ-332).
5. After a mode 2 line with bit 5 set, an instruction `$70` with `VSCROL` = 2 has 3 scan lines (rows 0-2) (REQ-328).
