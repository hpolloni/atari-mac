# REQ-128: CPU power-on state

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Should |
| Area | CPU (6502C) |
| Source | Project decision |
| Verification | Test |
| Depends on | REQ-124 |

## Requirement

The emulator shall set `A`, `X`, `Y`, `S` and the stored bits of `P` to `$00` at power-on, before the reset sequence.

## Rationale

The 6502 register contents at power-on are undefined (HRM 3.6 for `D`). Fixed values make each run of the emulator the same. Tests and replays need this.

## Acceptance criteria

1. Directly after `Cpu::new`, before the first tick: `A` = `X` = `Y` = `S` = `$00` and `P` = `$30` (all stored bits 0).
2. After `Cpu::new` and the 7 ticks of the reset sequence: `A` = `X` = `Y` = `$00`, `S` = `$FD` and `P` = `$34` (`I` = 1, all other stored bits 0).
3. Two CPUs created with `Cpu::new`, on two flat 64 KB buses with the same contents, make the same bus accesses in the first 100,000 ticks.

## Notes

The HRM says that `D` is undefined at power-up on the 6502 (HRM 3.6). It does not give other register values. The values here are a project decision. `S` = `$FD` follows from REQ-124.
