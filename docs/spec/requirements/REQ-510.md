# REQ-510: Volume and volume-only mode

## Requirement

The emulator shall make each channel add its `AUDCx` bits 0-3 volume to the mix when the channel output is 1, and nothing when it is 0. When `AUDCx` bit 4 is 1, the channel output shall be 1.

## Rationale

Volume-only mode plays 4-bit digital samples. Many games and demos use it for speech and drums.

## Acceptance criteria

"Mix level" is the sum of the four channel levels (test accessor).

1. With `AUDC1` = `$1F` and `AUDC2-4` = `$00`, the mix level is 15 on each cycle for 10000 cycles. This is true with `AUDCTL` = `$00` and with `AUDCTL` = `$40`, with `AUDF1` = `$00`.
2. With `AUDC1` = `$10` and `AUDC2-4` = `$00`, the mix level is 0 on each cycle for 10000 cycles.
3. With `AUDC1` = `$18`, `AUDC3` = `$18` and `AUDC2` = `AUDC4` = `$00`, the mix level is 16 on each cycle for 1000 cycles after an `STIMER` write, for each of the 256 `AUDCTL` values.
4. With `AUDCTL` = `$01`, `AUDF1` = `AUDF3` = `$FF`, `AUDC1` = `$AF`, `AUDC3` = `$A7`, `AUDC2` = `AUDC4` = `$00` and an `STIMER` write on cycle T, the mix level is 7 on each cycle from T+1 to T+1000. Channel 1 has output 0 and adds nothing. Channel 3 has output 1 and adds 7.
5. With `AUDCTL` = `$20`, `AUDF3` = `$00`, `AUDC3` = `$BF` and an `STIMER` write on cycle T, timer 3 fires on cycles T+8 and T+12. The channel 3 flip-flop (test accessor) changes on each fire, and the digital output stays 1. A write of `AUDC3` = `$AF` on cycle T+10 makes the digital output 0 on cycle T+11 and 1 on cycle T+12.
6. With `AUDC1-4` = `$1F`, the mix level is 60.

## Notes

The mix level is the sum of the channel volumes before the host output stage (REQ-539). Its range is 0-60.

The override of volume-only mode comes after the high-pass XOR. So the inversion of channels 1 and 2 (REQ-511) does not apply in this mode.
