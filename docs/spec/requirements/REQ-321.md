# REQ-321: Jump instruction

## Requirement

The emulator shall execute a display list instruction with bits 3-0 = `%0001` and bit 6 = 0 as a jump: ANTIC loads the next two bytes (low byte first) into `DLISTL`/`DLISTH` and shows one blank scan line.

## Rationale

Display lists use jumps to loop or to continue in other memory.

## Acceptance criteria

1. The instruction `$01 $00 $30` makes the next instruction fetch read `$3000`.
2. A jump on scan line N makes the next instruction fetch occur on scan line N + 1. Positions `$22-$DD` of scan line N have code `%000`.
3. The instruction `$31 $00 $30` gives the same result as `$01 $00 $30`. After a mode line with bit 5 clear, and with `VSCROL` = 4, it has 1 scan line, and the next instruction fetch reads `$3000`.
4. A jump at `$07FD` with the target `$4400` makes the next instruction fetch read `$4400` (REQ-324 does not apply to the jump).
5. With `NMIEN` = `$80`, the instruction `$81 $00 $30` on scan line N sets `NMIST` bit 7 on cycle 7 of scan line N and causes one NMI there.
