# REQ-123: No interrupt directly after an interrupt sequence

## Requirement

The emulator shall execute the first instruction of an interrupt handler before it starts a different interrupt sequence, unless that instruction is `BRK`.

## Rationale

The 6502 cannot acknowledge an interrupt directly after an interrupt sequence (HRM 3.4).

## Acceptance criteria

1. An IRQ sequence runs in cycles N-6 to N. The NMI line goes high in cycle N. The first instruction of the IRQ handler (`NOP`) runs in cycles N+1 and N+2. The NMI sequence starts in cycle N+3.
2. An NMI sequence runs in cycles S to S+6. The NMI line goes low in cycle S+5 and high again in cycle S+6. The first instruction of the NMI handler (`NOP`) runs in cycles S+7 and S+8. The second NMI sequence starts in cycle S+9.
3. An IRQ sequence runs in cycles N-6 to N. The first instruction of the IRQ handler is `BRK` at `$3000`. The NMI line goes high in cycle N. The `BRK` sequence runs in cycles N+1 to N+7. It pushes the return address `$3002` and `P` with bit 4 = 1, and reads `$FFFA` and `$FFFB`.
