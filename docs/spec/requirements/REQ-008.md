# REQ-008: Window display

## Requirement

The frontend shall show each frame in a window on macOS, scaled by an integer factor.

## Rationale

The user must see the Atari display without distortion.

## Acceptance criteria

1. At the default scale 2, the window content is 768 x 480 pixels, and each frame buffer pixel is a block of 2 x 2 window pixels.
2. `--scale 3` gives a window content of 1152 x 720 pixels.
3. The window title contains the file name of the loaded media, or `atari-mac` without media.

## Notes

Project decision: one frame buffer pixel (one high-resolution pixel by one scanline) is shown as a square. On a TV it is a little narrower than tall.
