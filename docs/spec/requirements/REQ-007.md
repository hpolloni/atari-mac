# REQ-007: Real-time speed

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Frontend |
| Source | Project decision |
| Verification | Demonstration |
| Depends on | REQ-001 |

## Requirement

In a release build, the frontend shall run the emulation at the frame rate of the selected video standard (59.92 Hz NTSC, 49.86 Hz PAL).

## Rationale

Games and audio need the correct speed.

## Acceptance criteria

1. On an Apple Silicon Mac, `atari-mac --frames 600` (window and audio on) prints an elapsed time of 10.01 s, with an error of no more than 1 percent (600 / 59.9227 Hz = 10.013 s).
2. On the same Mac, `atari-mac --headless --frames 6000` in a release build finishes in no more than 10.0 s (at least 10 times real time).
