# REQ-014: Deterministic core

## Requirement

For the same ROMs, media and input sequence, the emulation core shall produce the same frames and audio samples on every run and on every host.

## Rationale

Tests that compare frames are reliable only when the core is deterministic.

## Acceptance criteria

1. Two machines created with the same `MachineConfig` and run for 300 frames give equal frame buffers after each frame and equal audio sample sequences.
2. The `clippy.toml` setting `disallowed-methods` lists `std::time::Instant::now`, `std::time::SystemTime::now` and `std::env::var`, and `atari-core` passes clippy.

## Notes

Project decision: a product rule of the emulator. The HRM does not cover it.
