# REQ-342: Light pen position registers

## Requirement

The emulator shall latch the horizontal position counter into `PENH` and bits 8-1 of the vertical counter into `PENV` when the light pen input changes from not asserted to asserted.

## Rationale

Light pen and light gun programs read these registers. The light pen input on ANTIC is connected to the joystick trigger lines.

## Acceptance criteria

1. The light pen input changes from not asserted to asserted on scan line 100, cycle 50. Then `PENV` reads `$32` and `PENH` reads `$64`.
2. The light pen input changes to asserted on scan line 101, cycle 112. Then `PENV` reads `$33` (the vertical counter shows the next scan line, REQ-338).
3. For an input change on cycle c (c = 0-113), `PENH` reads 2 × c (0-226) (project decision).
4. If the input stays asserted for 2 frames, `PENH` and `PENV` keep the values of the latch.
5. `PENH` and `PENV` keep their values across vertical blank and across a reset.
6. In the full machine, a press of the trigger of joystick port 1 or of port 2 on scan line 100 makes `PENV` read `$32`.

## Notes

The HRM does not give the register addresses. Project decision: `PENH` is `$D40C` and `PENV` is `$D40D` (see REQ-301).

The HRM does not give the exact relation between the cycle and the `PENH` value. Project decision: `PENH` = 2 × cycle at the latch. The HRM says that real `PENH` values are 30 to 60 counts higher than GTIA positions because of delays in the display and the pen.

The 65XE has two joystick ports. HRM 7.4 says that a trigger on any port of the 800/XL/XE latches the position.
