# REQ-227: CA2 and CB2 output modes

## Requirement

The emulator shall drive CA2 (SIO motor) and CB2 (SIO command) low for bits 5-3 = `110`, high for `111`, and with the pulse modes `100` and `101` of HRM 14.5.

## Rationale

The OS pulls the command line low while it sends a command to an SIO device. It pulls the motor line low to start the cassette (HRM 2.5). The SIO device emulation needs these levels.

## Acceptance criteria

1. A write of `$34` to `PBCTL` makes the SIO command line (CB2) low. A write of `$3C` to `PBCTL` makes it high.
2. A write of `$34` to `PACTL` makes the SIO motor line (CA2) low. A write of `$3C` to `PACTL` makes it high.
3. `PACTL` = `$2C` (bits 5-3 = `101`). A read of `PORTA` in machine cycle c makes CA2 low at the end of cycle c. CA2 is high again at the end of cycle c+1.
4. `PACTL` = `$24` (bits 5-3 = `100`, bit 1 = 0). A read of `PORTA` makes CA2 low. CA2 stays low until a CA1 high-to-low transition, and is high after it.
5. `PBCTL` = `$2C`. A write of `PORTB` in machine cycle c makes CB2 low at the end of cycle c, and high again at the end of cycle c+1. `PBCTL` = `$24`. A write of `PORTB` makes CB2 low until a CB1 high-to-low transition.

## Notes

HRM 14.5 gives the pulse modes in one line each. Other details of the 6520 modes are in [MOS76], which this project does not use. The HRM does not say in which cycle the one-cycle pulse occurs. The pulse in the cycle after the access is a project decision. The SIO bus behavior is in the REQ-600 range.
