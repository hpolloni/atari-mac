# REQ-325: Memory scan counter 4K boundary

## Requirement

The emulator shall increment only the low 12 bits of the memory scan counter during playfield fetches, so that the address wraps from the top of a 4K block to the bottom of the same block.

## Rationale

A scan line that crosses a 4K boundary wraps to the start of the 4K block in the middle of the scan line. The OS puts its large screens so that the boundary is between scan lines.

## Acceptance criteria

1. With `DMACTL` = `$22`, in a mode E line with LMS `$2FF0`, the 16th fetch reads `$2FFF` and the 17th fetch reads `$2000`.
2. The first fetch of the next mode E line without LMS reads `$2018`.
3. An LMS of `$3FF0` on the mode line after that makes its first fetch read `$3FF0` (an LMS loads all 16 bits).
