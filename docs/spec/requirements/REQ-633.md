# REQ-633: Empty drive

## Requirement

When no image is inserted in D1:, the disk drive shall reply to Status as REQ-627 gives, and shall reply to Read, Put, Write and Format with a valid sector number (1-65535 for Read, Put and Write) with ACK and then Error (`$45`).

## Rationale

The OS sends commands to D1: at boot also when no disk is inserted. The 1050 rev. K and rev. L return an error for a disk access with no disk, with no motor start.

## Acceptance criteria

No image is inserted in D1: in all criteria. The computer sends each data frame with its checksum (REQ-616).

1. Status: the drive sends `41 43 00 7F E0 00 60`.
2. Read sector 1: the drive sends `41`, `45`, 128 bytes of `$00` and `00`.
3. Read sector 65535 (AUX1 = AUX2 = `$FF`): the drive sends `41`, `45`, 128 bytes of `$00` and `00`.
4. Put sector 1 with 128 bytes of `$5A`: the drive sends `41`, receives the data frame, sends `41`, then `45`.
5. Write sector 1 with 128 bytes of `$5A`: the drive sends `41`, receives the data frame, sends `41`, then `45`.
6. Format `$21`: the drive sends `41`, `45`, 128 bytes of `$FF` and `FF`.
7. Read sector 0 gets NAK (REQ-628).

## Notes

With no image, the drive does not know the sector count. It accepts sector numbers 1-65535 and sends Error. The data bytes of the Read frame are `$00`, and the data bytes of the Format frame are `$FF`. These are project decisions.
