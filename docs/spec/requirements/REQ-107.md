# REQ-107: Processor status register and pushed flags

## Requirement

The emulator shall not store bits 4 and 5 of `P`, and shall push them as 1 and 1 for `PHP` and `BRK`, and as 0 and 1 for an IRQ or NMI sequence.

## Rationale

The B bit does not exist in the `P` register. It is visible only in the copy that the CPU pushes (HRM 3.1). Interrupt handlers use bit 4 on the stack to tell `BRK` from IRQ.

## Acceptance criteria

1. `LDA #$00`, `PHA`, `PLP`, `PHP`, `PLA` gives `A` = `$30`.
2. Start: `P` = `$C1` (`I` = 0), the IRQ line asserted. The IRQ sequence writes `$E1` to the stack.
3. Start: `P` = `$C5`. The NMI sequence writes `$E5` to the stack. (This is not the `BRK` hijack case of REQ-122.)
4. Start: `P` = `$C1`. `BRK` writes `$F1` to the stack.

## Notes

The Set Overflow (SO) input is not used on the main computer (HRM 3.1). The emulator does not need an SO input.
