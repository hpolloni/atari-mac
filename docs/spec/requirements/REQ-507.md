# REQ-507: STIMER

## Requirement

On a write to `STIMER`, the emulator shall reload all four timer counters from `AUDF1-4` and set the output flip-flops of all four channels to 1. The write shall not make a timer fire.

## Rationale

Software uses `STIMER` to start the channels in phase. The OS SIO code writes `STIMER` before each transfer.

## Acceptance criteria

1. With `AUDCTL` = `$00` and `AUDC1-4` = `$AF`, the digital outputs on the cycle after an `STIMER` write are 0 for channels 1 and 2 and 1 for channels 3 and 4. The test checks this for the flip-flop values 0, 0, 0, 0 and 1, 1, 1, 1 before the write. The test sets these values with timer fires before the write.
2. With `AUDCTL` = `$60`, `AUDF1` = `$00` and `AUDF3` = `$05`, after an `STIMER` write on cycle T, the next fire of timer 1 is on cycle T+8 and the next fire of timer 3 is on cycle T+13. This is true for 10 different start values of the counters.
3. With `AUDCTL` = `$00` and `AUDF2` = `AUDF4` = `$03`, after an `STIMER` write on cycle T, the first fires of timers 2 and 4 are on the same cycle, in the range T+92 to T+119.
4. With `IRQEN` = `$07`, an `STIMER` write does not change `IRQST`. With the setup of criterion 2 and `AUDC1` = `$AF`, the channel 1 flip-flop changes only on the fire cycles of timer 1. The `STIMER` write itself is not a fire.
5. With `SKCTL` = `$03` written on cycle W, `AUDCTL` = `$00` and `AUDF1` = `$00`, all fires of timer 1 are on cycles W + 24 + 28k (k = 0, 1, 2, ...). The test checks this with one `STIMER` write on each of the cycles W+100 to W+127, one cycle in each run.

## Notes

With the high-pass filters off, channels 1 and 2 have an inverted output (REQ-511). So after `STIMER`, channels 1 and 2 are off and channels 3 and 4 are on.

POKEY-SPEC 5 says that `STIMER` forces the audio outputs of channels 1 and 2 to logic high and of channels 3 and 4 to logic low. The HRM says that this is backwards if logic high is the state that makes sound (HRM 14.4, Errata). This requirement follows the HRM.

TRN HW-III.F/STIMER states only that `STIMER` resets all frequency dividers to their `AUDF` values. ACID800 pokey_timertiming checks the first fire of timer 1 after `STIMER` and the last `STIMER` write that prevents a fire.
