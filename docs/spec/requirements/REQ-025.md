# REQ-025: Keyboard input test

## Requirement

The test harness shall type text through the emulated keyboard, and shall check the result on the screen.

## Rationale

This tests POKEY keyboard scan, the keyboard IRQ and the OS editor.

## Acceptance criteria

1. After the `Ready` prompt, `type_text("PRINT 2+2\n")` and 60 more frames, the screen has a row `4`, then an empty row, then a row `Ready` (leading and trailing spaces removed).
2. `type_text` with a character that has no key returns `HarnessError::NoKey` with that character.
