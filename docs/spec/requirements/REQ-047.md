# REQ-047: Cross-references resolve

## Requirement

Each reference to a requirement, an open item, a slice or a design document in `docs/` and in the source code shall point to a file that exists.

## Rationale

A broken reference hides a gap in the trace from requirement to test.

## Acceptance criteria

1. Each `REQ-NNN`, `OI-NNN` and `SLICE-NN` in `docs/` and in `.rs` files names an existing file. A range `REQ-NNN to REQ-NNN` is checked at both ends.
2. Each relative markdown link in `docs/` and in `README.md` points to an existing file.
3. A reference to a withdrawn requirement is permitted only in a requirement file, an open item, or a line that says the requirement is withdrawn or merged.
4. A broken reference makes the check fail. The message gives the file, the line and the reference.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
