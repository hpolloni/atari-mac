# REQ-622: Drive transmit timing

## Requirement

A disk drive shall send each byte with a bit period of 51 µs, and shall start the bytes of one frame 549 µs apart, as the Atari 1050 does.

## Rationale

Software that measures the load speed, and the tone that POKEY makes during a sector read, depend on the byte rate. The 1050 sends at 51 cycles per bit and 549 cycles per byte at 1 MHz.

## Acceptance criteria

All criteria use Read sector 1 of the SD test image of REQ-619, and Read sector 1 with no image in D1: (REQ-633). The drive sends 131 bytes for each command: ACK, Complete or Error, 128 data bytes and the checksum.

1. The bit period of each of the 131 bytes is 91 machine cycles (NTSC) or 90 machine cycles (PAL).
2. From the first data byte to the checksum byte, the start bits of two bytes that follow each other are 983 machine cycles (NTSC) or 974 machine cycles (PAL) apart.
3. The first data byte starts 983 (NTSC) or 974 (PAL) machine cycles after the start of the Complete or Error byte.
4. Criteria 1 to 3 pass for NTSC and for PAL.

## Notes

The cycle counts are the times at the CPU clocks in REQ-618, rounded to the nearest cycle.

The HRM states that the delay from the Complete byte to the data frame is not specified and can be zero. This emulator uses the normal byte period.
