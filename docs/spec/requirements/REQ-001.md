# REQ-001: Target machine

## Requirement

The emulator shall emulate an Atari 65XE with 64 KB of RAM, a 6502C CPU, ANTIC, GTIA, POKEY and a 6520 PIA.

## Rationale

The 65XE is the target of this project. Other models add hardware that is not in scope.

## Acceptance criteria

1. The `atari-core` crate has one module for each chip in the requirement.
2. The memory map gives 64 KB of RAM and no extended memory.

## Notes

Out of scope: extended memory (130XE), 65C02 and 65C816 CPUs, PBI devices and memory upgrades.

The choice of the 65XE as the target machine is a project decision. FAQ 1.7 gives the 65XE hardware: 64 KiB of RAM, the Atari SALLY 6502 (FAQ 1.12: the Atari XE manuals call it "6502C"), ANTIC and GTIA. FAQ 1.12 gives the PIA and POKEY as the other chips of each Atari 8-bit computer.
