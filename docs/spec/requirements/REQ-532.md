# REQ-532: Force break

## Requirement

When `SKCTL` bit 7 is 1 and `SKCTL` bit 3 is 0, the emulator shall drive SIO DATA OUT to 0.

## Rationale

Some serial programs send a break condition.

## Acceptance criteria

1. With the output idle (SIO DATA OUT = 1) and `SKCTL` = `$03`, a write of `SKCTL` = `$83` on cycle X makes SIO DATA OUT read 0 from cycle X+1. A later write of `SKCTL` = `$03` on cycle Y makes SIO DATA OUT read 1 from cycle Y+1.
2. In the setup of REQ-525 criterion 1 with `SKCTL` = `$A3`, SIO DATA OUT reads 0 on each cycle of the frame and after it. `IRQST` bits 3 and 4 change on the same cycles as with `SKCTL` = `$23`.
3. In criterion 2, a write of `SKCTL` = `$23` on cycle L+300 (during data bit 2, which is 1) makes SIO DATA OUT read 1 from cycle L+301. The rest of the frame has the levels and the cycles of REQ-525 criterion 2.

## Notes

With two-tone mode on, force break selects the tone of timer 2 (REQ-533).

TRN HW-II.C/Serial-Output and POKEY-SPEC 7 state that `SKCTL` bit 7 forces the output to 0, or to channel 2 in two-tone mode.
