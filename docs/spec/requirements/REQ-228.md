# REQ-228: Clear of PIA interrupt status

## Requirement

The emulator shall clear both interrupt status bits of a port on a read of its data register, shall not clear them on a read of its data direction register or on a disable, and shall clear bit 6 when CA2 or CB2 changes to an output mode.

## Rationale

PIA interrupt handlers must read the data register to acknowledge an interrupt (HRM 2.5). Disabling an interrupt does not clear the status, unlike POKEY.

## Acceptance criteria

1. `PACTL` = `$04`. A CA1 and a CA2 high-to-low transition set `PACTL` bits 7 and 6. A read of `PORTA` (port A data register) clears both bits: `PACTL` reads `$04`.
2. `PACTL` = `$00` (bit 2 = 0). A CA1 and a CA2 high-to-low transition set `PACTL` bits 7 and 6. A read of `PORTA` (`DDRA`) does not clear the bits: `PACTL` reads `$C0`.
3. `PBCTL` = `$0D` (bits 0 and 3 = 1). A CB1 and a CB2 high-to-low transition set `PBCTL` bits 7 and 6. A write of `$04` to `PBCTL` clears bits 0 and 3. `PBCTL` reads `$C4`.
4. `PACTL` = `$04`, `PACTL` bits 7 and 6 = 1. A write of `$34` to `PACTL` (bits 5-3 = `110`) clears bit 6 and keeps bit 7. `PACTL` reads `$B4`.
