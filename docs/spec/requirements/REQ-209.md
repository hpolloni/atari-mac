# REQ-209: Self-test ROM control

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Should |
| Area | System: clocks, memory map, bank switching, reset, PIA |
| Source | HRM 2.6 Bank switching (ROM control); HRM 14.5 PIA registers (PORTB) |
| Verification | Test |
| Depends on | REQ-207 |

## Requirement

The emulator shall show the OS ROM bytes of `$D000-$D7FF` at `$5000-$57FF` when `PORTB` pin 7 = 0 and pin 0 = 1, and RAM there in all other cases.

## Rationale

The OS uses the self-test ROM for the built-in self-test. Some programs clear bit 7 by mistake and then see ROM at `$5000`.

## Acceptance criteria

1. `PORTB` pins = `$7F` (pin 7 = 0, pin 0 = 1). CPU reads of `$5000` and `$57FF` return the OS image bytes `$1000` and `$17FF`.
2. `PORTB` pins = `$7E` (pin 7 = 0, pin 0 = 0). For each address in `$5000-$57FF`, a CPU write and then a CPU read give the written value.
3. `PORTB` pins = `$FF` (pin 7 = 1). For each address in `$5000-$57FF`, a CPU write and then a CPU read give the written value.
