# REQ-103: Indexed writes always take the extra cycle

## Requirement

The emulator shall execute `abs,X`, `abs,Y` and `(zp),Y` stores with the extra cycle, as a dummy read followed by the write to the effective address, also when no page is crossed.

## Rationale

Writes cannot be speculative, because a wrong guess would change an unrelated location (HRM 3.3). Software that writes to hardware registers with indexed stores sees the dummy read.

## Acceptance criteria

1. Start: `X` = `$20`. `STA $D2F0,X` takes 5 cycles. Cycle 4 reads `$D210`. Cycle 5 writes `A` to `$D310`.
2. Start: `X` = `$01`. `STA $2000,X` takes 5 cycles. Cycle 4 reads `$2001`. Cycle 5 writes `A` to `$2001`.
3. Start: `Y` = `$20`. `STA $20F0,Y` takes 5 cycles. Cycle 4 reads `$2010`. Cycle 5 writes `A` to `$2110`.
4. Start: `Y` = `$01`, `$0040` = `$00`, `$0041` = `$20`. `STA ($40),Y` takes 6 cycles. Cycle 5 reads `$2001`. Cycle 6 writes `A` to `$2001`.
5. Start: `Y` = `$20`, `$0040` = `$F0`, `$0041` = `$20`. `STA ($40),Y` takes 6 cycles. Cycle 5 reads `$2010`. Cycle 6 writes `A` to `$2110`.
