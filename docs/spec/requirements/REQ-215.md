# REQ-215: Power-on RAM contents

## Requirement

The emulator shall fill RAM with `$00` at power-on.

## Rationale

RAM contents at power-on are undefined (HRM 2.3). A fixed value makes runs repeatable. Software must not depend on the value.

## Acceptance criteria

1. After power-on and before the first machine cycle, all 65,536 RAM bytes (also the RAM under ROM and under `$D000-$D7FF`) are `$00`.
2. A program writes `$55` to `$1000` and `$FF` to `$E000` (RAM under the OS ROM). After a second power-on, all 65,536 RAM bytes are `$00`.
3. Two machines with the same configuration run one frame after power-on. Their 65,536 RAM bytes are equal.

## Notes

The fill value is a project decision. The HRM says that one possible pattern after a long power-off is alternating `$00` and `$FF` bytes.
