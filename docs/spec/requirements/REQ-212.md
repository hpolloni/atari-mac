# REQ-212: Time of a bank switch

## Requirement

The emulator shall apply a memory map change from a CPU write to the port B data register or to `DDRB` to all bus accesses after the write cycle.

## Rationale

Code that switches the OS ROM off and then reads the RAM under it in the next instruction must see RAM.

## Acceptance criteria

1. Code in RAM. `PBCTL` = `$3C`, `DDRB` = `$FF`, RAM at `$E000` = `$AA`. `LDA #$FE`, `STA $D301`, `LDA $E000` gives `A` = `$AA`.
2. Code in RAM. `PBCTL` = `$38` (`DDRB` selected), port B output register = `$00`, `DDRB` = `$00`, RAM at `$E000` = `$AA`. `LDA #$01`, `STA $D301`, `LDA $E000` gives `A` = `$AA`.
3. The CPU write that disables the OS ROM is in machine cycle c. RAM at `$E000` = `$AA`. An ANTIC DMA read of `$E000` in cycle c+1 returns `$AA`.

## Notes

The HRM does not give a delay for the MMU. The change in the next cycle is a project decision.
