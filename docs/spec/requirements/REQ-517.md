# REQ-517: IRQEN write timing

## Requirement

The emulator shall latch an interrupt only if the `IRQEN` write that enables it occurs at least 4 cycles before the cycle on which the event shows in `IRQST`, and shall block an interrupt only if the `IRQEN` write that disables it occurs at least 2 cycles before that cycle.

## Rationale

Some programs enable or disable a timer IRQ just before it fires. The result depends on this timing.

## Acceptance criteria

In both criteria, `AUDCTL` = `$40`, `AUDF1` = `$00` and an `STIMER` write on cycle T make the first timer 1 event on cycle E = T+8 (REQ-506 criterion 1).

1. With `IRQEN` = `$00` before T, a write of `IRQEN` = `$01` on cycle T+4 (E-4) makes `IRQST` bit 0 read 0 on cycle T+8. A write of `IRQEN` = `$01` on cycle T+5 (E-3) makes `IRQST` bit 0 read 1 on cycles T+8 to T+11 and 0 on cycle T+12.
2. With `IRQEN` = `$01` before T, a write of `IRQEN` = `$00` on cycle T+6 (E-2) makes `IRQST` bit 0 read 1 on each cycle from T+7 to T+20. A write of `IRQEN` = `$00` on cycle T+7 (E-1) makes `IRQST` bit 0 read 0 and `irq()` return true on cycle T+8.

## Notes

The HRM example gives "an IRQ on cycle 16" with the last enabling write on cycle 12 and the last blocking write on cycle 14. The project reads "cycle 16" as the cycle on which the event shows in `IRQST`.
