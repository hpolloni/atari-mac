# REQ-336: WSYNC

## Requirement

The emulator shall, after a CPU write to `WSYNC` on cycle c (c <= 103), let the CPU run cycle c + 1, then hold the CPU RDY line low from cycle c + 2 until the end of cycle 104, so that CPU read cycles in that time wait until cycle 105.

## Rationale

DLI handlers and display kernels use `WSYNC` to start code at a fixed position in the scan line.

## Acceptance criteria

1. With `DMACTL` = `$00`, `STA WSYNC` has its write on cycle 50, followed by `STX $0600`. The `STX` opcode fetch is on cycle 51, and the `STX` write is on cycle 107.
2. With `DMACTL` = `$00`, `STA WSYNC` has its write on cycle 56. Refresh DMA uses cycle 57. The `STX $0600` write is on cycle 108.
3. On the first scan line of a mode 6 line with `DMACTL` = `$23` (character data fetch on cycle 105), `STA WSYNC` has its write on cycle 99, followed by `STX $0600`. The `STX` write is on cycle 108.
4. On the first scan line of a `$12` line with `DMACTL` = `$21` and `HSCROL` = 14 (refresh on cycle 105), `STA WSYNC` has its write on cycle 20, followed by `STX $0600`. The `STX` write is on cycle 108. On the first scan line of a mode 2 line with `DMACTL` = `$23` (character data fetch on cycle 105 and refresh on cycle 106), `STA WSYNC` has its write on cycle 8, followed by `STX $0600`. The `STX` write is on cycle 109.
5. In an ANTIC unit test, after a `WSYNC` write on cycle c (0 <= c <= 103), `out.rdy` is `true` on cycle c + 1, `false` on cycles c + 2 to 104, and `true` on cycle 105.

## Notes

RDY is not the same signal as the DMA halt (REQ-310). The 6502 ignores RDY on write cycles. Interrupts wait until the instruction after the `WSYNC` write completes.

The CPU behavior while RDY is low is in REQ-126: the CPU repeats its read cycle in each cycle and does write cycles normally. REQ-337 criteria 2 and 3 check the write cycles of `INC WSYNC`.

The test setups of criteria 3 and 4 follow from the start cycles of REQ-309 and the refresh rule of REQ-341. HRM 4.9 names these three cases (playfield DMA on cycle 105, refresh DMA on cycle 105, and playfield DMA on cycle 105 with refresh DMA on cycle 106).

TRN HW-II.A/Cycle-Counting says in the text that the processor restarts exactly 7 machine cycles before the start of the next TV line (cycle 107). The Horizontal Blank DMA Timing figure of the same section shows the `WSYNC` release 9 cycles before the end of the scan line (cycle 105). The HRM says that execution resumes on cycle 105. This requirement follows the HRM.
