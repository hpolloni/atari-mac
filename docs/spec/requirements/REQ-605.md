# REQ-605: CAR cartridge images

## Requirement

The emulator shall load a CAR image of type 1 as a standard 8 KB cartridge and a CAR image of type 2 as a standard 16 KB cartridge.

## Rationale

The CAR format has a header that gives the cartridge type. Emulators use it for cartridge types that the size cannot identify.

## Acceptance criteria

The test files use the offset pattern: data byte `i` holds `(i >> 8) & $FF`.

1. The file with the header `43 41 52 54 00 00 00 01 00 01 F0 00 00 00 00 00` (`CART`, type 1, checksum `$0001F000`) and 8192 data bytes loads with no error. The cartridge kind is standard 8 KB. A read of `$A100` gives `$01`, and a read of `$BFFF` gives `$1F`.
2. The file with the header `43 41 52 54 00 00 00 02 00 07 E0 00 00 00 00 00` (`CART`, type 2, checksum `$0007E000`) and 16384 data bytes loads with no error. The cartridge kind is standard 16 KB. A read of `$8100` gives `$01`, and a read of `$A000` gives `$20`.
3. The file of criterion 1 with header bytes 12-15 set to `FF FF FF FF` loads with no error.

## Notes

The CAR header and the type numbers are from CART-TXT. The CART-TXT introduction (it has no section key) gives the header: `CART`, the type (MSB first), the checksum (MSB first, of the ROM data only), 4 unused bytes (zero), and then the ROM data. CART-TXT does not give the checksum calculation. The checksum calculation in the format table, and to ignore bytes 12-15, are project decisions.

The HRM does not describe the CAR format. The HRM 8.6 SIDE 3 section refers to "the banking mode as specified in the CAR file format", but it gives no type numbers.

CART-TXT gives type 41 for the Atarimax 128 KB Flash cartridge (MaxFlash 1Mbit) and type 42 for the "old" Atarimax 1 MB Flash cartridge (MaxFlash 8Mbit). Type 75 is the "new" Atarimax 1 MB Flash cartridge. CART-TXT gives one difference between types 42 and 75: the bank at power-up (REQ-607).

To decide: this requirement does not cover the load of CAR types 41 and 42. REQ-608 gives only the bank switching of these cartridges.

### Format

| Offset | Size | Contents |
| --- | --- | --- |
| 0 | 4 | ASCII `CART` |
| 4 | 4 | Cartridge type, big-endian |
| 8 | 4 | Checksum, big-endian: the sum of all data bytes, modulo 2^32 |
| 12 | 4 | Not used. The emulator ignores these bytes. |
| 16 | n | ROM data, in the same order as a raw image |

| Type | Cartridge | Data size in bytes |
| --- | --- | --- |
| 1 | Standard 8 KB | 8192 |
| 2 | Standard 16 KB | 16384 |
| 41 | MaxFlash 1Mbit (REQ-608) | 131072 |
| 42 | MaxFlash 8Mbit (REQ-608) | 1048576 |
