# REQ-015: Portable core

## Requirement

The emulation core shall have no dependency except the `log` crate, and no I/O, and shall build on macOS and Linux.

## Rationale

A small core is easy to test, and other frontends can use it. The `log` crate is only an interface: it writes nothing, and the frontend chooses where the log lines go (REQ-084, REQ-085).

## Acceptance criteria

1. The `[dependencies]` table of `crates/atari-core/Cargo.toml` has only the entry `log`, with no optional features that do I/O.
2. CI builds and tests the core on macOS and Linux.

## Notes

The `log` dependency is a project decision of the user (2026-11-21, SLICE-09). Before that date, the core had no dependencies.


Windows is not a CI target (project decision, 2026-11-19). The core has no I/O, so it is expected to build on Windows, but no gate checks this.
