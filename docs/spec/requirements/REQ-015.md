# REQ-015: Portable core

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Product |
| Source | Project decision |
| Verification | Inspection |
| Depends on | None |

## Requirement

The emulation core shall have no dependencies and no I/O, and shall build on macOS and Linux.

## Rationale

A small core is easy to test, and other frontends can use it.

## Acceptance criteria

1. `crates/atari-core/Cargo.toml` has no `[dependencies]` entries.
2. CI builds and tests the core on macOS and Linux.

## Notes

Windows is not a CI target (project decision, 2026-11-19). The core has no I/O, so it is expected to build on Windows, but no gate checks this.
