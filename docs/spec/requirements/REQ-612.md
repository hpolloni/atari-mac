# REQ-612: Executable file loading

## Requirement

When the user starts an XEX file, the emulator shall do a cold reset with BASIC disabled, and shall then write the data of each segment into memory at its start address, in file order.

## Rationale

Most XEX programs need the RAM at `$A000-$BFFF` and do not work when BASIC is enabled. The segments must load in file order, because a later segment can overwrite an earlier one.

## Acceptance criteria

All criteria use AltirraOS and the BASIC ROM, NTSC. The run code is the segment at `$3000` with `A9 A5 8D 00 06 4C 05 30` (`LDA #$A5`, `STA $0600`, `JMP $3005`), and a segment at `$02E0` with `00 30` (RUNAD = `$3000`). "The program starts" is the first frame end at which `$0600` holds `$A5`. The test fails if this does not occur within 600 frames after the start.

1. Test file: a segment of 256 bytes at `$2000` with byte `k` = `k`, a segment of 16 bytes at `$A000` with byte `k` = `$F0 + k`, and the run code. When the program starts, `$2000-$20FF` holds `$00-$FF` and `$A000-$A00F` holds `$F0-$FF`.
2. In criterion 1, a CPU read of `$A000` gives `$F0`, not the BASIC ROM byte. Thus BASIC is disabled (`PORTB` bit 1 = 1).
3. Before the start, the test writes `$77` to RAM at `$7000`. When the program of criterion 1 starts, `$7000` holds `$00` (cold reset, REQ-215).
4. Test file: a segment at `$4000` with `11`, a segment at `$4000` with `22`, and the run code. When the program starts, `$4000` holds `$22`.
5. Criteria 1 to 4 pass with the SIOV shortcut off and with the SIOV shortcut on (REQ-623).

## Notes

The design document gives the load method (`docs/design/media.md`). A segment that overlaps the memory of the loader cannot load. The design document gives this memory range (`$0700-$08FF`).

Criterion 5 with the SIOV shortcut on applies only when REQ-623 is implemented.
