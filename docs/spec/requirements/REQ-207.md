# REQ-207: OS ROM control

## Requirement

The emulator shall show the 16 KB OS ROM at `$C000-$CFFF` and `$D800-$FFFF` when `PORTB` pin 0 = 1, and RAM there when pin 0 = 0.

## Rationale

The OS ROM must be visible to boot. Some programs disable it to use the RAM under it.

## Acceptance criteria

1. `PORTB` pins = `$FF`. CPU reads of `$C000`, `$CFFF`, `$D800` and `$FFFF` return the OS image bytes `$0000`, `$0FFF`, `$1800` and `$3FFF`.
2. `PORTB` pins = `$FF`. A CPU read of `$D40B` returns `VCOUNT`, not OS image byte `$140B`.
3. `PORTB` pins = `$FE`. For each address in `$C000-$CFFF` and `$D800-$FFFF`, a CPU write and then a CPU read give the written value.
4. The machine starts with an OS image of 16,384 bytes. For OS images of 8,192, 16,383 and 16,385 bytes, the machine gives a configuration error and does not start.

## Notes

AltirraOS and the Atari XL/XE OS ROMs are 16,384 bytes. The test data contains no Atari OS ROM image, so the tests use AltirraOS and test images.
