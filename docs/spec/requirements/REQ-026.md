# REQ-026: Golden frame tests

## Requirement

The test harness shall compare frames with reference PNG files, and shall have a mode that writes new reference files.

## Rationale

Frame comparison finds regressions in ANTIC and GTIA.

## Acceptance criteria

1. A frame passes only when every pixel is equal to the reference PNG.
2. On a difference, the test fails, and writes the actual frame and a difference image to `target/golden-failures/<name>-actual.png` and `<name>-diff.png`.
3. With `UPDATE_GOLDEN=1`, the test writes the reference PNG and passes.
