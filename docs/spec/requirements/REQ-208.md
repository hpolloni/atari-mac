# REQ-208: BASIC ROM control

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | System: clocks, memory map, bank switching, reset, PIA |
| Source | HRM 2.6 Bank switching (ROM control, BASIC ROM overlap (XL/XE only)); HRM 14.5 PIA registers (PORTB) |
| Verification | Test |
| Depends on | REQ-204, REQ-211 |

## Requirement

The emulator shall show the 8 KB BASIC ROM at `$A000-$BFFF` when `PORTB` pin 1 = 0, and RAM when pin 1 = 1, if no cartridge shows ROM there.

## Rationale

The OS enables BASIC at boot unless the user holds OPTION. Bit 1 is inverted compared with the OS ROM bit (HRM 2.6).

## Acceptance criteria

1. `PORTB` pins = `$FD` (pin 1 = 0), a BASIC image in the configuration, no cartridge. CPU reads of `$A000` and `$BFFF` return the BASIC image bytes `$0000` and `$1FFF`.
2. `PORTB` pins = `$FF` (pin 1 = 1), no cartridge. For each address in `$A000-$BFFF`, a CPU write and then a CPU read give the written value.
3. `PORTB` pins = `$FD`, no BASIC image in the configuration, no cartridge. For each address in `$A000-$BFFF`, a CPU write and then a CPU read give the written value.

## Notes

Criterion 3 is a project decision. The 65XE always contains BASIC, but the configuration can omit the BASIC image.
