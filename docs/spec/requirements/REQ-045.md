# REQ-045: No vague words

## Requirement

The requirement statement and the acceptance criteria shall not contain a word from the vague-word list `docs/spec/vague-words.txt`.

## Rationale

A vague word (for example "correctly") makes a criterion impossible to check without judgment.

## Acceptance criteria

1. The list contains at least: `correct`, `correctly`, `properly`, `appropriate`, `as expected`, `reasonable`, `etc`, `and so on`, `user-friendly`, `fast`, `quickly`.
2. A match is a whole word, without regard to case. Text in backticks is not checked.
3. A file with a match makes the check fail. The message gives the file, the criterion number and the word.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
