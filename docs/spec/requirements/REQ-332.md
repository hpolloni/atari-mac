# REQ-332: Display list interrupt

## Requirement

The emulator shall request a DLI at the start of the last scan line of each mode line that has IR bit 7 set, and shall send an NMI to the CPU for it if `NMIEN` bit 7 is set.

## Rationale

Most games and many OS-based programs change colors and registers with DLIs.

## Acceptance criteria

1. With `NMIEN` = `$80`, a write to `NMIRES` on scan line 39, and a `$82` line on scan lines 40-47: `NMIST` bit 7 reads 0 on scan lines 40-46 and reads 1 from cycle 7 of scan line 47. `out.nmi` is set once on scan lines 40-47, on scan line 47.
2. With `NMIEN` = `$00`, `NMIST` bit 7 reads the same as in criterion 1, and `out.nmi` is never set.
3. With `NMIEN` = `$80`, an instruction `$F0` on scan lines N to N + 7 causes one DLI, on scan line N + 7.
4. With `NMIEN` = `$80` and `VSCROL` = 5, a `$A2` line after a `$02` line has 3 scan lines (N to N + 2) and causes one DLI, on scan line N + 2.
5. With `NMIEN` = `$80`, an instruction `$81 $00 $30` on scan line N causes one DLI, on scan line N.
