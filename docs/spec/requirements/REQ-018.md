## Requirement

The emulator shall save the complete machine state to a byte array and restore it later.

## Rationale

Save states help users and help to reproduce bugs.

## Acceptance criteria

1. A state saved after frame 100 and restored in a new machine gives the same frame buffers for frames 101 to 200 as a run without interruption.
