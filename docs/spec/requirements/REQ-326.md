# REQ-326: Display list DMA off and enable timing

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Should |
| Area | ANTIC |
| Source | HRM 4.6 Display list (Suspended display list DMA, Display list DMA enable/disable timing) |
| Verification | Test |
| Depends on | REQ-319, REQ-344 |

## Requirement

The emulator shall repeat the last instruction byte in IR, with no display list fetch and no address fetch, when `DMACTL` bit 5 is 0 at the time of an instruction fetch.

## Rationale

The display list hardware always runs. `DMACTL` bit 5 only controls the fetch. Software and the OS turn display list DMA off and on, and the result must be the same as on hardware.

## Acceptance criteria

1. With `DMACTL` = `$02` (bit 5 = 0) and IR = `$02`, the display list address in the debug state does not change for a full frame, and `out.dma` is never `DisplayList` or `DisplayListAddress`.
2. With `DMACTL` = `$22`, a `$42 $00 $40` line starts. The test writes `$02` to `DMACTL` on the second scan line of that mode line. The next mode lines are mode 2 lines of 8 scan lines each. Each has `CharacterName` fetches on its first scan line and no `DisplayListAddress` fetch on cycles 6 and 7. The first name fetch of each mode line reads an address `$28` higher than the first name fetch of the mode line before it.
3. With `DMACTL` = `$02`, IR = `$82` and `NMIEN` = `$80`, `NMIST` bit 7 becomes set and one NMI occurs on the 8th scan line of each repeated mode 2 line, and on no other scan line.
4. After a JVB on scan line N, the test writes `$02` to `DMACTL`. Positions `$22-$DD` have code `%000` on scan lines N + 1 to 247 of that frame and on scan lines 8-247 of the next frame, and no display list DMA occurs.
5. `DMACTL` = `$02` and IR = `$02`, and scan line N + 1 starts a new mode line. A write of `$22` to `DMACTL` on cycle 113 of scan line N makes a `DisplayList` fetch occur on cycle 1 of scan line N + 1.
6. In the same state, a write of `$22` to `DMACTL` on cycle 0 of scan line N + 1 does not make a `DisplayList` fetch occur on cycle 1 of scan line N + 1.

## Notes

ANTIC clears IR bit 6 across vertical blank, and keeps bits 0-5 and 7. This matters only if display list DMA is enabled on cycle 0 or 1. The design implements this, but no separate test is needed.
