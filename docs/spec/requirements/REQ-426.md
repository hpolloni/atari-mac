# REQ-426: Fifth player

## Requirement

When `PRIOR` bit 4 = 1, the emulator shall show all four missiles in the `PF3` layer with the color `COLPF3`, above `PF0-PF2`, and shall not change the collision results.

## Rationale

Programs use the four missiles together as a fifth player in one color.

## Acceptance criteria

1. With `PRIOR` = `$11` and `COLPF3` = `$C8`, missile 0 alone shows `$C8`.
2. With `PRIOR` = `$11` and `COLPF3` = `$C8`, missile 0 on `PF0`, on `PF1` and on `PF2` shows `$C8`.
3. With `PRIOR` = `$11`, missile 0 on `PF1` sets `M0PF` = `$02`, and player 0 on missile 0 over the background sets `M0PL` = `$01` and `P0PF` = `$00`.
4. With `PRIOR` = `$10`, `COLPF3` = `$C8`, `GRAFM` = `$FF`, `HPOSM0` = `$40`, `HPOSM3` = `$90`, `HPOSM1` = `HPOSM2` = `$00` and `SIZEM` = `$C0`, HPOS `$40-$41` and `$90-$97` show `$C8`, and HPOS `$42` and `$98` show `COLBK`.
5. A unit test checks each cell of the `P5` rows of HRM Table 16 for all 11 `PRIOR[3:0]` columns, with `PRIOR` bit 4 = 1, missile 0 for P5 and the objects of REQ-425 criterion 6 for the other layers. All cells agree, except the three cells in the Notes.

## Notes

Source: project decision for the logic. The HRM gives no equations for the fifth player. The emulator uses the equations of REQ-424 with `PF3` = playfield 3 OR any missile. It also blocks `SF0-SF2` when any missile is active, because the HRM states that the fifth player "always wins against all other playfields". This model agrees with all cells of the `P5` rows of HRM Table 16, except three: `P5+P23` at `%0101` and at `%1100` (Table 16 gives `P23`, the model gives black), and `P5+P01+P23` at `%1100` (Table 16 gives `P01`, the model gives black). For `PRIOR` = `$18` with `PF0`, a player and the fifth player at one pixel, the HRM text says that `PF3` shows, but the model gives black. These conflicts are open issues in `docs/design/gtia.md`. For interactions with GTIA modes 9 and 11, see REQ-429 and REQ-431. The HRM states that the timing of bit 4 changes is temperature sensitive on some machines (HRM 6.10).
