# REQ-021: Missing test data fails the tests

## Requirement

When test data is missing, each test that needs it shall fail with a message that tells the user which command downloads the data.

## Rationale

A test that skips silently hides a missing gate.

## Acceptance criteria

1. `data::read_test_file` for a path that does not exist returns `HarnessError::Missing`. Its message contains the path and the given fetch command.
2. No test in `crates/harness/tests/` returns early with success when a data file is missing.

## Notes

Project decision: a rule of the test harness. The HRM does not cover it.
