# REQ-314: Character control (CHACTL)

## Requirement

The emulator shall apply `CHACTL` bit 0 (blank) and bit 1 (invert) to characters with name bit 7 set in IR modes 2 and 3, and shall apply `CHACTL` bit 2 (vertical reflect) to all character modes.

## Rationale

The OS shows inverse video with bit 1 and the cursor with inverse characters. Software makes text blink with bit 0.

## Acceptance criteria

1. With `CHACTL` = `$01`, a mode 2 character with name `$C1` and font byte `$9C` has code `%100` on its 4 color clocks (font data `$00`).
2. With `CHACTL` = `$02`, the same character has the codes `%101`, `%110`, `%100` and `%111` (font data `$63`).
3. With `CHACTL` = `$03`, the same character has code `%111` on its 4 color clocks (font data `$FF`).
4. With `CHACTL` = `$01`, `$02` and `$03`, a mode 2 character with name `$41` and font byte `$9C` has the codes `%110`, `%101`, `%111` and `%100`.
5. With `CHACTL` = `$03`, mode 4, 5, 6 and 7 lines with names `$81` and `$C1` have the same codes as with `CHACTL` = `$00`.
6. With `CHACTL` = `$04`, on row r (r = 0-7) of a mode 2, 3, 4 or 6 line, the font fetch reads font row 7 - r. On row r (r = 0-15) of a mode 5 or 7 line, it reads font row 7 - (r >> 1).
7. With `CHACTL` = `$04`, in mode 3: for name `$41`, rows 0-7 read font rows 7-0 and rows 8-9 have code `%100`. For name `$61`, rows 0-1 have code `%100`, rows 2-7 read font rows 5-0, and rows 8-9 read font rows 7-6.

## Notes

If playfield DMA is off when a name fetch occurs, ANTIC uses the names in the line buffer but uses the invert and blink state of the last character. This case is in REQ-344.
