# REQ-092: Automatic RETURN for a tape boot

## Requirement

When the command line has `--cas <file>` and `--auto-return`, the frontend shall press RETURN after the prompt tone of the tape boot, as the user does.

## Rationale

With `--cas` only, the user must press RETURN after the tone (OI-050). With `--auto-return`, a tape boots with no key press, also in headless mode, so a tape load can run in a script.

## Acceptance criteria

1. With `--cas` and `--auto-return`, the frontend presses RETURN from frame 180 to frame 186 (NTSC) or from frame 150 to frame 156 (PAL), the frames of REQ-081 criterion 4, and presses no other key.
2. `atari-mac --headless --frames 2400 --cas <file> --auto-return` with the boot test tape of REQ-643 boots the tape: `$0600` holds `$A5` at the end, for NTSC and PAL. Without `--auto-return`, the same run does not boot the tape.
3. `--auto-return` without `--cas` gives exit code 2 and a message that names both options.
4. Without `--auto-return`, `--cas` behaves as in REQ-081.
5. `--help` lists `--auto-return`.

## Notes

Project decision of the user (2026-11-21), an addition to OI-050 option 2. The default stays: the user presses RETURN. The option name is a project decision.
