# REQ-435: Trigger registers

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | GTIA, color palette, joystick and paddle inputs |
| Source | HRM 6.11 General purpose I/O (Trigger inputs); HRM 2.8 Miscellaneous connections (Cartridge sense); HRM 14.3 GTIA registers (TRIG0-3) |
| Verification | Test |
| Depends on | REQ-401 |

## Requirement

The emulator shall return bit 0 = 1 from `TRIGn` for an inactive input and 0 for an active input, with `TRIG2` always inactive and `TRIG3` active when no cartridge ROM is mapped at `$A000-$BFFF`.

## Rationale

The OS reads `TRIG3` to find a cartridge. Programs read `TRIG0` and `TRIG1` for the joystick buttons.

## Acceptance criteria

1. With no joystick button pressed and `GRACTL` = `$00`, `TRIG0` and `TRIG1` read `$01`. With trigger input 0 active, `TRIG0` reads `$00`. With trigger input 1 active, `TRIG1` reads `$00`.
2. `TRIG2` reads `$01` after power-on, with both joystick buttons pressed, and with `GRACTL` = `$04`.
3. With an 8K cartridge mapped at `$A000-$BFFF`, `TRIG3` reads `$01`.
4. With no cartridge, `TRIG3` reads `$00`, with the internal BASIC ROM enabled and with it disabled.
5. With a cartridge that bank switching can disable, the first read of `TRIG3` after the access that disables the cartridge ROM at `$A000-$BFFF` returns `$00`, and the first read after the access that enables it again returns `$01`.

## Notes

The machine supplies the RD5 state of the cartridge to GTIA (media requirements, REQ-6xx). The XEGS keyboard sense on `TRIG2` does not apply to the 65XE.
