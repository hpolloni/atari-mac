# REQ-330: Mode lines with unusual height

## Requirement

The emulator shall show the rows of a mode line that vertical scrolling extends past its normal height as in the table below.

| IR mode | Rows past the normal height |
| --- | --- |
| 0 | Blank |
| 1 | Blank. ANTIC fetches `DLISTL`/`DLISTH` again on each scan line. |
| 2 | Rows 8-9 show `$00` for names with bits 6-5 not `%11`. Rows 10-15 are as rows 2-7. |
| 3 | Rows 10-15 are as rows 2-7. |
| 4, 6 | Rows 8-15 are as rows 0-7. |
| 8-F | All rows show the data of the first scan line. |

## Rationale

Demos and some games use extended mode lines to reduce DMA.

## Acceptance criteria

1. With `VSCROL` = 2, a jump `$01 $00 $30` at address D follows a `$22` line. Memory `$3000-$3001` holds `$00 $31` and memory `$3100-$3101` holds `$00 $32`. The jump line has 3 scan lines. Its `DisplayListAddress` fetches on cycles 6 and 7 read D + 1 and D + 2 on its first scan line, `$3000` and `$3001` on its second scan line, and `$3100` and `$3101` on its third scan line. The next instruction fetch reads `$3200`.
2. With `VSCROL` = 15, a `$04` line after a `$24` line has 16 scan lines (rows 0-15). Rows 8-15 read font rows 0-7. A `$06` line after a `$26` line gives the same rows.
3. With `VSCROL` = 15, a `$02` line after a `$22` line has rows 0-15. For name `$41`, rows 8 and 9 have code `%100` on all color clocks (font data `$00`), and rows 10-15 read font rows 2-7. A `$03` line after a `$23` line with name `$41` reads font rows 2-7 on rows 10-15.
4. With `VSCROL` = 3, a `$0F` line after a `$2F` line has 4 scan lines. `Bitmap` DMA occurs only on its first scan line, and scan lines 2-4 have the same codes as scan line 1.
5. With `VSCROL` = 15, a `$00` line after a `$22` line has 16 scan lines, and positions `$22-$DD` have code `%000` on all of them.
6. A `$02` line follows a `$22` line, with `VSCROL` = 3. A write of `$01` to `VSCROL` on cycle 50 of its row 2 scan line makes the rows 0, 1, 2, ..., 15, 0, 1: the mode line has 18 scan lines.
