# REQ-541: Nonlinear DAC and saturation

## Requirement

The emulator shall have an option that replaces the linear channel volumes with the DAC weights 0.12, 0.26, 0.56 and 1.12 for volume bits 0-3, and applies the saturation curve of HRM E.2 to the sum.

## Rationale

The real POKEY compresses loud sounds. Some music sounds different without this effect.

## Acceptance criteria

1. With the option on, `AUDC1` = `$1F` and `AUDC2-4` = `$00`, the normalized DAC sum (test accessor) is 0.25 +/- 0.0001. With `AUDC1` = `$15`, it is (0.12 + 0.56) / 8.24 = 0.0825 +/- 0.0001.
2. The curve (test accessor, input x) gives these outputs, each +/- 0.001: x = 0 gives 0, x = 0.07 gives 0.152, x = 0.14 gives 0.304, x = 0.25 gives 0.509, x = 0.5 gives 0.793, x = 1.0 gives 1.000. These values come from `y = 2.171 * x` for `x <= 0.14`, and `y = 2.171 * (0.14 + (1 - exp(-2.85 * (x - 0.14))) / 2.85)` for `x >= 0.14`.
3. With the option on, the sample step of REQ-539 criterion 5 is 2.036 times the step with the option off, +/- 2 % (0.509 / 0.25).
4. After `Pokey::new`, the input of REQ-539 criterion 5 gives the same samples as after `set_nonlinear_audio(false)`.

## Notes

The normalizing divisor 8.24 is (0.12 + 0.26 + 0.56 + 1.12) * 4, from HRM E.2. With the option off, REQ-539 applies.

POKEY-SPEC 9.B gives the audio output pin as four open-drain devices with widths of 10, 20, 40 and 80 micron, so the DAC weights are in power-of-two ratios. It gives only the maximum output low voltage of each device with a 10 kOhm pull-up, not the levels in the computer.
