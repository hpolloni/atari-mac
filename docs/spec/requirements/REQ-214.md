# REQ-214: Reads of unmapped addresses

## Requirement

The emulator shall return `$FF` for a read of `$D100-$D1FF`, `$D600-$D7FF`, and of `$D500-$D5FF` when no cartridge drives the data bus.

## Rationale

No device responds to these addresses without PBI devices or a cartridge. On an XL and some XE machines, pull-up resistors force the bus to `$FF` (HRM 2.3).

## Acceptance criteria

1. RAM at `$D100-$D1FF` and `$D600-$D7FF` = `$00`. A CPU read of each address in `$D100-$D1FF` and `$D600-$D7FF` returns `$FF`.
2. No cartridge. A CPU read of each address in `$D500-$D5FF` returns `$FF`.
3. A test cartridge that does not drive the bus for `$D5xx` reads. A CPU read of `$D500` returns `$FF`.

## Notes

The HRM says that some XE machines have no pull-ups and show a floating bus. It does not say which type the 65XE is. The `$FF` value is a project decision. A floating bus model is an open issue.
