# REQ-644: Tape shortcut

## Requirement

When the tape shortcut is on, a tape is inserted, and the CPU is about to execute the instruction at SIOV (`$E459`) with the OS ROM enabled, `DDEVIC` = `$60` and `DCOMND` = `$52`, the emulator shall read the next data record of the tape into the buffer at once, shall put the result status in `DSTATS` and Y, shall set the N flag from bit 7 of the status, and shall return to the address after the `JSR` of the caller.

## Rationale

At 600 baud, a tape of 368 records takes about 17 minutes in real time, and more than one minute in turbo (REQ-082). The OS cassette handler and most boot loaders read each record through SIOV. With the shortcut, the same tape loads in seconds.

## Acceptance criteria

The record is the bytes of the next `data` chunk of the tape (REQ-639), from the tape position. The device control block and the status codes are in REQ-623.

1. With the shortcut on, the emulator copies the first `DBYT` bytes of the record to the buffer at `DBUF`. When the record has `DBYT + 1` bytes or more, and byte `DBYT` of the record is the checksum of the `DBYT` bytes before it (HRM C.2: the 8-bit sum with end-around carry), the status is `$01`.
2. When the checksum does not match, the buffer holds the bytes of criterion 1, and the status is `$8F`.
3. When the record has fewer than `DBYT + 1` bytes, the emulator copies the bytes that it has, and the status is `$8F`. When no record remains after the tape position, the buffer does not change, and the status is `$8A`.
4. After the request, the tape position is at the start of the record after the record that was read. The shortcut does not wait for the gap or the bits of the record: the request takes no emulated time, except the cycles of the return.
5. The shortcut does not change the motor line (REQ-641), the POKEY registers or the PIA registers, and makes no serial interrupt.
6. A request with another `DCOMND` (for example the write `$57`), with `DDEVIC` other than `$60`, or with the shortcut off, goes to the OS routine as before (REQ-643).
7. The boot test tape of REQ-643, with `--cas`, the RETURN press of REQ-081 criterion 4 and the shortcut on, reaches `$0600` = `$A5` for NTSC and PAL, in fewer frames than with the shortcut off.
8. After the same frames and the same key input, a save state (REQ-018) in the middle of a tape boot with the shortcut on loads and gives the same RAM at the end as a run without the save and the load.

## Notes

The tape shortcut is a project decision of the user (2026-11-21), an addition to the turbo of OI-051. The device code `$60` is the decision of OI-046 (option 2).

TRN OS-9/Handler-SIO-Interface: the cassette handler calls SIO with `DDEVIC` = `$60`, `DCOMND` = `$52` for a read, the buffer `CASBUF` and the length of the record without the checksum. A loader that reads the tape with its own code, not through SIOV, loads at the real speed, in turbo.
