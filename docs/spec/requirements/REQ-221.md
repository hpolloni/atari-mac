# REQ-221: Port A inputs

## Requirement

The emulator shall connect bits 0-3 of port A to joystick port 1 and bits 4-7 to joystick port 2, with a pressed direction at 0 and all other inputs at 1.

## Rationale

Port A reads the joystick directions (HRM 2.5). Port A has internal pull-ups, so pins that no device pulls low read as 1 (HRM 2.5).

## Acceptance criteria

1. `PACTL` = `$3C`, `DDRA` = `$00`, no joystick pressed. A read of `PORTA` returns `$FF`.
2. Joystick 1 up pressed: `PORTA` reads `$FE`. Joystick 1 right pressed: `$F7`. Joystick 2 up pressed: `$EF`. Joystick 2 right pressed: `$7F`.
3. `DDRA` = `$FF`, port A output register = `$00`. A write sets `DDRA` = `$00`. With no joystick pressed, `PORTA` reads `$FF` 10 cycles after the write and 1,000,000 cycles after the write.

## Notes

HRM 7.1 gives the bits of each port from bit 0: up, down, left, right. The joystick inputs are in the REQ-400 range.
