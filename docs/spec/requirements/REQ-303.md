# REQ-303: ANTIC power-up values

## Requirement

The emulator shall set `PENH` to `$00`, `PENV` to `$FF` and `NMIST` to `$7F` at power-on.

## Rationale

These are the typical power-up values on real hardware (HRM 4.1, Table 5). Software that reads these registers before the first update then sees the same values as on hardware.

## Acceptance criteria

1. After power-on, a read of `$D40C` (`PENH`) returns `$00`.
2. After power-on, a read of `$D40D` (`PENV`) returns `$FF`.
3. After power-on, with no write to `NMIRES` and no DLI, a read of `$D40F` (`NMIST`) returns `$7F` on every cycle of the first two frames.

## Notes

The HRM says that all other registers that ANTIC does not clear are undefined at power-on, and that the values above are only typical.

Project decision: at power-on, the emulator sets all other undefined ANTIC state to zero, and starts at scan line 0, cycle 0. This makes runs repeatable. On real machines, `VCOUNT` has different values at power-on.
