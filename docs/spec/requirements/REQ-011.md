# REQ-011: Audio output

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Frontend |
| Source | HRM 5.3 Sound generation |
| Verification | Demonstration |
| Depends on | REQ-007, REQ-538 |

## Requirement

The frontend shall play the POKEY audio on the default host audio device with no audio buffer underruns at real-time speed.

## Rationale

An underrun causes an audible click or gap.

## Acceptance criteria

1. In BASIC, `SOUND 0,121,10,8` runs for 10 s with `atari-mac --audio-stats`. The printed underrun count is 0.
2. A person hears a steady tone for the 10 s.
