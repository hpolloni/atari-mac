# REQ-202: Single memory bus

## Requirement

The emulator shall give the memory bus to exactly one bus master in each machine cycle, ANTIC when it needs a DMA or refresh cycle and otherwise the CPU.

## Rationale

Only the 6502 and ANTIC can drive the bus. ANTIC steals cycles with higher priority, and only the 6502 issues write cycles (HRM 2.3).

## Acceptance criteria

1. A program sets `DMACTL` = `$22` and a display list of mode 2 lines, and then loops. During one frame, the CPU makes no bus access in each machine cycle in which ANTIC does DMA or refresh.
2. In the frame of criterion 1, the CPU makes exactly one bus access in each other machine cycle, also while RDY is low (REQ-101, REQ-126).
3. The program of criterion 1 executes a KIL opcode after it sets `DMACTL`. The machine runs 10 frames. After the 10 frames, all 65,536 RAM bytes have the values from before the 10 frames.
