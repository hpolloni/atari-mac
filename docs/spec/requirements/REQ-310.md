# REQ-310: DMA cycles halt the CPU

## Requirement

The emulator shall halt the CPU for each cycle in which ANTIC does a display list, playfield, player/missile or memory refresh DMA cycle.

## Rationale

ANTIC is the only other bus master. It halts the 6502 for each DMA or refresh access. This sets the CPU speed. For example, a Graphics 0 screen reduces the NTSC CPU to approximately 64% of full speed (HRM 3.3).

## Acceptance criteria

1. In every cycle of a frame with `DMACTL` = `$3E` and a display list of mode 2, mode E and blank lines, `out.halt` is set exactly on the cycles where `out.dma` is not `None`.
2. With `DMACTL` = `$00`, an `STA $0600` instruction that would make its write cycle on refresh cycle 25 makes its write on cycle 26. On the first scan line of a normal mode E line, an `STA $0600` that would make its write on cycle 20 makes its write on cycle 21.
3. With `DMACTL` = `$00`, `out.halt` is set on cycles 25, 29, 33, 37, 41, 45, 49, 53 and 57 of every scan line, and on no other cycles.
4. With `DMACTL` = `$2C`, on the first scan line of a `$70` instruction, `out.halt` is set on cycles 0-5 and on cycles 25, 29, 33, 37, 41, 45, 49, 53 and 57, and on no other cycles.

## Notes

`WSYNC` uses the RDY signal, not halt. RDY stops only CPU read cycles (REQ-336).
