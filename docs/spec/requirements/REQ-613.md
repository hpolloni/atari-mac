# REQ-613: Executable init address

## Requirement

After each segment whose address range includes `$02E2` or `$02E3` (INITAD), the emulator shall call the routine at the address in INITAD with `JSR`, and shall load the next segment after the routine returns with `RTS`.

## Rationale

Many programs use init routines, for example to show a title screen while the rest of the file loads, or to decompress data. The init routine must run before the next segment loads.

## Acceptance criteria

Test file, in this order:

| Segment | Address | Data |
| --- | --- | --- |
| A | `$0600` | `00` |
| B | `$2000` | `EE 00 06 60` (`INC $0600`, `RTS`) |
| C | `$02E2` | `00 20` |
| D | `$0600` | `10` |
| E | `$02E2` | `00 20` |
| G | `$3000` | `A9 A5 8D 01 06 4C 05 30` (`LDA #$A5`, `STA $0601`, `JMP $3005`) |
| F | `$02E0` | `00 30` (RUNAD = `$3000`) |

1. With AltirraOS (NTSC), the test starts the file (REQ-612) and runs until `$0601` holds `$A5`, for at most 600 frames. Then `$0600` holds `$11`.
2. Criterion 1 passes with fast SIO off and with fast SIO on (REQ-623).

## Notes

The value `$11` shows three facts. The init routine ran after C and before D. It ran again after E. It did not run after segments A, B, D and G.
