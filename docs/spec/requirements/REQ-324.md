# REQ-324: Display list counter 1K boundary

## Requirement

The emulator shall increment only the low 10 bits of the display list address during display list fetches, so that the address wraps from the top of a 1K block to the bottom of the same block.

## Rationale

The display list counter has a 10-bit part that increments and a 6-bit part that does not.

## Acceptance criteria

1. An instruction `$02` at `$07FF` makes the next instruction fetch read `$0400`.
2. An instruction `$42` at `$07FE` makes ANTIC read the low address byte from `$07FF` and the high address byte from `$0400`. The next instruction fetch reads `$0401`.
3. An instruction `$01 $00 $30` at `$07FD` makes the next instruction fetch read `$3000` (the jump loads all 16 bits).
