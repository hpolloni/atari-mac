# REQ-089: Monitor breakpoints

## Requirement

The monitor shall stop the emulation when the CPU starts an instruction at a breakpoint address, or reads or writes a watched address.

## Rationale

The user must stop the machine when a loader reaches a given point, or when a program changes a given variable.

## Acceptance criteria

1. The command `b <address>` sets a breakpoint. The emulation stops before the instruction at that address, as at REQ-088 criterion 1.
2. The command `ww <address>` sets a write watch, and `wr <address>` sets a read watch. The emulation stops after the instruction that writes or reads that address, and the monitor shows the address, the value and the instruction line.
3. The command `bl` lists the breakpoints and the watches, each with a number. The command `bd <number>` deletes one.
4. The `--break <address>` option sets a breakpoint before the first frame.
5. A test sets a breakpoint at `$0600` and boots the boot test tape of REQ-643: the emulation stops before the first instruction of the boot program at `$0600`.
6. With no breakpoints and no watches, the speed limit of REQ-007 applies.
