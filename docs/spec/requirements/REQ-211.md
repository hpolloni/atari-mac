# REQ-211: Memory control from the port B pins

## Requirement

The emulator shall control the memory map from the levels of the port B pins: the output register for output bits, and 1 for input bits 0, 1 and 7.

## Rationale

Pull-ups hold port B bits 0, 1 and 7 high when they are inputs. Because a PIA reset makes all bits inputs, the OS ROM is enabled and BASIC and self-test are disabled after reset (HRM 2.6).

## Acceptance criteria

1. After a PIA reset (`DDRB` = `$00`), with a BASIC image: `$C000` reads OS image byte `$0000`, `$A000` reads RAM, and `$5000` reads RAM.
2. `DDRB` = `$FF`, port B output register = `$FC`. `$C000` reads RAM, `$A000` reads BASIC image byte `$0000`, and `$5000` reads RAM.
3. `DDRB` = `$00`, port B output register = `$00`. The results are those of criterion 1.
4. Port B output register = `$00`. A write changes `DDRB` from `$00` to `$01`. Before the write, `$C000` reads OS image byte `$0000`. After the write, `$C000` reads RAM.
5. `DDRB` = `$80`, port B output register = `$00`. `$5000` reads OS image byte `$1000` (pin 7 = 0, pin 0 = 1 from the pull-up), and `$A000` reads RAM (pin 1 = 1 from the pull-up).
