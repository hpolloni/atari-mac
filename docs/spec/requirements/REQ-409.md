# REQ-409: NTSC palette

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | GTIA, color palette, joystick and paddle inputs |
| Source | HRM 6.3 Color encoding (NTSC color encoding, NTSC brightness encoding); HRM D.2 NTSC color encoding |
| Verification | Test |
| Depends on | REQ-404 |

## Requirement

The emulator shall convert each NTSC color byte to RGB with `Y = L / 15`, `U = S cos(180° - d(H - 1))`, `V = S sin(180° - d(H - 1))` (no chroma for H = 0), `S = 0.233`, `d = 24°`, the YUV to RGB matrix of HRM D.2, a clamp to 0-1 and `round(255 x value)`.

## Rationale

GTIA makes luminance and chroma directly, so there is no RGB palette in the hardware (HRM D.1). A formula from the HRM gives a palette that a test can check. H is bits 4-7 and L is bits 0-3 of the color byte.

## Acceptance criteria

In these criteria, "the inverse matrix" is the RGB to YUV matrix of HRM D.2: `Y = 0.299 R + 0.587 G + 0.114 B`, `U = -0.147 R - 0.289 G + 0.436 B`, `V = 0.615 R - 0.515 G - 0.100 B`, with R, G and B in the range 0-1.

1. `$00` gives (0, 0, 0), `$08` gives (136, 136, 136), `$0E` gives (238, 238, 238) and `$0F` gives (255, 255, 255), with no tolerance.
2. `$94` gives (54, 52, 186), `$1A` gives (170, 193, 49) and `$48` gives (200, 110, 99), with a tolerance of 1 for each channel.
3. For each of the 256 bytes with no channel outside 0-1 before the clamp, the inverse matrix applied to the RGB result divided by 255 gives Y within 0.01 of `L / 15`. For H = 1-15, it also gives a chroma angle `atan2(V, U)` within 2° of `180° - 24° x (H - 1)` and a magnitude `sqrt(U² + V²)` within 0.01 of 0.233.
4. Each byte with H = 0 gives R = G = B.
5. `build(NTSC, &PaletteParams::default())` gives the same 256 values as `table(NTSC)`.

## Notes

Source: HRM D.2 for the formula. The HRM states that no authoritative palette exists (HRM 6.3, "A word on colors"). The value `d = 24°` is the nominal delay in HRM 6.3. The value `S = 0.233` is the 130XE saturation in HRM Table 117. The HRM has no measurement for the 65XE, so the project uses the 130XE value (project decision). The palette does not model the close luminance levels 7 and 8, the blacker-than-black level 0, gamma conversion or NTSC to sRGB color correction. These are open issues in `docs/design/gtia.md`.
