# REQ-059: Source file length limit

## Requirement

Each Rust source file of the workspace shall have at most 1500 lines, except the files on the code baseline, which shall not become longer.

## Rationale

A long file is hard to read, and two teammates that change the same long file get merge conflicts. The limit makes a teammate split a module into submodules before it grows more.

## Acceptance criteria

1. The gate reads the same files as REQ-058 criterion 2. The length of a file is its number of lines (the number of newline characters, plus 1 if the last line has no newline).
2. A file with more than 1500 lines that is not on the code baseline fails the gate. The message gives the file and its length.
3. The code baseline `docs/spec/code-baseline.txt` has one line for each file that is allowed above 1500 lines: `lines`, the file and its length at the time of the line.
4. A file on the baseline that is longer than its baseline value fails the gate. A baseline line for a file that does not exist, that has 1500 lines or fewer, or that is shorter than its baseline value, fails the gate as stale.
5. The gate runs where the gate of REQ-058 runs.

## Notes

Project decision: the user asked for this gate on 2026-11-21. A file on the baseline can not grow, so a change that adds lines to it first moves code into a submodule.
