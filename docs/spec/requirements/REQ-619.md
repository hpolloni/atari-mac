# REQ-619: Command reply sequences

## Requirement

A disk drive shall reply to each command that it accepts with the byte sequence for the command type in the table.

| Type | Commands | Sequence |
| --- | --- | --- |
| Read | Status `$53`, Read `$52`, Format `$21`, Format medium `$22`, Read Percom block `$4E` | ACK `$41`; Complete `$43` or Error `$45`; data frame; checksum of the data frame |
| Write | Put `$50`, Write `$57`, Write Percom block `$4F` | ACK `$41`; the computer sends a data frame and its checksum; ACK `$41`; Complete `$43` or Error `$45` |

## Rationale

The protocol has no field that tells the direction or the length of a data frame. The computer and the device must both know them from the command. A Format command is a read-type command, because it returns the bad sector list.

## Acceptance criteria

The SD test image has 720 sectors of 128 bytes. Each byte of sector `n` holds `n & $FF`. A list of bytes is the complete list of bytes that the drive sends for the command, in order.

1. Status (`31 53 00 00 84`) with the SD test image: the drive sends `41 43 00 FF E0 00 E0`.
2. Read sector 1 (`31 52 01 00 84`) of the SD test image: the drive sends `41`, `43`, 128 bytes of `$01`, and `80`.
3. Read sector 1 with no image in D1: (REQ-633): the drive sends `41`, `45`, 128 bytes of `$00`, and `00`.
4. Put sector 1 (`31 50 01 00 82`) of the SD test image: the drive sends `41`. After the computer sends 128 bytes of `$5A` and `2D`, the drive sends `41` and then `43`.
5. Format (`31 21 00 00 52`) of the SD test image: the drive sends `41`, `43`, 128 bytes of `$FF`, and `FF`.
6. Read Percom block (`31 4E 00 00 7F`) with the SD test image: the drive sends `41`, `43`, the 12 bytes `28 00 00 12 00 00 00 80 FF 00 00 00`, and `BA`.
7. Write Percom block (`31 4F 00 00 80`) with the SD test image: the drive sends `41`. After the computer sends the 12-byte SD block of criterion 6 and `BA`, the drive sends `41` and then `43`.

## Notes

The HRM states that the data frame of a read-type command follows also an Error byte.
