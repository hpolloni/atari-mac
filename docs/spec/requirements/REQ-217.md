# REQ-217: System Reset button

## Requirement

When the Reset button is pressed, the emulator shall reset the CPU, ANTIC and the PIA, keep RAM, GTIA and POKEY unchanged, and send no reset NMI.

## Rationale

On the XL/XE, the Reset button pulls the reset lines of the 6502, ANTIC, FREDDIE and the PIA. This masks NMIs, sets the default memory banking, and restarts the CPU at the reset vector (HRM 2.4). The OS then does a warm start.

## Acceptance criteria

1. The CPU executes `NOP` instructions in RAM. After the Reset button, the next 7 CPU cycles are the reset sequence of REQ-124 (7 reads, no write). The next CPU cycle fetches the opcode at the address in OS image bytes `$3FFC` and `$3FFD`.
2. Before the Reset button: `DDRB` = `$FF`, port B output register = `$FC`, `PACTL` = `$3C`, `PBCTL` = `$3C`. After the Reset button, CPU reads of `$D302`, `$D303`, `$D300` and `$D301` return `$00`. `$C000` reads OS image byte `$0000`, and `$A000` reads RAM.
3. Before the Reset button: `NMIEN` = `$40` (VBI on), `DMACTL` = `$22`. After the Reset button, a test OS image whose reset code loops and does not write `NMIEN` or `DMACTL` gets no NMI sequence in 2 frames (no read of `$FFFA`). In the second full frame, ANTIC halts the CPU in the same machine cycles as in a new machine that runs the same image.
4. All 65,536 RAM bytes are the same before and after the Reset button. The GTIA state and the POKEY state are the same before and after the Reset button.
5. `NMIST` bit 5 is 0 before the Reset button (after a write to `NMIRES`). After the Reset button, `NMIST` bit 5 is still 0.

## Notes

FREDDIE is the memory controller. It has no state of its own on the 65XE that the emulator must model. The memory banking reset comes from the PIA reset. The HRM names only the 6502, ANTIC, FREDDIE and the PIA. The statement that GTIA and POKEY are not reset follows from that list.

To compare the GTIA and POKEY states, the test clones the chip before the Reset button and compares it with `==` after. Each chip type derives `Clone` and `PartialEq` (OI-005).
