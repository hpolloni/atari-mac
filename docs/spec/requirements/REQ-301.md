# REQ-301: ANTIC register functions and read values

## Requirement

The emulator shall implement the ANTIC register map in the table below, and a read of a register offset that has no read function shall return `$FF`.

| Offset | Read | Write |
| --- | --- | --- |
| `$0` | `$FF` | `DMACTL` |
| `$1` | `$FF` | `CHACTL` |
| `$2` | `$FF` | `DLISTL` |
| `$3` | `$FF` | `DLISTH` |
| `$4` | `$FF` | `HSCROL` |
| `$5` | `$FF` | `VSCROL` |
| `$6` | `$FF` | No effect |
| `$7` | `$FF` | `PMBASE` |
| `$8` | `$FF` | No effect |
| `$9` | `$FF` | `CHBASE` |
| `$A` | `$FF` | `WSYNC` |
| `$B` | `VCOUNT` | No effect |
| `$C` | `PENH` | No effect |
| `$D` | `PENV` | No effect |
| `$E` | `$FF` | `NMIEN` |
| `$F` | `NMIST` | `NMIRES` |

## Rationale

ANTIC drives `$FF` onto the data bus for addresses in its range that have no register. This is true also on models with a floating data bus (HRM 4.1).

## Acceptance criteria

1. A test writes each of the values `$00`, `$55`, `$AA` and `$FF` to each offset `$0-$F`. After each write, reads of offsets `$0-$A` and `$E` return `$FF`.
2. On scan line 100, cycle 50, a read of offset `$B` returns `$32` (`VCOUNT`, REQ-338). After power-on, a read of offset `$C` returns `$00` (`PENH`) and a read of offset `$D` returns `$FF` (`PENV`) (REQ-303, REQ-342).
3. After power-on, a read of offset `$F` returns `$7F` (`NMIST`, REQ-303). After a write to offset `$F`, a read of offset `$F` returns `$1F` (REQ-331).
4. Two ANTIC instances start in the same state with the same memory and run for 2 frames. On scan line 100, cycle 50, one instance gets a write of `$FF` to each of the offsets `$6`, `$8`, `$B`, `$C` and `$D`. The two instances give the same `CycleOutput` on each cycle, and the same values on reads of offsets `$B`, `$C`, `$D` and `$F` on each cycle.
5. Two ANTIC instances start in the same state with the same memory and run for 2 frames. One instance reads all 16 offsets on each cycle. The two instances give the same `CycleOutput` on each cycle.
6. The requirements for the registers check the write functions: `DMACTL` (REQ-308, REQ-326, REQ-339, REQ-340), `CHACTL` (REQ-314), `DLISTL`/`DLISTH` (REQ-319), `HSCROL` (REQ-327), `VSCROL` (REQ-328), `PMBASE` (REQ-340), `CHBASE` (REQ-313, REQ-317), `WSYNC` (REQ-336), `NMIEN` (REQ-332, REQ-333) and `NMIRES` (REQ-331).

## Notes

The HRM register listing (HRM 14.7) does not give addresses for `PENH` and `PENV`. The offsets `$C` and `$D` come from TRN HW-III.I/PENH, HW-III.I/PENV and HW-V.A. TRN is the Atari Home Computer System Hardware Manual [ATA82], which HRM 4.17 cites. See REQ-342.

ACID800 antic_default reads `$D406` and expects `$FF`.
