# REQ-087: Disassembler

## Requirement

The emulation core shall give the disassembly text and the length of the instruction at each address, for all 256 opcodes.

## Rationale

The CPU trace (REQ-086) and the monitor (REQ-089) show instructions as text.

## Acceptance criteria

1. The disassembly gives the length of the instruction in bytes (1 to 3) and its text.
2. The text of a documented instruction is the mnemonic in upper case and the operand in the standard 6502 syntax: `#$nn`, `$nn`, `$nn,X`, `$nn,Y`, `$nnnn`, `$nnnn,X`, `$nnnn,Y`, `($nnnn)`, `($nn,X)`, `($nn),Y`, `A` for the accumulator, and the target address `$nnnn` for a branch.
3. The text of an undocumented instruction uses the name in HRM 3.5. An opcode that stops the CPU has the text `KIL`.
4. A test disassembles each of the 256 opcodes with the operand bytes `$34 $12` at the address `$2000`, and compares the length and the text with a table in the test.
5. Reading the bytes for the disassembly does not change the machine: it does not read the hardware registers (`$D000` to `$D7FF`) with their side effects.

## Notes

The undocumented names follow HRM 3.5. Where the HRM gives more than one name, the design gives the name that the disassembler uses.
