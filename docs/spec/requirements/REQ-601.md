# REQ-601: Priority in the left cartridge window

| Field | Value |
| --- | --- |
| Status | Withdrawn |
| Priority | Must |
| Area | Media |
| Source | HRM 2.6 Bank switching (BASIC ROM overlap) |
| Verification | Test |
| Depends on | REQ-600 |

## Requirement

This requirement is withdrawn. REQ-210 states it (OI-004).

## Rationale

The XL/XE OS enables BASIC by default. A cartridge must stay visible when BASIC is enabled.

## Acceptance criteria

1. None. The criteria are in REQ-210.

## Notes

The criteria of this requirement were merged into REQ-210. The ID is kept, because IDs never change (see `docs/spec/README.md`).
