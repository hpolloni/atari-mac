# REQ-601: Priority in the left cartridge window

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Media |
| Source | HRM 2.6 Bank switching (BASIC ROM overlap) |
| Verification | Test |
| Depends on | REQ-600 |

## Requirement

In the range `$A000-$BFFF`, the emulator shall show cartridge ROM if the cartridge maps it, else BASIC ROM if `PORTB` bit 1 is 0, else RAM.

## Rationale

The XL/XE OS enables BASIC by default. A cartridge must stay visible when BASIC is enabled.

## Acceptance criteria

The test uses a BASIC ROM image of 8192 bytes of `$BB`. The 8 KB cartridge image has 8192 bytes of `$CC`. The MaxFlash 1Mbit image has 131072 bytes of `$DD`. All reads and writes are CPU accesses through the machine memory map.

1. With the 8 KB cartridge and `PORTB` bit 1 = 0, a read of `$A000` gives `$CC`.
2. With no cartridge and `PORTB` bit 1 = 0, a read of `$A000` gives `$BB`.
3. With no cartridge and `PORTB` bit 1 = 1, a write of `$C3` to `$A000` and then a read of `$A000` gives `$C3`.
4. With the MaxFlash 1Mbit cartridge after an access to `$D510` (disabled, REQ-608) and `PORTB` bit 1 = 0, a read of `$A000` gives `$BB`.
5. With the MaxFlash 1Mbit cartridge after an access to `$D510` and `PORTB` bit 1 = 1, a write of `$C3` to `$A000` and then a read of `$A000` gives `$C3`.

## Notes

The memory map and `PORTB` are in the system area (REQ-200 range). This requirement covers only the cartridge side of the priority.

Criteria 4 and 5 apply only when REQ-608 is implemented.

REQ-210 (system area) states the same priority.
