# REQ-229: PIA interrupt request

## Requirement

The emulator shall assert the CPU IRQ line while any PIA interrupt status bit is set with its interrupt enabled, or while POKEY requests an IRQ.

## Rationale

A set status bit with the interrupt enabled issues an IRQ (HRM 2.5). POKEY shares the IRQ line with the PIA (HRM 5.7).

## Acceptance criteria

1. `PACTL` = `$3D` (bit 0 = 1). A CA1 high-to-low transition sets `PACTL` bit 7. The PIA asserts IRQ.
2. `PBCTL` = `$0C` (bits 5-3 = `001`). A CB2 high-to-low transition sets `PBCTL` bit 6. The PIA asserts IRQ.
3. After criterion 1, a read of `PORTA` clears the status. The PIA does not assert IRQ after the read cycle.
4. `PACTL` = `$3C` with bit 7 = 1, and `PBCTL` = `$04` with bit 6 = 1 (both interrupts disabled). The PIA does not assert IRQ.
5. The CPU IRQ line is asserted when only the PIA asserts IRQ, when only POKEY asserts IRQ, and when both assert IRQ. It is not asserted when neither asserts IRQ.
