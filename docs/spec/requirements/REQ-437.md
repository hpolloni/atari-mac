# REQ-437: Console keys

## Requirement

The emulator shall return from `CONSOL` bits 0-3 the value 0 for each line that is pressed (START bit 0, SELECT bit 1, OPTION bit 2) or that has a 1 in the last value written to `CONSOL`, and 1 for all other lines.

## Rationale

The OS and many programs read the console keys. For example, the OS boots a cassette when START is held at power-on, and disables BASIC when OPTION is held.

## Acceptance criteria

1. After a write of `$08` and with no key pressed, `CONSOL` reads `$07`.
2. After a write of `$08`, START gives `$06`, SELECT gives `$05`, OPTION gives `$03`, and SELECT and OPTION together give `$01`.
3. After a write of `$0F`, `CONSOL` reads `$00` for all key states.
4. After a write of `$00` and with no key pressed, `CONSOL` reads `$0F`.

## Notes

Source: project decision for bit 3 when the last write had bit 3 = 0. The HRM states that a 0 bit lets the line read normally. Bit 3 is the speaker line and has no key, so the project reads it as 1.

GTIA-SPEC 8.0 states that the switch lines have internal pull-up resistors. This agrees with the value 1 for bit 3.
