# REQ-090: Monitor memory and registers

## Requirement

The monitor shall show and change the CPU registers and the memory, and shall show the disassembly of memory.

## Rationale

The user must look at the state of the machine at a stop, and change it to test a theory.

## Acceptance criteria

1. The command `x` shows the CPU registers in the format of REQ-086 criterion 1, and the beam position (scanline and horizontal position).
2. The command `m <address> [<length>]` shows the memory as the CPU sees it, 16 bytes on each line, in hexadecimal and in ATASCII (default length 128).
3. The command `d <address> [<count>]` shows the disassembly of `<count>` instructions (default 16) with REQ-087.
4. The command `e <address> <byte> [<byte>...]` writes bytes to RAM. The command `r <register> <value>` changes A, X, Y, S, P or PC.
5. A read for criteria 2 and 3 does not change the machine: a hardware register address shows its value without its side effect, or `--` when the chip has no such value.
6. An address that does not parse gives a message and no change.
