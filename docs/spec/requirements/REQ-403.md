# REQ-403: NTSC/PAL detection register

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | GTIA, color palette, joystick and paddle inputs |
| Source | HRM 6.1 System role (NTSC/PAL detection); HRM 14.3 GTIA registers (PAL) |
| Verification | Test |
| Depends on | REQ-401 |

## Requirement

The emulator shall return `$0F` from `PAL` (`$D014`) on an NTSC machine and `$01` on a PAL machine.

## Rationale

The OS and many programs read `PAL` to select the frame rate and the colors. The HRM states that all bits are stable, so the emulator returns the full byte.

## Acceptance criteria

1. With the NTSC configuration, a read of `$D014` returns `$0F`.
2. With the PAL configuration, a read of `$D014` returns `$01`.

## Notes

The GTIA type sets this value, not the ANTIC type (HRM 4.2). The project supports only matched NTSC or matched PAL machines.
