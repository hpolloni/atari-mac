# REQ-024: System boot test

## Requirement

The test harness shall boot the machine with the free ROMs and shall read the screen text.

## Rationale

This is the smallest test of the full system.

## Acceptance criteria

1. `screen_text` reads the screen address from `SAVMSC` (`$58-$59`) and returns 24 strings of 40 characters.
2. `has_row(machine, text)` is true if a row equals `text` after leading and trailing spaces are removed (the OS text screen has a left margin of 2 columns).
3. `internal_to_ascii` gives `' '` for `$00`, `'0'` for `$10`, `'A'` for `$21`, `'A'` for `$A1` (inverse), and `'?'` for `$40`.
