# REQ-052: Published traceability matrix

## Requirement

Each CI run shall publish the traceability matrix as a build artifact and in the job summary.

## Rationale

A matrix in a local `target/` directory is not visible to reviewers.

## Acceptance criteria

1. The CI job that runs the traceability check uploads `target/traceability.md` as an artifact named `traceability`.
2. The same job appends the counts line and the table of failing rules to `$GITHUB_STEP_SUMMARY`.
3. The matrix has one row for each requirement that is not withdrawn, with its slice, package, state, tests and evidence.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
