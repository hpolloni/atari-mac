# REQ-019: Display filter flags

## Requirement

The emulator shall turn on the NTSC artifacting filter (REQ-411) when the command line has `--artifacting`, and the PAL chroma blending filter (REQ-412) when the command line has `--pal-blending`, and shall keep both filters off without these flags.

## Rationale

The user selects the TV effects at start. The filters are off by default, so that the window shows the frame buffer colors.

## Acceptance criteria

1. Without the flags, the screenshot of `--headless --frames 240 --screenshot` has each pixel equal to `palette::rgb` of the frame buffer byte.
2. With `--artifacting` on an NTSC machine, the screenshot equals the output of `palette::artifact_ntsc_row` for each row.
3. With `--pal-blending` on a PAL machine, the screenshot equals the output of `palette::pal_blend_row` for each row.
4. `--help` lists both flags.
5. `--pal-blending` on an NTSC machine, or `--artifacting` on a PAL machine, gives exit code 2 and a message that names the flag and the video standard.
