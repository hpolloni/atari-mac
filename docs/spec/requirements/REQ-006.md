# REQ-006: BASIC disabled with OPTION

## Requirement

When the OPTION key is held during the power-on reset, the emulator shall boot without BASIC.

## Rationale

The XL/XE OS disables BASIC when OPTION is held. Many programs need the RAM at `$A000-$BFFF`.

## Acceptance criteria

1. With OPTION held from power-on for 180 frames, `poke_ram($A000, $5A)` followed by `peek($A000)` gives `$5A` (RAM is visible).
2. Without OPTION, after 180 frames, `peek($A000)` gives byte `$0000` of the BASIC ROM.
