# REQ-046: Valid source citations

## Requirement

The `source` of each requirement shall be either a list of HRM sections that exist, or `Project decision`, and a requirement with the source `Project decision` shall have a `Notes` section.

## Rationale

A wrong section number sends the reader to the wrong place in the specification.

## Acceptance criteria

1. The file `docs/spec/hrm-sections.txt` lists each section number and title of the HRM edition of 2026-01-03, one per line.
2. Each `HRM n.m` in `source` matches a number in that list. A source can name more than one section.
3. A source that names no HRM section and is not `Project decision` makes the check fail.
4. A requirement with the source `Project decision` and no `Notes` section makes the check fail.

## Notes

The HRM is not in git, so the section list is committed. It holds only numbers and titles.
