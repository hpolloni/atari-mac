# REQ-406: Visible area and blank columns

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | GTIA, color palette, joystick and paddle inputs |
| Source | HRM 6.2 Display generation (Horizontal positions); HRM 6.6 Collision detection (Horizontal and vertical blank) |
| Verification | Test |
| Depends on | REQ-405 |

## Requirement

The emulator shall write `$00` to the frame buffer columns for HPOS `$20`, `$21`, `$DE` and `$DF`, and the computed display color to the columns for HPOS `$22-$DD`.

## Rationale

The HRM gives the visible range as `$22-$DD` (188 color clocks). P/M graphics show in `$22-$2B`, although ANTIC clips the wide playfield to `$2C-$DD`. HPOS `$20-$21` and `$DE-$DF` are in horizontal blank.

## Acceptance criteria

1. With `COLBK` = `$46`, no P/M graphics and code `%000` at all HPOS `$20-$DF` of scanlines 8-247, columns 0-3 and 380-383 of each row are `$00` and columns 4-379 are `$46`.
2. With `COLPF0` = `$46` and code `%100` at all HPOS `$20-$DF` of scanlines 8-247, columns 0-3 and 380-383 of each row are `$00` and columns 4-379 are `$46`.
3. With `HPOSP0` = `$20`, `GRAFP0` = `$FF`, single width and `COLPM0` = `$1A`, columns 4-15 of the row are `$1A` and columns 0-3 are `$00`.

## Notes

Source: project decision for the value `$00` in the blank columns. The HRM states that the hardware shows nothing there. HRM 14.3 gives the wide playfield as `$22-$DD`, but HRM 6.2 and HRM 4.3 give `$2C-$DD` for the visible wide playfield. The clip of the left 10 color clocks is done by ANTIC. GTIA shows the codes that ANTIC sends.
