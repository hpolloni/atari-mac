# REQ-013: Headless mode

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Frontend |
| Source | Project decision |
| Verification | Test |
| Depends on | REQ-014 |

## Requirement

The frontend shall have a headless mode that runs a given number of frames without a window and without audio, then saves the last frame as a PNG file.

## Rationale

Automated tests and bug reports need screenshots.

## Acceptance criteria

1. `atari-mac --headless --frames 180 --screenshot out.png` exits with status 0 and writes a 384 x 240 RGB PNG file.
2. Each pixel of the PNG equals `palette::rgb` of the frame buffer byte at the same position after 180 frames from power-on.
