# REQ-300: ANTIC register address decoding

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | ANTIC |
| Source | HRM 4.1 Basic operation |
| Verification | Test |
| Depends on | None |

## Requirement

The emulator shall decode only the low four address bits for CPU accesses to `$D400-$D4FF`, so that each address `$D4XY` accesses register `$D40Y`.

## Rationale

Some software uses mirror addresses. Bounty Bob Strikes Back! loops on `$D47B`, a mirror of `VCOUNT`, and stops on startup if mirrors do not work (HRM 4.16 Examples).

## Acceptance criteria

1. On scan line 100, a read of `$D47B` on cycle 50 returns `$32`. A read of `$D40B` on cycle 50 of the same scan line also returns `$32`.
2. For each address `$D4XY` (X and Y = `$0-$F`), a read returns the same value as a read of `$D40Y` in the same ANTIC state.
3. Two ANTIC instances start in the same state with the same memory. On the same cycle, one instance gets a write of `$22` to `$D4F0` and the other gets a write of `$22` to `$D400`. In the next frame, the two instances give the same `CycleOutput` on each cycle.
4. After power-on, a read of `$D4FF` returns `$7F`. This is the same value as a read of `$D40F` (`NMIST`, REQ-303).
