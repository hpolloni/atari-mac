# REQ-003: Free system ROMs

## Requirement

The emulator shall boot with AltirraOS 3.11 as the OS ROM and Altirra BASIC 1.58 as the BASIC ROM.

## Rationale

These ROMs can be distributed freely. The Atari ROMs are copyrighted.

## Acceptance criteria

1. `scripts/fetch-roms.sh` writes `roms/altirraos-xl.rom` (16,384 bytes, SHA-256 `9de5a313...6ccf`) and `roms/altirra-basic.rom` (8,192 bytes, SHA-256 `19fd6437...0913`).
2. `git ls-files '*.rom'` prints no file.
3. `Machine::new` accepts both files without an error.

## Notes

The license notice is in `roms/README.md`. The full checksums are in `scripts/fetch-roms.sh`.
