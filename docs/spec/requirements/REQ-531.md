# REQ-531: Serial port reset

## Requirement

The emulator shall reset the serial clock flip-flops when `SKCTL` bits 4-6 are `000`, shall stop the serial state machines and discard a pending `SEROUT` byte in initialization mode, and shall keep the last output bit on SIO DATA OUT in both cases.

## Rationale

Software writes `SKCTL` = `$00` to reset the serial port. An interrupted send can leave SIO DATA OUT at 0.

## Acceptance criteria

In criteria 1 and 3, the setup and the load cycle L are those of REQ-525 criterion 1 (`SEROUT` = `$4F`).

1. A write of `SKCTL` = `$00` on cycle L+10 (during the start bit) makes SIO DATA OUT read 0 on each cycle for the next 10000 cycles, and `take_serial_byte` gives no byte. A write of `SKCTL` = `$00` on cycle L+110 (during data bit 0, which is 1) makes SIO DATA OUT read 1 for the next 10000 cycles.
2. A byte pending in `SEROUT` when `SKCTL` = `$00` is written is not sent after initialization mode ends (REQ-502 criterion 4).
3. A write of `SKCTL` = `$03` (bits 4-6 = `000`) on cycle L+300 (during data bit 2, which is 1), with SIO CLOCK IN constant, keeps SIO DATA OUT at 1 for 1000 cycles. Then a write of `SKCTL` = `$23` makes the frame continue: data bit 3 starts on the first fire of timer 4 after the write, and data bits 3-7 and the stop bit follow, 94 cycles each. `take_serial_byte` then gives the value `$4F`.
4. With `SKCTL` = `$0B`, `AUDCTL` = `$00`, `AUDF1` = `$05`, `AUDF2` = `$07` and the output idle, on a cycle on which SIO DATA OUT reads 1, a write of `SKCTL` = `$03` and then a write of `SKCTL` = `$0B` on the next cycle make SIO DATA OUT read 0 until the next fire of timer 1 or timer 2.
5. In the setup of criterion 4, an `STIMER` write does not change SIO DATA OUT.

## Notes

HRM 5.6 states that bits 4-6 = `000` reset the serial clock flip-flops "to a known state", and that the serial output then updates on the next output clock cycle. Criterion 3 checks this through the output timing. The level of the flip-flops after the reset is a project decision (`docs/design/pokey.md`, "Serial port").

TRN HW-II.C/Serial-Mode-Control and POKEY-SPEC 7 state that mode `000` also resets the internal clock phase to zero.
