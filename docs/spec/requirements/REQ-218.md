# REQ-218: PIA register addresses

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | System: clocks, memory map, bank switching, reset, PIA |
| Source | HRM 2.5 Peripheral Interface Adapter (PIA) (Addressing, I/O ports) |
| Verification | Test |
| Depends on | REQ-205 |

## Requirement

The emulator shall decode only address bits 0 and 1 in `$D300-$D3FF`, with `PORTA` at offset 0, `PORTB` at offset 1, `PACTL` at offset 2 and `PBCTL` at offset 3.

## Rationale

Each PIA register is repeated 64 times in the `$D3xx` block (HRM 2.5).

## Acceptance criteria

1. A CPU write of `$3C` to `$D3FE` and then a CPU read of `$D302` give `$3C`.
2. Start: `PBCTL` = `$3C`, `PBCTL` bit 7 = 1, `DDRB` = `$FF`, port B output register = `$FD`. A CPU read of `$D305` returns `$FD`. After the read, `PBCTL` bit 7 = 0.
3. A CPU write of `$34` to `$D3FF` and then a CPU read of `$D303` give `$34`.
