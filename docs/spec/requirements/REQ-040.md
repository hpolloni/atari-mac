# REQ-040: Quality gates

| Field | Value |
| --- | --- |
| Status | Draft |

## Requirement

Each change on `main` shall pass all quality gates of `make check` and of the CI workflow.

## Rationale

The gates find defects before they are merged.

## Acceptance criteria

1. The CI job `CI success` is green for each commit on `main`.
