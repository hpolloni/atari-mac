# REQ-055: Specification gates in every run

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Quality |
| Source | Project decision |
| Verification | Test |
| Depends on | REQ-040 |

## Requirement

The specification gates of REQ-043 to REQ-054 shall run in `make check`, in the pre-commit hook and in CI.

## Rationale

A gate that does not run on each change does not protect the specification.

## Acceptance criteria

1. `make spec-check` runs all specification gates, and `make check` and `make pre-commit` call it.
2. CI has a job `Specification` that runs `make spec-check`, and `CI success` needs it.
3. The gates run in no more than 10 seconds on a developer computer.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
