# REQ-050: Every requirement is planned in a slice

## Requirement

Each requirement that is not withdrawn shall be in a work package of a slice. A requirement with the priority `must` shall be in a `Done` package before the product is declared complete.

## Rationale

A requirement that no slice plans is never implemented.

## Acceptance criteria

1. A requirement that is not withdrawn and that no slice plans makes the check fail. The matrix has a section "Not in a slice" with each such requirement.
2. The file `docs/plan/README.md` has a field `product_complete`. When it is `true`, a `must` requirement whose package is not `Done` makes the check fail.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
