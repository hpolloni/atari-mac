# REQ-050: Every requirement is planned in a slice

| Field | Value |

## Requirement

The traceability matrix shall show each requirement that is not withdrawn and that no slice plans, and a requirement with the priority `must` shall be in a slice before the product is declared complete.

## Rationale

A requirement that no slice plans is never implemented.

## Acceptance criteria

1. The matrix has a section "Not in a slice" with each such requirement.
2. The file `docs/plan/README.md` has a field `product_complete`. When it is `true`, a `must` requirement that no slice plans makes the check fail.

## Notes

Project decision: the specification gates are a project rule. The HRM does not cover them.
