# REQ-219: Data direction register select

## Requirement

The emulator shall connect `PORTA` and `PORTB` to the data direction register when bit 2 of `PACTL` or `PBCTL` is 0, and to the data register when bit 2 is 1.

## Rationale

The OS uses this selection to set the direction bits and then read the joysticks.

## Acceptance criteria

1. `PACTL` = `$30` (bit 2 = 0). A CPU write of `$F0` to `PORTA` sets `DDRA` = `$F0`. A read of `PORTA` returns `$F0`.
2. After criterion 1, `PACTL` = `$34` (bit 2 = 1). A write of `$55` to `PORTA` sets the port A output register to `$55`. With no joystick pressed, a read of `PORTA` returns `$5F`. After `PACTL` = `$30`, a read of `PORTA` returns `$F0` (`DDRA` did not change).
3. `PACTL` = `$34`, `DDRA` = `$01`, port A output register = `$00`, no joystick pressed. A read of `PORTA` returns `$FE` (bit 0 is an output). With `DDRA` = `$00`, a read of `PORTA` returns `$FF` (all bits are inputs).
4. Port A output register = `$55`. `PACTL` = `$30`, and a write of `$FF` sets `DDRA` = `$FF`. Then `PACTL` = `$34`. A read of `PORTA` returns `$55` (the output register kept its value).
5. `PBCTL` = `$38`. A write of `$FF` to `PORTB` sets `DDRB` = `$FF`, and a read of `PORTB` returns `$FF`. Then `PBCTL` = `$3C`. A write of `$FD` to `PORTB` and then a read of `PORTB` give `$FD`.
