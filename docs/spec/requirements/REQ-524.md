# REQ-524: ASCII to key code for test input

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | POKEY: audio, timers, keyboard, interrupts, serial port |
| Source | HRM 5.8 Keyboard scan (Key codes; Table 12); project decision for the conversion rules |
| Verification | Test |
| Depends on | REQ-523 |

## Requirement

The emulator shall provide a function that converts each printable ASCII character that is a key legend of the 65XE (REQ-523), and newline, tab, escape and backspace, to the `KBCODE` value that types it, with bit 6 set when the key needs Shift.

## Rationale

The test harness types text into BASIC and the OS editor through this function (REQ-025).

## Acceptance criteria

1. Each of the 26 letters, in upper case and in lower case, gives the code of its letter key in REQ-523. For example, `'A'` and `'a'` give `$3F`, and `'Z'` and `'z'` give `$17`.
2. Each of the 10 digits gives the code of its digit key in REQ-523. For example, `'1'` gives `$1F` and `'0'` gives `$32`. `' '` gives `$21`. `'\n'` gives `$0C` (RETURN).
3. `'!'` gives `$5F`, `'"'` gives `$5E`, `'#'` gives `$5A`, `'$'` gives `$58`, `'%'` gives `$5D`, `'&'` gives `$5B`, `'\''` gives `$73`, `'@'` gives `$75`, `'('` gives `$70`, `')'` gives `$72`.
4. `'<'` gives `$36`, `'>'` gives `$37`, `'-'` gives `$0E`, `'_'` gives `$4E`, `'='` gives `$0F`, `'|'` gives `$4F`, `';'` gives `$02`, `':'` gives `$42`, `'+'` gives `$06`, `'\\'` gives `$46`, `'*'` gives `$07`, `'^'` gives `$47`.
5. `','` gives `$20`, `'['` gives `$60`, `'.'` gives `$22`, `']'` gives `$62`, `'/'` gives `$26`, `'?'` gives `$66`.
6. `'\t'` gives `$2C` (TAB), `'\x1B'` gives `$1C` (ESC), `'\x08'` gives `$34` (BACK SPACE).
7. `'{'`, `'}'`, `'~'`, `` '`' ``, all other characters from `'\x00'` to `'\x1F'`, `'\x7F'`, and the characters `'\u{80}'`, `'\u{E9}'` and `'\u{20AC}'` give no value.
8. No value has bit 7 (Control) set.

## Notes

The function uses the keycap legends of HRM Table 12. The character that appears on the screen depends on the OS keyboard table and on the CAPS state of the OS. These are outside the HRM. Upper case and lower case letters both give the unshifted letter key. This is a project decision: the OS starts in upper case mode, so the unshifted key types an upper case letter. The test harness uses upper case text.

The function never sets bit 7 (Control).
