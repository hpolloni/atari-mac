# REQ-624: Drive D1: device ID

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Media |
| Source | HRM 9.1 Basic SIO protocol (Table 29: SIO device IDs); HRM 9.2 Poll Commands (Type 0 Poll) |
| Verification | Test |
| Depends on | REQ-615, REQ-617 |

## Requirement

The emulated disk drive D1: shall reply only to command frames with device ID `$31`.

## Rationale

The disk drive IDs are `$31-$3F`. The OS boots from D1:, which is ID `$31`. A reply to another ID would interfere with other devices.

## Acceptance criteria

All criteria use the SD test image of REQ-619 in D1:. Each frame is a Status frame with the given ID: `ID 53 00 00` and its checksum (REQ-616).

1. The Status frame with ID `$31` gets the reply `41 43 00 FF E0 00 E0`.
2. The Status frames with the IDs `$00`, `$30`, `$32`, `$3F`, `$40`, `$4F`, `$50`, `$5F` and `$FF` each get no byte in the 178,977 machine cycles (100 ms) after the command line goes high.

## Notes

Drives D2: to D8: are out of scope. The design permits more drives later.
