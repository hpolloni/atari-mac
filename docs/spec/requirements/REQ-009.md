# REQ-009: Keyboard mapping

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Frontend |
| Source | HRM 5.8 Keyboard scan |
| Verification | Test |
| Depends on | REQ-008, REQ-523 |

## Requirement

The frontend shall map the host keyboard to all keys of the 65XE keyboard, including SHIFT, CONTROL, BREAK, HELP, START, SELECT, OPTION and RESET.

## Rationale

All software input comes from these keys.

## Acceptance criteria

1. A unit test of the frontend key map checks each row of the key table in `docs/design/architecture.md`: the host key gives the listed Atari key.
2. The same test checks that each key of the 65XE keyboard (REQ-523) has at least one host key.
