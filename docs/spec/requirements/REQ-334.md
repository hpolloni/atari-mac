# REQ-334: NMI cycle timing and NMIEN deadlines

## Requirement

The emulator shall set the `NMIST` bit on cycle 7 and assert the NMI on cycle 8 of the scan line of a DLI or VBI, so that the CPU starts the 7-cycle NMI sequence at the first instruction boundary on cycle 10 or later.

## Rationale

DLI handlers count cycles to change registers in horizontal blank. The NMI must start on the same cycle as on hardware.

## Acceptance criteria

1. On the scan line of a DLI, after a write to `NMIRES` on the scan line before, a read of `NMIST` on cycle 6 gives bit 7 = 0, and a read on cycle 7 gives bit 7 = 1.
2. With `DMACTL` = `$20` and `NMIEN` = `$C0`, an instruction `$80` (1 blank line with DLI) has no DMA on cycles 2-24. The CPU runs `NOP` instructions. If a `NOP` starts on cycle 8, the NMI sequence starts on cycle 10. If a `NOP` starts on cycle 9, the NMI sequence starts on cycle 11.
3. In the setup of criterion 2 with `NMIEN` = `$00`, an `STA NMIEN` writes `$C0` on cycle 7, and `NOP` instructions start on cycles 8, 10 and 12. The NMI sequence starts on cycle 12 (the earliest start is cycle 11).
4. A write of `$C0` to `NMIEN` on cycle 8 (from `$00`) causes no NMI on that scan line. `NMIST` bit 7 still becomes set.
5. With `NMIEN` = `$C0`, a write of `$00` to `NMIEN` on cycle 8 prevents the NMI of that scan line. A write of `$00` on cycle 9 does not prevent it.
6. A write to `NMIRES` on cycle 8 does not prevent the NMI of that scan line.

## Notes

The CPU needs two cycles to see the NMI (HRM 4.8, DLI timing). The CPU requirements (area `cpu`) must agree with this contract. The HRM also says that an IRQ sequence that starts on cycles 5-9 can be taken over by the NMI. That is CPU behavior and is not part of this requirement.

Criteria 2 and 3 use the CPU contract of HRM 4.8 and HRM Figure 6, note 2: the 7-cycle NMI sequence starts on the first instruction boundary on cycle 10 or later, or on cycle 11 or later for an enable on cycle 7.

ACID800 antic_nmist writes `$00` to `NMIEN` on cycle 6 and, in a second run, on cycle 7 of scan line 248. It expects that the write on cycle 6 prevents the VBI and that the write on cycle 7 does not prevent it. The cycle numbers come from the instruction cycles of the test and the `WSYNC` timing of REQ-336. With the same timing, the test expects that a write of `$80` on cycle 7 enables a DLI and that a write on cycle 8 does not, and that `NMIST` bit 7 reads 0 on cycle 6 and 1 on cycle 7. These results agree with the HRM. The HRM says that `NMIEN` must be written by cycle 8 to disable an interrupt. This requirement follows the HRM (criterion 5).
