# REQ-042: Test coverage

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | Quality |
| Source | Project decision |
| Verification | Test |
| Depends on | None |

## Requirement

The tests shall execute at least 80 percent of the lines of the workspace.

## Rationale

Code that no test executes can contain defects that nobody sees.

## Acceptance criteria

1. The CI job `Coverage (cargo-llvm-cov)` runs `cargo llvm-cov --fail-under-lines 80` and passes.
