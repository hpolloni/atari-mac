# REQ-097: Command-line option combinations

## Requirement

The frontend shall reject the option combinations that it cannot run before the machine starts, with exit code 2 and a message on standard error that names the options.

## Rationale

Two options that use the same device, or an option without the option that it needs, give a machine that does not do what the user asked for.

## Acceptance criteria

1. `--headless` without `--frames` gives the message `--headless needs --frames`.
2. `--xex` with `--disk` gives the message `--xex and --disk cannot be used together: both use drive D1:`.
3. `--xex` with `--bas` gives the message `--xex and --bas cannot be used together: an executable starts with BASIC disabled`.
4. `--cas` with `--xex` gives the message `--cas and --xex cannot be used together: both make key presses at the start`.
5. `--trace-from` or `--trace-frames` without `--trace` gives the message `--trace-from and --trace-frames need --trace`.
6. `--trace-frames 0` gives the message `--trace-frames must be at least 1`.
7. The message has the format of REQ-096 criterion 5. A syntax error of REQ-096 comes before the errors of this requirement.
8. When the command line breaks more than one rule of this requirement or of REQ-019 criterion 5, REQ-080 criterion 8, REQ-081 criterion 6, REQ-092 criterion 3 and REQ-093 criterion 5, the message is for the first rule in this order: `--trace-frames 0`, the other trace rule, `--headless`, `--no-run`, `--xex` with `--disk`, `--xex` with `--bas`, `--cas` with `--bas`, `--no-basic` with `--bas`, `--auto-return`, `--cas` with `--xex`, then the filter rules of REQ-019 criterion 5.

## Notes

Project decision: the user asked on 2026-11-22 for requirements for the rules of the parser that no requirement stated. The rules are the behavior of the parser on that date (commit 46f8c65). The other combination rules are in REQ-019 criterion 5, REQ-080 criterion 8, REQ-081 criterion 6, REQ-092 criterion 3 and REQ-093 criterion 5.
