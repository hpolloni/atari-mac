# REQ-005: Boot to BASIC

## Requirement

With AltirraOS, Altirra BASIC, no cartridge and no disk, the emulator shall show the BASIC `READY` prompt in no more than 3 seconds of emulated time.

## Rationale

This proves that the CPU, the memory map, ANTIC, the keyboard path and the OS work together.

## Acceptance criteria

1. From power-on, after no more than 180 NTSC frames, one row of `screen_text` is `READY` after trailing spaces are removed.
