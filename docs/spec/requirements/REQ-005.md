# REQ-005: Boot to BASIC

## Requirement

With AltirraOS, Altirra BASIC, no cartridge and no disk, the emulator shall show the Altirra BASIC prompt `Ready` in no more than 4 seconds of emulated time.

## Rationale

This proves that the CPU, the memory map, ANTIC, the keyboard path and the OS work together.

## Acceptance criteria

1. From power-on, after no more than 240 NTSC frames, one row of `screen_text` is `Ready` after leading and trailing spaces are removed.

## Notes

Changed at the WP-5 merge (2026-11-19), from the real ROM output: Altirra BASIC prints `Ready`, not `READY` (Atari BASIC). With no disk drive, the OS sends 3 SIO commands with 28 attempts each (HRM 9.2), so the prompt appears at about frame 195. The limit was 180 frames (3 s) before.
