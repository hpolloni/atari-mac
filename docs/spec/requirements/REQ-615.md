# REQ-615: Command frame reception

## Requirement

The emulated SIO devices shall receive a command frame of five bytes (device ID, command, AUX1, AUX2, checksum) that the computer sends at 19200 baud while the command line is low.

## Rationale

The OS addresses each SIO device with a command frame. The PIA CB2 output drives the command line. The line is active low. The high-to-low edge starts a command frame, and the low-to-high edge tells the device that the computer is ready for the reply.

## Acceptance criteria

All criteria use NTSC timing, an SD image in D1:, and host bytes with a bit period of 94 machine cycles unless the criterion gives another value. The host bytes of a frame follow each other with no gap. "No reply" means that the drive sends no byte in the 178,977 machine cycles (100 ms) after the command line goes high.

1. The computer lowers the command line, sends `31 53 00 00 84` (Status), and raises the command line. The drive sends `41` and then the rest of the Status reply of REQ-619.
2. The computer sends `31 53 00 00 84` with the command line high, and the command line stays high. No reply.
3. The computer lowers the command line, sends `31 53 00`, raises the line, lowers it again, sends `31 53 00 00 84` and raises the line. The drive sends one Status reply only, after the second rising edge.
4. Frames `31 53 00 00 84` with all bytes at a bit period of 90 cycles, and with all bytes at 98 cycles, each get the Status reply.
5. A frame `31 53 00 00 84` with its second byte (`53`) at a bit period of 89 cycles gets no reply. The same frame with its second byte at 99 cycles gets no reply.

## Notes

Each byte has one start bit, eight data bits from LSB to MSB and one stop bit, with no parity.

The HRM gives the bit period of a POKEY divisor as `2 * (divisor + 7)` machine cycles. Divisor 40 gives 94 cycles. The HRM states that the transmitter and the receiver must agree within 5 percent. 5 percent of 94 is 4.7 cycles, so the accepted bit periods are 90 to 98 cycles. To treat a byte outside this range as a framing error is a project model of the receiver.

The POKEY side of the serial port is in the POKEY area (REQ-500 range). The PIA CB2 output is in the system area (REQ-200 range).
