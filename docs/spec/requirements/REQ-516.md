# REQ-516: Serial output complete interrupt

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Must |
| Area | POKEY: audio, timers, keyboard, interrupts, serial port |
| Source | HRM 5.6 Serial port (Output shift register); HRM 5.7 Interrupts (Interrupt enable/status); HRM 14.4 POKEY registers (IRQEN, IRQST) |
| Verification | Test |
| Depends on | REQ-515, REQ-525 |

## Requirement

The emulator shall make `IRQST` bit 3 read 0 while the serial output shift register is idle and 1 while it shifts, for all `IRQEN` values, and shall assert the IRQ output while `IRQST` bit 3 is 0 and `IRQEN` bit 3 is 1.

## Rationale

The OS SIO code waits for the serial output complete interrupt at the end of each transmitted frame.

## Acceptance criteria

The setup and the load cycle L are those of REQ-525 criterion 1.

1. After `Pokey::new`, with `IRQEN` = `$00`, `IRQST` bit 3 reads 0 and `irq()` returns false.
2. With the output idle, a write of `IRQEN` = `$08` on cycle X makes `irq()` return true from cycle X+1. `IRQST` bit 3 stays 0.
3. `IRQST` bit 3 reads 0 on cycle L-1, 1 on each cycle from L to L+939, and 0 from cycle L+940.
4. With a second write of `SEROUT` after the load (between cycles L+1 and L+939), `IRQST` bit 3 reads 1 on each cycle from L to L+1879, and 0 from cycle L+1880.
5. A write of `IRQEN` = `$00` or `IRQEN` = `$F7` does not change `IRQST` bit 3. The test makes the writes while the output is idle and while it shifts.
6. With `IRQEN` = `$08`, `irq()` returns false from cycle L to cycle L+939 and true from cycle L+940, if no other source is active.

## Notes

HRM 5.7 says that the status bit "and corresponding interrupt" are set even if `IRQEN` bit 3 is 0. HRM 14.4 says that setting `IRQEN` bit 3 makes the interrupt fire while the output is idle. The project reads this as: the status bit ignores `IRQEN`, and the IRQ output needs `IRQEN` bit 3. See the open issues in `docs/design/pokey.md`.
