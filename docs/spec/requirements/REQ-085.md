# REQ-085: Log option of the frontend

## Requirement

When the command line has `--log <categories>`, the frontend shall write the log records of these categories to standard error, one line for each record.

## Rationale

The user turns on only the categories that they need, so that the output stays short.

## Acceptance criteria

1. `<categories>` is a list separated by commas of the categories of REQ-084 (`tape`, `sio`, `reset`, `media`), `frontend` and `all`. `all` turns on each category. A category turns on its records of level `info`. A category with the suffix `:debug` (for example `sio:debug`) also turns on its records of level `debug`.
2. Each line has the format `[frame <f> cycle <c>] <category>: <message>`, where `<f>` and `<c>` are the frame count and the cycle count of the record (REQ-084 criterion 2). A record of the frontend has the counts of the machine at the start of its frame.
3. The category `frontend` has a record when turbo starts or stops, with the cause (BASIC typing, the tape motor or the disk drive, REQ-095), when the user pauses or continues the emulation, and at a cold reset from F10.
4. A category name that is not in the list gives exit code 2 before the machine starts, and a message on standard error that names the category.
5. Without `--log`, the frontend writes no log line, and the maximum level of the `log` crate is `Off`.
6. `--help` lists `--log <categories>`.
