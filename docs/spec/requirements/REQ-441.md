# REQ-441: GTIA P/M DMA without ANTIC P/M DMA

## Requirement

When `GRACTL` bit 1 = 1 and ANTIC fetches missiles but not players, the emulator shall load `GRAFP0-3` with the data bus values of machine cycles 2-5 of each scanline.

## Rationale

The HRM describes this odd effect. Few programs depend on it.

## Acceptance criteria

In all criteria, `HPOSP0-3` = `$40`, `$50`, `$60`, `$70`, single width.

1. With `GRACTL` = `$03`, a missile DMA byte on cycle 0, no player DMA byte, and bus values `$81`, `$42`, `$24`, `$18` on cycles 2, 3, 4, 5 of each scanline, players 0-3 show the bit patterns `$81`, `$42`, `$24`, `$18` at their positions on each scanline.
2. With `GRACTL` = `$01` and the inputs of criterion 1, `GRAFP0-3` do not change.
3. With `GRACTL` = `$03`, player DMA bytes `$FF` on cycles 2-5 and different bus values, players 0-3 show `$FF`.

## Notes

ANTIC must give GTIA the data bus value of these cycles. The HRM also states that with all P/M DMA off in ANTIC, GTIA takes the first halted cycle in horizontal blank as the missile fetch and loads players at cycles 3-7. That case is an open issue in `docs/design/gtia.md`.
