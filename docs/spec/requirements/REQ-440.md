# REQ-440: Joystick buttons

## Requirement

The emulator shall connect the button of joystick port 1 to the `TRIG0` input and the button of joystick port 2 to the `TRIG1` input.

## Rationale

Games read the fire button through `TRIG0` (`$D010`) and `TRIG1` (`$D011`).

## Acceptance criteria

1. With the port 1 button pressed, `TRIG0` reads `$00`. With it released, `TRIG0` reads `$01`.
2. With the port 2 button pressed, `TRIG1` reads `$00` and `TRIG0` does not change.
