# REQ-431: GTIA mode 11 (16 hues)

| Field | Value |
| --- | --- |
| Status | Draft |
| Priority | Should |
| Area | GTIA, color palette, joystick and paddle inputs |
| Source | HRM 6.9 GTIA special modes (Mode 11); HRM 6.6 Collision detection (Playfield collisions) |
| Verification | Test |
| Depends on | REQ-428, REQ-424 |

## Requirement

With `PRIOR` bits 6-7 = `%11`, the emulator shall show each playfield pixel p as `COLBK` OR `p x 16`, with luminance 0 for p = 0, treat the playfield as background for priority and collisions, and show any player or missile on top of it.

## Rationale

GRAPHICS 11 shows 16 hues at one luminance.

## Acceptance criteria

1. With `PRIOR` = `$C0` and `COLBK` = `$06`, pixel 3 shows `$36` and pixel 0 shows `$00`.
2. With `PRIOR` = `$C0` and `COLBK` = `$16`, pixel 0 shows `$10`.
3. With `PRIOR` = `$C0` and `COLPM0` = `$46`, player 0 on pixels 0-15 shows `$46`.
4. With `PRIOR` = `$D0`, `COLBK` = `$06`, `COLPF3` = `$08` and the fifth player (missile 0) on pixel 2, the pixel shows `$28`. On pixel 0 it shows `$00`.
5. With `PRIOR` = `$C0`, player 0 and missile 0 on pixels 0-15 set no bit in `P0PF` and `M0PF`.
