# REQ-084: Machine event log

## Requirement

The emulation core shall send a log record through the `log` crate for each machine event of the categories in the table, and the records shall not change the emulated machine.

## Rationale

The user must see what the machine does while it loads a tape or a disk, without a debugger: when the motor runs, which record loads, which SIO command the OS sends and what the device replies.

## Acceptance criteria

1. Each record has the `log` target `atari::<category>`, with a category from this table, and the level `info`, except where the table gives `debug`:

   | Category | Events and the data that each record contains |
   | --- | --- |
   | `tape` | The motor starts or stops (REQ-641): the record index (from 0) and the byte offset in that record. A data record starts (REQ-642): its index, its length in bytes and its baud rate. The tape ends. |
   | `sio` | A command frame ends: the device ID, the command, AUX1, AUX2, and whether the checksum matches the frame bytes (all bytes in hexadecimal). A device replies: ACK, NAK, COMPLETE or ERROR, and the length of the data frame. The SIOV shortcut does a request (REQ-623): the device ID, the command and the result. A transmitted or received data byte (`debug`): its value. |
   | `reset` | A cold reset and a warm reset (the RESET key). |
   | `media` | A cartridge, an executable, a disk image or a tape image is inserted: its kind, its length in bytes and, for a cartridge, its type. |

2. Each record contains the frame count and the machine cycle count at the event (`Machine::frame_count`, `Machine::cycle_count`).
3. A test logger receives the records of criterion 1 for these runs: the boot test tape of REQ-643 (`tape`, `sio` is not needed), the boot test disk of SLICE-05 (`sio`), a RESET key press and a cold reset (`reset`), and each kind of media (`media`).
4. After the same frames and the same key input, the frame buffer and the RAM are the same when all categories are on at level `debug` and when the log is off.
5. The core calls no `log` function that formats a message when the maximum level of the `log` crate is `Off`.

## Notes

Project decision (2026-11-21, SLICE-09). The HRM does not cover it. The message text after the data of criterion 1 is not fixed. The design gives it.

The speed limit of REQ-007 applies with the log off.
