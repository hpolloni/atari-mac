# REQ-041: No unsafe code

## Requirement

The emulator shall contain no `unsafe` code.

## Rationale

Safe Rust removes a whole class of memory defects.

## Acceptance criteria

1. The workspace lint `unsafe_code = "forbid"` is set.

## Notes

Project decision: a quality rule of the project. The HRM does not cover it.
